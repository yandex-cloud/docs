# Создать пользовательское правило

Для работы с [пользовательскими правилами](../../concepts/custom-rules.md) необходима [роль](../../security/kspm-roles.md) `security-deck.rules.editor` или выше в окружении.

{% list tabs group=instructions %}

- Интерфейс {{ sd-name }} {#cloud-sd}

  1. Перейдите в сервис [{{ sd-full-name }}]({{ link-sd-main }}).
  1. На панели слева выберите ![file-text](../../../_assets/console-icons/file-text.svg) **{{ ui-key.yacloud_org.app.security.control_rules_rWmUV }}**.
  1. В верхней части окна выберите [окружение](../../concepts/workspace.md).
  1. Перейдите на вкладку **{{k8s}}®** и нажмите кнопку **{{ ui-key.yacloud_org.security.rules.create_rule_pcNF6 }}**.
  1. В блоке **Основные параметры**:

     1. Введите название и описание правила.
     1. Выберите **Тип проверки**, который определяет тип правил, применяемых к кластеру {{ k8s }}. Сейчас поддерживается только Admission — правило применяется при создании или изменении {{ k8s }}-объекта.

        По умолчанию правило создается в режиме `Аудит`. После создания правила вы можете [поменять режим](./manage-rule-modes.md).

     1. Выберите критичность правила.
     1. В поле **Рекомендации** опишите набор действий, которые необходимо выполнить для устранения нарушения.

   1. В блоке **Правила политики** вставьте YAML-код правила. Для правил типа Admission поддерживаются только [Kyverno ClusterPolicy](https://kyverno.io/policies/?type=ClusterPolicy). Копируйте только сам список правил, начиная с поля `- name` (без полей `spec` и `rules`).
        
      Нажмите **Проверить**, чтобы проверить правильность введенного кода. Проверка также будет автоматически запущена при сохранении правила.

  1. Нажмите кнопку **Сохранить**.

{% endlist %}

Созданное правило отобразится на вкладке **Пользовательские**. При срабатывании правила отправляется алерт. Чтобы просмотреть алерты, на панели слева выберите ![alerts](../../../_assets/security-deck/alerts.svg) **{{ ui-key.yacloud_org.security-center.label_alerts }}** или [откройте](./use-kspm.md) дашборд модуля {{ kspm-name }}.

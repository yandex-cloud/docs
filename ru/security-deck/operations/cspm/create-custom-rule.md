# Создать пользовательское правило

Для работы с [пользовательскими правилами](../../concepts/custom-rules.md) необходима [роль](../../security/cspm-roles.md) `security-deck.rules.editor` или выше.

{% list tabs group=instructions %}

- Интерфейс {{ sd-name }} {#cloud-sd}

  1. Перейдите в сервис [{{ sd-full-name }}]({{ link-sd-main }}).
  1. На панели слева выберите ![file-text](../../../_assets/console-icons/file-text.svg) **{{ ui-key.yacloud_org.app.security.control_rules_rWmUV }}**.
  1. В верхней части окна выберите [окружение](../../concepts/workspace.md).
  1. Перейдите на вкладку **Конфигурация** и нажмите **{{ ui-key.yacloud_org.security.rules.create_rule_pcNF6 }}**.
  1. В блоке **Базовое правило** выберите правило, параметры которого будут использоваться как основа для создания пользовательского правила.

     Базовое правило также можно выбрать в общем списке правил. Если на основе правила в списке доступно создать пользовательское правило, возле него можно нажать ![image](../../../_assets/console-icons/ellipsis.svg) и выбрать ![image](../../../_assets/console-icons/copy-plus.svg) **Создать правило на основе**.

  1. В блоке **Основные параметры**:
     
     1. Измените название и описание правила.
     1. Выберите критичность правила.
     1. В поле **Рекомендации** опишите набор действий, которые необходимо выполнить для устранения нарушения.

  1. (Опционально) В блоке **Настраиваемые параметры** измените параметры, специфические для базового правила.
  1. Нажмите кнопку **Сохранить**.

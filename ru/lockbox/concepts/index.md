# Обзор сервиса {{ lockbox-full-name }}

{{ lockbox-full-name }} — это сервис для централизованного хранения секретов, таких как пароли, [SSH-ключи](../../glossary/ssh-keygen.md) и токены. Секрет состоит из набора версий, в которых хранятся данные. Версия содержит одну или больше пар ключ-значение. Ключ — это несекретный идентификатор значения, по которому вы будете его идентифицировать. Значение — это секретные данные.

{{ lockbox-full-name }} позволяет централизованно создавать, изменять и удалять секреты, а также управлять доступом к ним с помощью [{{ iam-full-name }}](../../iam/index.yaml).

Все секреты хранятся в зашифрованном виде. По умолчанию используется системный ключ. Вы также можете шифровать секреты собственным ключом [{{ kms-full-name }}](../../kms/index.yaml).

## Мониторинг и аудит {#monitoring-and-audit}

В [{{ monium-name }}](../../monium/index.yaml) доступны [метрики {{ lockbox-name }}](../metrics.md): количество активных версий секретов и операции получения их содержимого.

Чтобы отслеживать изменения секретов и доступ к их содержимому, [создайте трейл](../../audit-trails/operations/create-trail.md) в {{ at-full-name }}. Для регистрации обращений к содержимому включите сбор событий уровня сервисов (Data Plane). Поддерживаемые события перечислены в [справочнике аудитных логов](../at-ref.md).

# Видео в сервисе {{ video-name }}

С помощью {{ video-name }} вы можете загружать на [канал](index.md#channels) _видео_ для дальнейшей публикации на внешних ресурсах.

{% include [video-characteristic](../../_includes/video/video-characteristic-multiple.md) %}

По умолчанию воспроизведение видео начинается только после обработки, если браузер поддерживает исходный файл. Вы можете изменить это в настройках канала. Тогда исходный файл будет воспроизводиться сразу, без изменений, и содержать исходные метаданные.

{% include [video-multi-soundtracks](../../_includes/video/video-multi-soundtracks.md) %}

{% include [video-resolution-limits](../../_includes/video/video-resolution-limits.md) %}

Для видео доступна загрузка пользовательских обложек. Обложка будет отображаться в интерфейсе {{ video-name }}, а также в [плеере](./player.md) на сайте, где размещено видео.

{% include [image-characteristic](../../_includes/video/image-characteristic.md) %}

Вы можете [опубликовать](../operations/video/get-link.md) видео и выбрать тип доступа:

* **{{ ui-key.yacloud_video.videos.label_access_rights-sign-url-access }}** — видео будет доступно по специальной ссылке. {#temporary-link}

    {% include [video-temporary-links](../../_includes/video/video-temporary-links.md) %}

* **{{ ui-key.yacloud_video.videos.label_access_rights-public }}** — видео будет доступно неограниченное время и всем, у кого есть ссылка на видео. {#permanent-link}

На сайте можно разместить как одиночные видео, так и [плейлисты](playlists.md) с видео в определенной последовательности. В плейлистах будут доступны к просмотру только видео с постоянными ссылками. Публикация плейлистов описана в разделе [{#T}](../operations/playlists/get-link.md).

## Статусы {#statuses}

### Статусы видео {#video-statuses}

* `{{ ui-key.yacloud_video.videos.status_wait-uploading }}` — исходный файл с видео загружается в хранилище {{ yandex-cloud }}.
* `{{ ui-key.yacloud_video.videos.status_processing }}` — исходный файл с видео транскодируется в несколько вариантов видео с различным битрейтом и разрешением. При дальнейшем просмотре видео на клиентских устройствах видеоплеер подбирает оптимальный вариант для плавного воспроизведения при текущей скорости интернет-соединения.
* `{{ ui-key.yacloud_video.videos.status_ready }}` — транскодирование выполнено, видео готово к просмотру.
* `{{ ui-key.yacloud_video.videos.status_error }}` — ошибка при загрузке файла или транскодировании видео. Проверьте стабильность интернет-соединения, целостность файла, его формат и повторите попытку.

### Статусы публикации {#publication-statuses}

* `{{ ui-key.yacloud_video.videos.status_published }}` — видео [опубликовано](../operations/video/publish.md).
* `{{ ui-key.yacloud_video.videos.status_unpublished }}` — видео не опубликовано.

## ИИ-возможности {#ai-capabilities}

Чтобы предложить пользователям больше возможностей и увеличить аудиторию ваших видео, включите нейросетевые функции, построенные на ML-моделях Яндекса. Подробнее о работе нейросетевых функций см. в [блоге Яндекса](https://habr.com/ru/companies/yandex/articles/792608/).

### Суммаризация {#summarization}

[Суммаризация](../operations/video/summarization.md#enable) позволяет автоматически создавать краткое содержание видео, которое передает его основные моменты и ключевую информацию. Суммаризация доступна для видео длительностью не более 4 часов. При включении суммаризации к видео автоматически добавляются таймкоды. Вы можете скорректировать предложенные таймкоды или [добавить свои вручную](#timecodes).

### Нейроперевод {#stranslation}

[Нейроперевод](../operations/video/translation.md) позволяет автоматически переводить видео на несколько языков и озвучивать его [разными голосами](https://habr.com/ru/news/905118/). Список поддерживаемых языков приведен в [интерфейсе {{ video-name }}]({{ link-video-main }}).

### Субтитры {#subtitles}

Нейросетевые [субтитры](../operations/video/subtitles.md) помимо текста, который произносится в видео, содержат разделение на спикеров. Речь нового спикера будет начинаться с новой строки и тире, что повышает удобство восприятия речи. Список поддерживаемых языков приведен в [интерфейсе {{ video-name }}]({{ link-video-main }}).

Также можно загрузить свои субтитры в форматах SRT и VTT. Максимальный размер файла субтитров — 500 МБ. Для одного видео вы можете загрузить несколько файлов субтитров на одном или разных языках.

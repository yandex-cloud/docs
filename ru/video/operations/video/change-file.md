# Заменить видеофайл

В интерфейсе {{ video-name }} вы можете заменить уже загруженный видеофайл на новый. При этом ID видео и ссылка на него останутся прежними.

Новый файл проходит обработку. Пока она не завершена, продолжает воспроизводиться предыдущая версия видео.

Заменить файл нельзя, пока видео находится в статусе `{{ ui-key.yacloud_video.videos.status_wait-uploading }}` или `{{ ui-key.yacloud_video.videos.status_processing }}`. Дождитесь окончания загрузки и обработки.

{% include [change-file-cancel-note](../../../_includes/video/change-file-cancel-note.md) %}

Чтобы заменить видео:

{% list tabs group=instructions %}

- Интерфейс {{ video-name }} {#console}

  1. Откройте [главную страницу]({{ link-video-main }}) {{ video-name }}.
  1. Выберите канал.
  1. На вкладке ![image](../../../_assets/console-icons/circle-play.svg) **{{ ui-key.yacloud_video.videos.title_videos }}** в строке с нужным видео нажмите ![image](../../../_assets/console-icons/ellipsis.svg) и выберите **{{ ui-key.yacloud_video.common.action_edit }}**.
  1. Под видео нажмите **Заменить видеофайл**.
  1. В открывшемся окне нажмите кнопку **Выбрать файл** и выберите новое видео.

      {% include [video-characteristic](../../../_includes/video/video-characteristic.md) %}

  1. Дождитесь окончания загрузки и обработки нового файла.

{% endlist %}

После успешной замены файла будет показано новое видео. При необходимости вы можете [изменить](./update.md) его название, описание и другие параметры.

Если при загрузке или обработке возникла ошибка, проверьте подключение к интернету, целостность и формат файла, затем повторите попытку.

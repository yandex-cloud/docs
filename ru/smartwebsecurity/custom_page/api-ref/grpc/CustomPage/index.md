# SmartWebSecurity CustomPage API, gRPC: CustomPageService

A set of methods for managing CustomPage resources.

## Methods

#|
||Method | Description ||
|| [Get](get.md) | Returns the specified CustomPage resource. ||
|| [List](list.md) | Retrieves the list of CustomPage resources in the specified folder. ||
|| [Create](create.md) | Creates a CustomPage resource in the specified folder. ||
|| [Update](update.md) | Updates the specified CustomPage resource. ||
|| [Delete](delete.md) | Deletes the specified CustomPage resource. ||
|#

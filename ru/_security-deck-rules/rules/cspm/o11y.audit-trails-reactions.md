#### Описание

**Как работает правило**: правило проверяет, что в окружении Security Deck включен модуль [Обнаружение угроз (TD)](https://yandex.cloud/ru/docs/security-deck/concepts/threat-detector).

**Риски при невыполнении правила**:
* Без уведомлений организация не узнает своевременно об угрозах в реальном времени в используемых сервисах. Это увеличивает время реакции на угрозу и повышает вероятность успешной эксплуатации уязвимости злоумышленником.
* Аномальная активность (например, несанкционированные операции с ресурсами) может остаться незамеченной. Инцидент развивается без реагирования, что увеличивает масштаб ущерба.

Модуль [Обнаружение угроз (TD)](https://yandex.cloud/ru/docs/security-deck/concepts/threat-detector) представляет собой первую линию реагирования на инциденты безопасности в облачной инфраструктуре пользователя в Yandex Security Deck. Позволяет в автоматическом режиме обнаруживать подозрительную активность и уведомлять пользователя об обнаруженных угрозах.

Модуль Обнаружение угроз анализирует события аудита, фиксируемые в инфраструктуре клиента и регистрируемые с помощью сервиса [Yandex Audit Trails](https://yandex.cloud/ru/services/audit-trails).

При каждом срабатывании [правила](https://yandex.cloud/ru/docs/security-deck/concepts/threat-detector#rules) на потенциальную угрозу безопасности Security Deck формирует [алерт](https://yandex.cloud/ru/docs/security-deck/concepts/alerts) с подробной информацией о событии и советами по устранению выявленной угрозы.

#### Инструкции и решения по выполнению

Включите модуль Обнаружение угроз (TD) при создании окружения в Security Deck. Подробнее в [инструкции](https://yandex.cloud/ru/docs/security-deck/operations/workspaces/create).

При срабатывании правила на потенциальную угрозу безопасности вы получите [алерт](https://yandex.cloud/ru/docs/security-deck/operations/alerts/view) с подробностями инцидента и рекомендациями по исправлению.

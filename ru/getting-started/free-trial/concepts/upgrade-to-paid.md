# Переход на платную версию

{% note warning %}

Пробный период и стартовый грант для новых клиентов недоступны.

Рекомендуем сразу [перейти на платную версию](./upgrade-to-paid.md).

{% endnote %}

Переход на платную версию не происходит автоматически после завершения пробного периода. Чтобы перейти на платную версию, перейдите в [сервис {{ billing-name }}]({{ link-console-billing }}), откройте страницу платежного аккаунта и нажмите **{{ ui-key.yacloud_billing.billing.account.dashboard.button_go-pay }}**. 



## Оплата услуг

В {{ yandex-cloud }} услуги оплачиваются в зависимости от потребленного количества. Подробные инструкции по оплате ресурсов после перехода на платную версию вы найдете в [документации](../../../billing/) сервиса {{ billing-name }}.

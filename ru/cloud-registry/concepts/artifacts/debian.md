# Debian-артефакт

_Артефакт Debian_ — это файл пакета `*.deb`, содержащий скомпилированное программное обеспечение, метаданные, зависимости и другие ресурсы для систем на базе [Debian](https://{{ lang }}.wikipedia.org/wiki/Debian) и [Ubuntu](https://{{ lang }}.wikipedia.org/wiki/Ubuntu).

## Формат пакета {#package-format}

[DEB](https://ru.wikipedia.org/wiki/Deb_(формат_файла)) — это формат пакета, используемый в системах на базе Debian. Пакет DEB представляет собой архив, содержащий:

* скомпилированные исполняемые файлы и библиотеки;
* метаданные пакета (название, версия, описание, зависимости);
* скрипты установки и удаления;
* файлы конфигурации.

Артефакты Debian используются для распространения программного обеспечения, которое можно устанавливать и которым можно управлять с помощью менеджеров пакетов [APT](https://ru.wikipedia.org/wiki/APT) (Advanced Package Tool) и [dpkg](https://{{ lang }}.wikipedia.org/wiki/Dpkg).

## Подпись метаданных {#metadata-signing}

{{ cloud-registry-name }} поддерживает подпись метаданных Debian-реестра с помощью GPG-ключа. Подпись позволяет клиентам проверять подлинность пакетов перед установкой.

При создании реестра с подписью метаданных:

* Секретная часть GPG-ключа хранится в [{{ lockbox-full-name }}](../../../../lockbox/).
* {{ cloud-registry-name }} автоматически подписывает метаданные реестра при каждом обновлении.
* Клиенты используют публичную часть GPG-ключа для проверки подписи.

Подробнее о настройке подписи в разделе [{#T}](../../operations/debian/installation.md#prepare-gpg-key).

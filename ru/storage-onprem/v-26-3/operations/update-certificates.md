# Обновление сертификатов

Чтобы установить или обновить сертификат для S3 API или консоли управления через CLI:

1. Подготовьте файл сертификата и файл приватного ключа.

1. Загрузите сертификат:

    {% note tip %}

    Чтобы не проверять статус обновления сертификата вручную, добавьте флаг `--wait` к команде загрузки — так она завершится только после применения сертификата. Например, `cli ops certs upload-s3 --cert-file <файл_сертификата> --key-file <файл_ключа> --wait`

    {% endnote %}

    * Для S3 API:

        ```bash
        cli ops certs upload-s3 --cert-file <файл_сертификата> --key-file <файл_ключа>
        ```

    * Для консоли управления:

        ```bash
        cli ops certs upload-console --cert-file <файл_сертификата> --key-file <файл_ключа>
        ```

    Команда проверит, что сертификат и ключ образуют корректную пару, а CN и SAN сертификата соответствуют доменам кластера. Поддерживаются Wildcard-сертификаты: например, `*.onprem.local` включает `s3.onprem.local`.

    При успешной проверке команда вернет имя задачи обслуживания, в рамках которой обновится сертификат. Если проверки не пройдены, команда возвращает ошибку. Например, с перечнем недостающих имен:

    ```text
    Error: rpc error: code = InvalidArgument desc = invalid certificate: certificate names mismatch: missing names: s3.onprem.local
    ```

1. Дождитесь завершения задачи обслуживания. Сертификат обновится в течение нескольких секунд — минут.

    Чтобы проверить статус задачи, выполните команду:

    ```bash
    cli ops tasks get <имя_задачи>
    ```

# Требования к кластеру {{ k8s }}

Надежность хранения данных, доступность S3 API и производительность {{ objstorage-onprem-name }} зависят от конфигурации кластера. Учитывайте следующие требования и рекомендации:

* Необходимо не менее трех узлов, на которых развернут {{ objstorage-onprem-name }}. Это влияет на надежность защиты данных в слое хранения MDS2, отказоустойчивость используемых сервисов и доступность S3 API. Производительность также масштабируется с увеличением количества хостов.
* {{ objstorage-onprem-name }} лучше всего работает с большим количеством HDD на каждом из хостов. Разделение данных по дискам влияет не только на надежность, но и на производительность — {{ objstorage-onprem-name }} по возможности использует все диски параллельно и равномерно.
* Настоятельно рекомендуется также использовать быстрый диск SSD/NVMe, на котором TopoLVM будет создавать PV. Это влияет на производительность шардов {{ PG }}, которые Goose активно использует под нагрузкой.
* Из-за большого объема горизонтального трафика рекомендуется использовать отдельные сетевые интерфейсы для оверлея {{ k8s }} и внешних подключений.

Подробнее о доступности и восстановлении избыточности — в разделе [Отказоустойчивость](system-characteristics.md#reliable-configurations).

# Требования к кластеру {{ k8s }}

{{ objstorage-onprem-name }} может обеспечить заявленные свойства при выполнении требований к конфигурации кластера:

1. Необходимо не менее трех хостов, на которых развернут {{ objstorage-name }}.
    Это влияет на надежность защиты данных в Elliptics, отказоустойчивость используемых сервисов и доступность S3 API.

    Также производительность масштабируется вместе с количеством хостов.

1. {{ objstorage-name }} лучше всего работает с большим количеством HDD на каждом из хостов.
    Разделение данных по дискам влияет не только на надежность, но и на производительность — {{ objstorage-name }} старается утилизировать все диски параллельно и равномерно.

1. Настоятельно рекомендуется иметь также быстрый SSD/NVMe-диск, из которого TopoLVM будет создавать PV.
    Это влияет на производительность шардов {{ PG }}, которые Goose активно использует под нагрузкой.

1. Рекомендуется иметь отдельные сетевые интерфейсы для слоя {{ k8s }} и внешних подключений из-за большого количества горизонтального трафика.

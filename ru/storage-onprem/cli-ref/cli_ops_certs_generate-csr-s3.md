# cli ops certs generate-csr-s3

Generate CSR for S3 certificate via cert-manager

```
cli ops certs generate-csr-s3 [flags]
```

## Options

```
  -h, --help   help for generate-csr-s3
      --wait   Wait for CSR and print it
```

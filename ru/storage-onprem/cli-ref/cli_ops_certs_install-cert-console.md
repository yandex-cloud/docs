# cli ops certs install-cert-console

Install signed Console certificate returned by client CA

```
cli ops certs install-cert-console [flags]
```

## Options

```
      --cert-file string   Signed certificate file path (PEM)
      --csr string         CSR name (from generate-csr)
  -h, --help               help for install-cert-console
      --wait               Wait for task completion
```

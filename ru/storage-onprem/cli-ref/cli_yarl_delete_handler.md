# cli yarl delete handler

Delete a per-handler operation quota

```
cli yarl delete handler <entity> [flags]
```

## Options

```
  -h, --help                  help for handler
  -o, --operation Operation   handler name
  -s, --scope Scope           scope: bucket, tenant (default bucket)
```

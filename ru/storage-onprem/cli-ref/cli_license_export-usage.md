# cli license export-usage

Download encrypted license usage data

```
cli license export-usage [flags]
```

## Options

```
  -f, --force           Overwrite an existing output file
      --from string     Export range start in RFC3339 format
  -h, --help            help for export-usage
  -o, --output string   Output file path
      --to string       Export range end in RFC3339 format
```

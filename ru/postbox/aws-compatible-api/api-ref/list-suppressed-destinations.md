# Метод ListSuppressedDestinations

Возвращает список адресов в [пользовательском стоп-листе](../../concepts/suppression-list.md#user). Нужное облако определяется по сервисному аккаунту, от имени которого выполняется запрос.

## Запрос {#request}

```http
GET /v2/email/suppression/addresses HTTP/2
```

### Query-параметры {#query-parameters}

#|
|| **Параметр** | **Описание** ||
|| `PageSize` | **Тип**: integer.

Максимальное число результатов, которое может быть на одной странице в ответе на запрос. Значение по умолчанию — `100`, максимально допустимое — `1000`. Если передать значение больше `1000`, будет использовано значение `1000`. Отрицательное значение приводит к ошибке. ||
|| `NextToken` | **Тип**: string.

Токен позволяет получить следующую страницу результатов запроса. Для этого передайте значение параметра `NextToken`, который вернулся в ответе на предыдущий запрос. Значение токена нельзя разбирать или составлять вручную. ||
|| `Reason` | **Тип**: string.

Причина добавления адреса в стоп-лист: `BOUNCE` или `COMPLAINT`. Параметр можно указать несколько раз. Если параметр не указан, возвращаются адреса со всеми причинами. ||
|| `StartDate` | **Тип**: string.

Нижняя граница времени последнего изменения записи, включительно. ||
|| `EndDate` | **Тип**: string.

Верхняя граница времени последнего изменения записи, включительно. ||
|#

Даты указываются в формате [RFC 3339](https://www.ietf.org/rfc/rfc3339.txt) (`2026-01-01T00:00:00Z`) либо как время в секундах в формате Unix. Допустимый диапазон дат — с 1 января 1970 года по 31 декабря 2105 года. Значение `StartDate` не может быть больше значения `EndDate`.

## Ответы {#responses}

### 200 OK {#200}

```json
{
   "SuppressedDestinationSummaries": [
      {
         "EmailAddress": "user@example.com",
         "Reason": "COMPLAINT",
         "LastUpdateTime": 1586552585.000
      }
   ],
   "NextToken": "<токен>"
}
```

#|
|| **Параметр** | **Описание** ||
|| `SuppressedDestinationSummaries` | **Тип**: array.

Массив адресов в стоп-листе. Записи отсортированы от недавно измененных к более старым. ||
|| `EmailAddress` | **Тип**: string.

Адрес получателя. ||
|| `Reason` | **Тип**: string.

Причина добавления адреса в стоп-лист: `BOUNCE` или `COMPLAINT`. ||
|| `LastUpdateTime` | **Тип**: number.

Время последнего изменения записи в секундах в формате Unix. ||
|| `NextToken` | **Тип**: string.

Токен позволяет получить следующую страницу результатов запроса. Возвращается, только если страница заполнена целиком. Пустое значение означает, что данные закончились. ||
|#

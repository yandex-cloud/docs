# Метод GetDedicatedIps

Возвращает список [выделенных IP-адресов](../../concepts/glossary.md#dedicated-ip) в каталоге или [пуле](../../concepts/glossary.md#dedicated-ip-pool). Нужный каталог определяется по сервисному аккаунту, от имени которого выполняется запрос.

## Запрос {#request}

```http
GET /v2/email/dedicated-ips HTTP/2
```

### Query-параметры {#query-parameters}

#|
|| **Параметр** | **Описание** ||
|| `PoolName` | **Тип**: string.

Имя пула. Если параметр указан, в ответе возвращаются только IP-адреса из этого пула.

Необязательный параметр. ||
|| `PageSize` | **Тип**: integer.

Максимальное число результатов, которое может быть на одной странице в ответе на запрос. Если число доступных результатов больше значения `PageSize`, в ответе на запрос возвращается токен `NextToken` для запроса следующей страницы результатов.

Необязательный параметр. ||
|| `NextToken` | **Тип**: string.

Токен позволяет получить следующую страницу результатов запроса. Для этого передайте значение параметра `NextToken`, который вернулся в ответе на предыдущий запрос.

Необязательный параметр. ||
|#

## Ответы {#responses}

### 200 OK {#200}

```json
{
  "DedicatedIps": [
    {
      "Ip": "<IP-адрес>",
      "WarmupStatus": "DONE",
      "WarmupPercentage": 100,
      "PoolName": "<имя_пула>"
    }
  ],
  "NextToken": "<токен>"
}
```

#|
|| **Параметр** | **Описание** ||
|| `DedicatedIps` | **Тип**: array.

Массив выделенных IP-адресов. ||
|| `Ip` | **Тип**: string.

Выделенный IP-адрес. ||
|| `WarmupStatus` | **Тип**: string.

Статус [прогрева](../../concepts/dedicated-ip.md#warmup) IP-адреса. Всегда возвращается значение `DONE`. ||
|| `WarmupPercentage` | **Тип**: integer.

Процент завершения прогрева IP-адреса. Всегда возвращается значение `100`. ||
|| `PoolName` | **Тип**: string.

Имя пула, в котором находится IP-адрес. IP-адреса, не распределенные по пользовательским пулам, находятся в пуле по умолчанию `ses-default-dedicated-pool`. ||

|| `NextToken` | **Тип**: string.

Токен позволяет получить следующую страницу результатов запроса. Если число доступных результатов больше значения `PageSize`, в ответе на запрос возвращается токен `NextToken` для запроса следующей страницы результатов. Каждой странице присваивается свой токен для пагинации. ||
|#

Ответ `200 OK` может содержать дополнительные параметры. Он не возвращается строго в формате, указанном выше.

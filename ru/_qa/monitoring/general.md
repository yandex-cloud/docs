# Общие вопросы про {{ monitoring-name }}

{% include [logs](../logs.md) %}

#### Как посмотреть сервисные дашборды? {#dont-see-dashboards}

Сервисные дашборды создаются автоматически после создания ресурсов в {{ yandex-cloud }}. Добавьте необходимый ресурс и обновите [главную страницу]({{ link-monitoring }}) сервиса {{ monitoring-name }}.

#### Почему пропали старые данные графиков в {{ monitoring-name }}? {#lost-data-graphs}

Метрики, для которых новые значения не поступали в течение 30 дней, автоматически удаляются из {{ monitoring-name }}. Для сервиса {{ managed-prometheus-name }} этот срок составляет 60 дней, для сервиса {{ compute-full-name }} — 7 дней.

Существует также ненастраиваемый механизм прореживания данных, сокращающий их объем в хранилищах.

#### Почему не передаются метрики и нельзя создать воркспейс {{ prometheus-name }}? {#prometheus-trouble}

Такое возможно, если в облаке нет [ресурсов](../../overview/roles-and-resources.md#resources), которые передают данные мониторинга. Начните использовать какой-либо ресурс и дождитесь, когда метрики начнут отображаться в {{ monitoring-name }}.

#### Почему на графиках есть разрывы, хотя облачный ресурс работает нормально? {#gaps-in-chart-lines}

Разрыв на графике сам по себе не означает, что облачный ресурс не работает. Проверьте, поступают ли значения метрики за выбранный период: в разделе **{{ ui-key.yacloud_monitoring.aside-navigation.menu-item.explorer.title }}** откройте [таблицу значений](../../monium/metrics/metric-explorer.md#view-source).

Если значения есть, проверьте настройки [прореживания](../../monium/concepts/decimation.md#reading-decimation). Когда в интервале прореживания нет значений, способ заполнения **Без значения** оставляет пропуск на графике.

Чтобы проверить график без прореживания:

1. Откройте нужный график в разделе **{{ ui-key.yacloud_monitoring.aside-navigation.menu-item.explorer.title }}** в [{{ monium-name }}]({{ link-monium }}).
1. Выберите временной диапазон не более 7 дней: для большего диапазона отключить прореживание нельзя.
1. Справа вверху графика нажмите ![Настройки графика](../../_assets/console-icons/gear.svg).
1. На панели настроек раскройте раздел **{{ ui-key.yacloud_monitoring.wizard.tab.downsampling }}** и в поле **{{ ui-key.yacloud_monitoring.channel.field_method }}** выберите **{{ ui-key.yacloud_monitoring.wizard.vis.downsampling.none }}**.
1. Закройте панель настроек. Изменения сразу отобразятся на графике.

Если данных нет и в таблице, проверьте их поставку и [использование квоты `Metrics Write`](../../monium/concepts/limits.md#quota-resources). При исчерпании квоты часть точек отбрасывается, поэтому на графике могут появляться пропуски.

Подробнее о параметрах графика — в разделе [Настроить отображение на графике](../../monium/metrics/metric-explorer.md#set-graph).

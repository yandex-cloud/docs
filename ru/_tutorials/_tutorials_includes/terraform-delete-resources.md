Чтобы удалить ресурсы, созданные с помощью {{ TF }}:

1. Удалите из конфигурации блоки `resource` и `module`, относящиеся к этой инфраструктуре, а также источники данных и выходные значения `output`, которые на них ссылаются. Сохраните блоки `terraform` и `provider`.

1. Проверьте план удаления:

   ```bash
   terraform plan
   ```

   {% note alert %}

   {{ TF }} удалит ресурсы, для которых вы убрали описания из конфигурации: кластеры, [сети](../../vpc/concepts/network.md#network), [подсети](../../vpc/concepts/network.md#subnet), [виртуальные машины](../../compute/concepts/vm.md) и другие ресурсы.

   {% endnote %}

   Проверьте список ресурсов, которые {{ TF }} собирается удалить.

1. Примените изменения:

   ```bash
   terraform apply
   ```

1. Подтвердите удаление: введите `yes` и нажмите **Enter**.

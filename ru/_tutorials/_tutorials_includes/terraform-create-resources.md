1. После проверки конфигурации выполните команду:

   ```bash
   terraform plan
   ```

   Терминал выведет список ресурсов и их параметров. На этом этапе ресурсы не создаются. Если конфигурация содержит ошибки, {{ TF }} укажет на них.

   {% note alert %}

   Все созданные с помощью {{ TF }} ресурсы тарифицируются. Внимательно проверьте план.

   {% endnote %}

1. Чтобы создать ресурсы, выполните команду:

   ```bash
   terraform apply
   ```

1. Подтвердите создание ресурсов: введите в терминал слово `yes` и нажмите **Enter**.

   {{ TF }} создаст ресурсы и выведет в терминале [IP-адреса](../../vpc/concepts/address.md) созданных [виртуальных машин](../../compute/concepts/vm.md). Проверьте наличие ресурсов и их настройки в [консоли управления]({{ link-console-main }}).

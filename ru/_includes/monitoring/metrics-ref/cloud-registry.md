Имя метрики пишется в метку `name`.

При переходе к графику из сервисного дашборда значение метки `service` используется без подчеркиваний — `cloud-registry`.

Если вы создаете запрос в {{ monium-name }} через **Обзор** → **Метрики**, укажите проект каталога с реестром (`project = folder__<идентификатор_каталога>`), `cluster = default` и `service = __cloud-registry__`. Для просмотра метрик конкретного реестра добавьте его идентификатор в метку `registry_id`.

Общие метки для всех метрик сервиса {{ cloud-registry-name }}:

Метка | Значение
----|----
service | Идентификатор сервиса: `cloud-registry`
registry_id | Идентификатор [реестра](../../../cloud-registry/concepts/registry.md)

Сервисному аккаунту сканирования {{ dspm-name }} назначается `dspm.worker` и, для бакета с пользовательским {{ kms-short-name }}-ключом, `kms.keys.decrypter` согласно [инструкции сканирования](../../../../security-deck/operations/dspm/create-scan.md). Если доступ к бакету регулирует политика доступа, отдельно проверяются разрешение опубликованных IP-адресов {{ sd-name }} и успешное сканирование.

Для просмотра прав в {{ ciem-name }} требуется `organization-manager.viewer` на организацию или более широкая документированная роль; отзыв проверяется отдельно по [документированным ролям и ограничениям](../../../../security-deck/security/ciem-roles).

Свидетельство {{ ycdr-name }} включает одобрение доступа, конфигурацию отдельного коллектора для каждого облака, успешную передачу тестового события по TLS и привязку `ycdr.admin`; подробнее в [обзоре {{ ycdr-name }}](../../../../ycdr/concepts/index.md) и описании [модели доступа](../../../../ycdr/security/index.md).

Условия {{ ciem-name }} и {{ ycdr-name }} не переносятся на весь {{ sd-name }} или его [Alerts](../../../../security-deck/concepts/alerts.md).

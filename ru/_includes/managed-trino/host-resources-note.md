{% note info %}

В классах хостов `standard` и `memory-optimized` часть ресурсов виртуальной машины резервируется для служебных компонентов {{ mtr-name }}. Чтобы определить ресурсы, доступные координатору или воркеру {{ TR }}, используйте таблицы в разделе [Классы хостов](../../managed-trino/concepts/instance-types.md). Для классов `legacy` число vCPU и объем RAM в имени класса соответствуют ресурсам, доступным компоненту {{ TR }}.

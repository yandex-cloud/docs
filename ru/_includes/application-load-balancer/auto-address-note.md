Автоматически выделенный публичный IP-адрес по умолчанию удаляется вместе с балансировщиком. Чтобы сохранить адрес для нового балансировщика, [включите для него защиту от удаления](../../vpc/operations/deletion-protection.md#enable-deletion-protection) перед удалением текущего балансировщика.

| Информация об источнике | Описание  |
| ----------------------- | --------- |
| Базы данных | Базы данных, доступные в источнике |
| Таблицы | Таблицы и их принадлежность к базе данных |
| Представления | Представления и их SQL-определения |
| Хранимые процедуры | Хранимые процедуры и их SQL-определения |
| Колонки | Имена и типы данных |
| Комментарии | Комментарии к таблицам и колонкам |
| Происхождение данных | Связи между таблицами и представлениями, а также между представлениями |
| Происхождение данных на уровне колонок | Связи между колонками источника и колонками представлений |
| Профилирование данных | Статистика по таблицам и колонкам |
| Удаленные объекты | Объекты, которые были удалены из источника после предыдущей выгрузки |

Метаданные загружаются из системных таблиц {{ MY }}. В каталоге метаданные представлены в виде структуры: база данных → таблица/представление → колонка.

Происхождение данных определяется на основе разбора SQL-определений представлений.

Для сбора метаданных пользователю необходимы следующие привилегии:

* для представлений — `SHOW VIEW`;
* для метрик профилирования данных — `SELECT` на таблицы.

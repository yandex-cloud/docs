| Информация об источнике | Описание  |
| ---------------------- | --------- |
| Базы данных | Базы данных, доступные в источнике |
| Таблицы | Пользовательские таблицы |
| Представления | Представления и их SQL-определения |
| Материализованные представления | Материализованные представления и их SQL-определения |
| Словари| Словари и их структура |
| Колонки | Имена и типы данных |
| Комментарии | Комментарии к таблицам и колонкам |
| Происхождение данных | Связи между таблицами и представлениями, а также между представлениями |
| Происхождение данных на уровне колонок | Связи между колонками |
| Использование объектов | Статистика обращений к объектам |
| Профилирование данных | Статистика по таблицам и колонкам |
| Удаленные объекты | Объекты, которые были удалены из источника после предыдущей выгрузки |

Метаданные загружаются из системных таблиц {{ CH }} с помощью `SQLAlchemy`. В каталоге метаданные представлены в виде структуры: база данных → таблица/представление → колонка.

Происхождение данных определяется на основе разбора SQL-определений представлений, которые хранятся в `system.tables.create_table_query`.

Для профилирования данных пользователю необходимы права `SELECT` на таблицы.

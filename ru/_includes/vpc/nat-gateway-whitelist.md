{% note info %}

Если внешний ресурс ограничивает доступ по IP-адресам, учитывайте, что публичные IP-адреса [NAT-шлюза](../../vpc/concepts/gateways.md#nat-gateway) могут меняться и их нельзя зарезервировать. Для доступа с фиксированного IP-адреса используйте [NAT-инстанс](../../vpc/tutorials/nat-instance/index.md) со [статическим публичным IP-адресом](../../vpc/operations/set-static-ip.md). Добавьте этот адрес в список разрешенных на внешнем ресурсе.

[Диапазоны публичных IPv4-адресов ресурсов {{ yandex-cloud }}](../../vpc/concepts/ips.md) используются разными клиентами облака. Добавление всех этих диапазонов в список разрешенных откроет сетевой доступ также с IP-адресов других клиентов.

{% endnote %}

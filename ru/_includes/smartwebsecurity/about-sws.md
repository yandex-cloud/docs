{{ sws-name }} защищает веб-приложения от угроз на прикладном уровне L7 модели OSI: [DDoS-атак](../../glossary/ddos.md), ботов и эксплуатации уязвимостей, например SQL-инъекций.

На [прокси-серверах {{ sws-name }}](../../smartwebsecurity/concepts/domain-protect.md#proxy) автоматически включена [Network Protection](../../smartwebsecurity/concepts/network-protection.md) — защита от DDoS-атак на сетевом (L3) и транспортном (L4) уровнях. Если вы подключаете профиль безопасности к собственному L7-балансировщику {{ alb-name }}, защиту на этих уровнях можно включить отдельно с помощью [{{ ddos-protection-full-name }}](../../vpc/ddos-protection/index.md).

Входящий трафик проверяется по правилам профиля безопасности. В профиле можно настроить:

* Базовые правила — для простой фильтрации трафика по заданным условиям.
* Правила Smart Protection — для автоматической защиты от DDoS-атак на уровне L7 при помощи алгоритмов машинного обучения и поведенческого анализа.
* Правила профиля Cloud WAF — для защиты от эксплуатации уязвимостей веб-приложения или сайта. Правила блокируют множество известных угроз, например SQL-инъекции и командные инъекции, межсайтовый скриптинг и другие. В профиль Cloud WAF можно добавить несколько наборов правил: [OWASP Core Rule Set](https://owasp.org/www-project-modsecurity-core-rule-set/) (CRS), [Yandex Ruleset](../../smartwebsecurity/concepts/waf.md#yandex-ruleset) и [ML WAF (Yandex Malicious Score)](../../smartwebsecurity/concepts/waf.md#yandex-ml-ruleset).
* Проверку в [{{ captcha-full-name }}](../../smartcaptcha/) — для защиты от ботов с помощью [CAPTCHA](https://ru.wikipedia.org/wiki/Капча).
* Фильтрацию по спискам IP-адресов — для разрешения или блокировки запросов от указанных адресов.

Чтобы снизить нагрузку на приложение, к профилю безопасности можно подключить профиль Advanced Rate Limiter (ARL). Его правила ограничивают количество запросов, прошедших проверку профилем безопасности.

Помимо Cloud WAF, для защиты веб-приложений можно использовать SolidWall WAF. Его правила настраивают и сопровождают аналитики сервиса. SolidWall WAF подключается только через домены: в отдельном профиле создают приложение и добавляют к нему домены. Порядок подключения описан в [руководстве по настройке](../../smartwebsecurity/tutorials/solidwall-waf.md).

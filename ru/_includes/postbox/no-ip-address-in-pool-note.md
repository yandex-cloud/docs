Если к конфигурации привязан пул, в котором нет ни одного выделенного IP-адреса, письма с этой конфигурацией не отправляются: метод [SendEmail](../../postbox/aws-compatible-api/api-ref/send-email.md) возвращает ошибку `404 NotFoundException`. Автоматического переключения на общий пул IP-адресов сервиса не происходит.

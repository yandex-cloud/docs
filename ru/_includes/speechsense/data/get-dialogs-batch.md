Чтобы получить данные нескольких диалогов, передайте их идентификаторы одним массивом в запросе Get. Рекомендуемый размер пакета — до 100 диалогов. Если ответ получается слишком большим, уменьшите пакет или ограничьте результаты анализа маской `resultsMask` в REST API или `results_mask` в gRPC API.

Каждый вызов Get расходует [квоту на получение диалогов]({{ link-docs-ai }}speechsense/concepts/limits#speechsense-quotas). Например, данные 100 диалогов можно получить одним запросом с массивом из 100 ID. При запросе каждого диалога отдельно потребуется 100 запросов. Квоты действуют на проект и учитывают как запросы API, так и просмотр диалогов в интерфейсе {{ speechsense-name }}.

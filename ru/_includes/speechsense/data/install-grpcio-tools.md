Создайте и активируйте виртуальное окружение, затем установите пакет `grpcio-tools` с помощью менеджера пакетов [pip](https://pip.pypa.io/en/stable/):

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install grpcio-tools
```

Остальные команды Python выполняйте в этом окружении.

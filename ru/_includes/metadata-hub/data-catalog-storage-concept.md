При создании источника данных для него автоматически создается хранилище данных (data store), содержащее метаданные этого источника. Если в одном каталоге создано несколько источников для одного кластера управляемых баз данных или одной пользовательской инсталляции базы данных, их метаданные объединяются в одно хранилище.

Для каждого хранилища доступна информация о загрузках, источниках, выгруженных данных и связях между объектами БД или сервиса. Метаданные хранилища поддерживают [разметку метаданных](#metadata-markup) и поиск.

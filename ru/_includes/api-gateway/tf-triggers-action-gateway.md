* `action` — параметры приемника. Блок можно указать несколько раз, чтобы триггер вызывал несколько ресурсов, в том числе разных типов. Максимальное количество ресурсов ограничено [лимитами](../../api-gateway/concepts/limits.md#api-gw-limits).

    * `gateway_websocket_broadcast` — параметры API-шлюза:

        * `gateway_id` — идентификатор API-шлюза.
        * `path` — путь в OpenAPI-спецификации. Через WebSocket-соединения, которые установлены по этому пути, будут отправляться события.
        * `service_account_id` — идентификатор сервисного аккаунта с правами на отправку событий в WebSocket-соединения.

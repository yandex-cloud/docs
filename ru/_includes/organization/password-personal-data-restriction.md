{% note info %}

При установке или смене пароля проверяется, что пароль не содержит текущие значения атрибутов пользователя: логин, адрес электронной почты, имя, фамилию и номер телефона. Проверка выполняется без учета регистра, независимо от того, кто устанавливает пароль: пользователь или администратор. Ограничение действует для всех пулов пользователей независимо от настроек парольной политики. Отключить это ограничение нельзя.

{% endnote %}

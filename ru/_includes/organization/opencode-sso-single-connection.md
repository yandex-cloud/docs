* Для одного рабочего пространства можно настроить только одно подключение SSO: либо [SAML](https://ru.wikipedia.org/wiki/SAML), либо [OIDC](https://ru.wikipedia.org/wiki/OpenID#OpenID_Connect). Использовать оба протокола одновременно нельзя.
* К рабочему пространству можно привязать несколько почтовых доменов, но каждый домен может принадлежать только одному рабочему пространству.

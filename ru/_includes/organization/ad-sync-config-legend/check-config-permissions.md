check_config_permissions

Настройки [проверки прав доступа](../../../organization/concepts/ad-sync/sync-agent.md#auth-data-security) к файлам с аутентификационными данными, выполняемой при запуске агента. Необязательный параметр. Возможные значения:

* `true` — проверка прав доступа к файлам конфигурации агента, содержащим чувствительные данные, включена.
* `false` — проверка прав доступа к файлам конфигурации агента отключена. Значение по умолчанию.

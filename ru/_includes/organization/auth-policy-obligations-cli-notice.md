{% note info %}

В параметре `--obligations` вы можете указать любое из трех требований (`stepUpRequired`, `reauthenticationRequired` или `skipMfa`), любые два из них или все три одновременно. При этом к событиям аутентификации будут предъявляться сразу все требования, которые заданы в параметре `--obligations` политики.

Не рекомендуется задавать для одной политики аутентификации более одного требования. Вместо этого рекомендуем создать несколько разных политик с разными требованиями.

{% endnote %}

### enable_password_writeback {#config-enable-password-writeback}

Параметр, управляющий [обратной записью паролей](../../../organization/concepts/sync-external/ldap-sync.md#password-writeback) пользователей во внешний каталог.

{% include [pw-writeback-preview-notice](./pw-writeback-preview-notice.md) %}

Возможные значения:

* `true` — при попытке изменить пароль синхронизированного пользователя на стороне {{ org-full-name }} ([изменение пароля](../../../organization/operations/manage-account.md#edit-password) самим пользователем или [сброс пароля](../../../organization/operations/user-pools/reset-user-password.md#reset) администратором) агент сначала попытается изменить пароль соответствующего пользователя во внешнем каталоге. И только в случае успеха этой операции агент изменит пароль в {{ org-full-name }}.
* `false` — при изменении пароля синхронизированного пользователя на стороне {{ org-full-name }} пароль этого пользователя не будет изменен во внешнем каталоге. В процессе ближайшей итерации синхронизации агент вернет на стороне {{ org-full-name }} пароль этого пользователя к прежнему значению, полученному из внешнего каталога. Это также поведение по умолчанию, если функциональность обратной записи не активирована.

Для корректной работы обратной записи паролей настройте также [раздел](#config-ldap) `ldap.password_writeback` конфигурации агента синхронизации.

## Преобразование событий {#transform-messages}

Для каждого приемника в триггере можно задать шаблон преобразования в [формате jq](https://jqlang.github.io/jq/manual/), по которому событие преобразуется перед отправкой. Преобразование позволяет, например:

* привести событие к формату, ожидаемому приемником;
* оставить в событии только нужные поля;
* добавить в событие собственные поля и значения.

Шаблон задается отдельно для каждого приемника, поэтому один триггер может отправлять разным приемникам разные представления одного и того же события. Если шаблон не задан, событие отправляется в приемник в исходном виде.

## Группирование событий {#batching}

Настройки группирования позволяют передавать в приемник сразу несколько событий. Эти настройки задают ограничение сверху по размеру группы событий и по времени ее накопления. Например, если размер группы событий равен 3, то в приемник могут поступать группы, в которых содержится от 1 до 3 событий.

Вы можете настроить группирование событий перед отправкой их в приемник у следующих триггеров:

* триггер для {{ message-queue-name }};
* триггер для {{ cloud-logging-name }};
* триггер для {{ objstorage-name }};
* триггер для {{ container-registry-name }};
* триггер для {{ iot-name }};
* триггер для {{ yds-name }};
* триггер для почты;
* триггер для Telegram.

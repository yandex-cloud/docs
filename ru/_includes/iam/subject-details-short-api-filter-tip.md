Чтобы получить определенные атрибуты субъектов, передайте их в поле `field_mask`. Чтобы нужным образом отфильтровать результаты, в поле `filter` передайте фильтрующее выражение на языке [Common Expression Language (CEL)](https://cel.dev/). Подробнее читайте в разделе [{#T}](../../iam/concepts/subject-details.md).

* (Опционально) `filter` — фильтрация списка обслуживаний. Допустимые значения:

    * `status` — вывод обслуживаний определенного статуса:

        * `SCHEDULED` — запланировано;
        * `RUNNING` — выполняется;
        * `SUCCEEDED` — успешно завершено;
        * `CANCELLED` — отменено.


    > Например: `filter=status="CANCELLED"`.

* (Опционально) `orderBy` — сортировка списка обслуживаний:

    * `<поле_сортировки>` — название поля, по которому производится сортировка. Допустимые значения:

        * `created_at` — сортировка по дате и времени создания обслуживания;
        * `start_scheduled_at` — сортировка по запланированным дате и времени начала обслуживания;
        * `started_at` — сортировка по дате и времени фактического начала обслуживания.

            {% note info %}

            Для обслуживания, которое еще не началось, фильтрация по параметру `started_at` недоступна.

            {% endnote %}

    * `<направление_сортировки>` — допустимые значения:

        * `asc` — сортировка по возрастанию;
        * `desc` — сортировка по убыванию.

    > Например: `orderBy=created_at asc`.

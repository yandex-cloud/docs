Расширение поддерживает:

* Точный и приблизительный поиск ближайших соседей.
* Различные типы векторов: одинарной точности, половинной точности, бинарные и разреженные векторы.
* Несколько метрик сравнения векторов: L2 (евклидово расстояние), косинусное расстояние, скалярное произведение, L1 (манхэттенское расстояние), расстояние Хэмминга и Жаккара.
* Работу с любым языком программирования, который поддерживает подключение к {{ PG }}.

Векторный поиск можно комбинировать с привычными возможностями {{ PG }} и SQL.

По умолчанию в `vector` выполняется точный поиск, при котором сравниваются все векторы. Для больших объемов данных можно создавать векторные индексы и использовать приблизительный поиск. В этом случае поиск выполняется быстрее, но результаты могут быть менее точными.

В `vector` поддерживается два типа индексов:

* HNSW — организует векторы в структуру данных, которая позволяет быстро переходить от одного похожего вектора к другому и находить ближайших соседей без проверки всей таблицы. В основе этой структуры лежит многослойный граф.
* IVFFlat — разбивает все векторы на несколько групп (списков). Во время поиска проверяются не все группы, а только те, которые наиболее близки к искомому вектору. По сравнению с HNSW этот индекс строится быстрее и использует меньше памяти, но уступает по качеству и скорости поиска.

Настройки пулера соединений Odyssey, заданные на уровне пользователя, применяются только к этому пользователю. Если отдельная настройка не задана, используется соответствующая настройка уровня кластера.

Пользовательские настройки применяются к подключениям только при наличии подходящего [правила аутентификации](../../../managed-greenplum/concepts/user-authentication.md), в котором значение поля `user` совпадает с именем пользователя.

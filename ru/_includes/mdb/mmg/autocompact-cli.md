* `--autocompact` — автоматическая перепаковка для освобождения дискового пространства: `true` или `false`.
  
  Перепаковка выполняется во время [окна обслуживания](../../../storedoc/concepts/maintenance.md#maintenance-window) не чаще одного раза в неделю. В кластерах с одним хостом перепаковка не выполняется.

  Для перепаковки отбираются коллекции, у которых процент раздувания не меньше `--autocompact-bloat-percent`. Если предварительная оценка показывает, что их перепаковка позволит освободить не меньше `--autocompact-target-free-space`, то перепаковка выполняется.

* `--autocompact-bloat-percent` — минимальный процент раздувания коллекции, при котором коллекция отбирается для перепаковки. Значение по умолчанию — `10%`.
* `--autocompact-target-free-space` — минимальный суммарный объем дискового пространства в мегабайтах, который должен освободиться при перепаковке коллекций. Значение по умолчанию — `10` МБ.
  
* `--autocompact-compaction-type` — перепаковка хоста-мастера. Возможные значения:
  
  * `compaction-type-ignore-primary` — перепаковка хоста-мастера не выполняется. Используется по умолчанию.
  * `compaction-type-switch-primary` — перепаковка хоста-мастера выполняется.
    
    Перед перепаковкой хоста-мастера роль мастера переключается на другой хост.

* `enabled` — автоматическая перепаковка для освобождения дискового пространства: `true` или `false`.
* `bloatPercent` — минимальный процент раздувания коллекции, при котором коллекция отбирается для перепаковки. Значение по умолчанию — `10%`.
* `targetFreeSpace` — минимальный суммарный объем дискового пространства в мегабайтах, который должен освободиться при перепаковке коллекций. Значение по умолчанию — `10` МБ.
* `compactionType` — перепаковка хоста-мастера. Возможные значения:
    
  * `COMPACTION_TYPE_IGNORE_PRIMARY` — перепаковка хоста-мастера не выполняется. Используется по умолчанию.
  * `COMPACTION_TYPE_SWITCH_PRIMARY` — перепаковка хоста-мастера выполняется.
    
    Перед перепаковкой хоста-мастера роль мастера переключается на другой хост.

Перепаковка выполняется во время [окна обслуживания](../../../storedoc/concepts/maintenance.md#maintenance-window) не чаще одного раза в неделю. В кластерах с одним хостом перепаковка не выполняется.

Для перепаковки отбираются коллекции, у которых процент раздувания не меньше `bloatPercent`. Если предварительная оценка показывает, что их перепаковка позволит освободить не меньше `targetFreeSpace`, то перепаковка выполняется.

* `enabled` — включить автомасштабирование шардов: `true` или `false`. Значение по умолчанию — `false` (выключено).
* `minShards` — минимальное количество шардов в кластере. Значение по умолчанию и минимальное значение - `1`.
* `maxShards` — максимальное количество шардов в кластере. Значение по умолчанию и максимальное значение - `10`.
* `cpuThreshold` — пороги утилизации CPU (в процентах) для изменения количества шардов:
  * `downThreshold` – порог для уменьшения.
  * `upThreshold` — порог для увеличения.
* `memoryThreshold` — пороги использованной оперативной памяти (в процентах) для изменения количества шардов:
  * `downThreshold` – порог для уменьшения.
  * `upThreshold` — порог для увеличения.

* `enabled` — включить автомасштабирование шардов: `true` или `false`. Значение по умолчанию — `false` (выключено).
* `min_shards` — минимальное количество шардов в кластере. Значение по умолчанию - `1`.
* `max_shards` — максимальное количество шардов в кластере. Значение по умолчанию — `10`.
* `cpu_threshold` — пороги утилизации CPU (в процентах) для изменения количества шардов:
  * `down_threshold` – порог для уменьшения. Значение по умолчанию — `40`.
  * `up_threshold` — порог для увеличения. Значение по умолчанию — `80`.
* `memory_threshold` — пороги использованной оперативной памяти (в процентах) для изменения количества шардов:
  * `down_threshold` – порог для уменьшения. Значение по умолчанию — `40`.
  * `up_threshold` — порог для увеличения. Значение по умолчанию — `80`.

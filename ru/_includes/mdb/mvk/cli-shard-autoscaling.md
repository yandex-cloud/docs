* `enabled` — включить автомасштабирование шардов: `true` или `false`. Значение по умолчанию — `false` (выключено).
* `min-shards` — минимальное количество шардов в кластере.
* `max-shards` — максимальное количество шардов в кластере.
* `cpu-down-threshold` — порог утилизации CPU (в процентах) для уменьшения количества шардов. Значение по умолчанию — `40`.
* `cpu-up-threshold` — порог утилизации CPU (в процентах) для увеличения количества шардов. Значение по умолчанию — `80`.
* `memory-down-threshold` — порог использованной оперативной памяти (в процентах) для уменьшения количества шардов. Значение по умолчанию — `40`.
* `memory-up-threshold` — порог использованной оперативной памяти (в процентах) для увеличения количества шардов. Значение по умолчанию — `80`.

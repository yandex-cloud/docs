* **{{ ui-key.yacloud.clickhouse.cluster.field_cloud-storage-data-cache }}** — разрешает временное хранение в кластерном хранилище данных, запрошенных из объектного хранилища. В результате запрашиваемые из объектного хранилища холодные данные попадают на быстрые диски, где их обработка будет быстрее.

    По умолчанию кеширование данных включено.

* **{{ ui-key.yacloud.clickhouse.cluster.field_cloud-storage-data-cache-max-size }}** — определяет максимальный объем памяти (в байтах), выделяемый в кластерном хранилище для временного хранения данных, запрошенных из объектного хранилища. Если значение параметра не задано, максимальный объем памяти по умолчанию равен половине объема кластерного хранилища.

* **{{ ui-key.yacloud.clickhouse.cluster.field_cloud-storage-move-factor }}** — устанавливает минимальную долю свободного места в кластерном хранилище. Если доля свободного места меньше этого значения, данные переносятся в объектное хранилище. Минимальное значение — `0`, максимальное — `1`, по умолчанию — `0.01`.

    Куски данных для переноса выстраиваются в очередь от большего к меньшему, затем переносится такое количество кусков, при котором будет выполняться условие для указанной минимальной доли свободного места в кластерном хранилище.

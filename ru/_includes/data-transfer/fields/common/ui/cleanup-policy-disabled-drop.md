**Политика очистки** — выберите способ очистки данных в базе-приемнике перед переносом:

* `Drop` — полное удаление таблиц, участвующих в трансфере (вариант по умолчанию). Таблицы будут удалены при запуске трансфера, до начала поставки данных.

    Используйте эту опцию, чтобы при любой активации трансфера в базу-приемник всегда передавалась самая последняя версия схемы таблиц из источника.

* `Disabled` — не очищать. Новые данные будут объединены с данными в таблицах, которые уже существуют по заданным путям.

    Выберите эту опцию, если будет производиться только репликация без копирования данных.

* `Replace` — данные записываются во временные таблицы, существующие таблицы заменяются новыми после окончания поставки. Старые данные будут доступны до тех пор, пока трансфер не завершит работу. Если трансфер завершится с ошибкой, старые таблицы не будут удалены.

Вы можете создать [авторизованный ключ](../../iam/concepts/authorization/key.md) с неограниченным сроком жизни и постоянно аутентифицироваться в {{ yandex-cloud }} CLI с его помощью. Использование долгоживущего ключа менее безопасно, чем использование имперсонации.

Для получения авторизованного ключа требуется изначальная аутентификация в CLI аккаунтом Яндекса, федеративным аккаунтом или аккаунтом локального пользователя с помощью устройства с браузером и графическим интерфейсом. Дальнейшая работа с CLI может выполняться на сервере без графического интерфейса.

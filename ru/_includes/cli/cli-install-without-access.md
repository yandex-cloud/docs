Вы можете самостоятельно [скачать архив с исполняемым файлом CLI](../../cli/operations/install-cli.md#bin) и установить его.

Например, это может быть полезно, если на целевом устройстве нет доступа к `https://{{ s3-storage-host-cli }}`. Скачайте архив с исполняемым файлом CLI на другом устройстве, а затем перенесите архив на целевое устройство разрешенным в вашей организации способом.

Использование [имперсонации](../../iam/concepts/access-control/impersonation.md) является рекомендованным и наиболее безопасным способом аутентифицироваться в {{ yandex-cloud }} CLI. 

Данный способ не подходит для работы на сервере без графического интерфейса, поскольку требует изначальной аутентификации в {{ yandex-cloud }} CLI аккаунтом Яндекса, федеративным аккаунтом или аккаунтом локального пользователя с помощью браузера.

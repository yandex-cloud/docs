Режим управления целевыми группами настраивается в [сервисе](../../managed-kubernetes/concepts/service.md#type) {{ k8s }} — ресурсе `Service` типа `LoadBalancer`. По настройкам сервиса контроллер {{ managed-k8s-name }} автоматически создает сетевой балансировщик нагрузки [{{ network-load-balancer-name }}](../../network-load-balancer/concepts/index.md), который направляет трафик на узлы кластера.

По умолчанию балансировщики нагрузки используют общую целевую группу, включающую все узлы кластера. Балансировщик проверяет доступность всех узлов кластера, даже если поды приложения, к которому он направляет трафик, размещены только на нескольких из них.

Чтобы сократить число проверяемых узлов, для сервиса с политикой `externalTrafficPolicy: Local` можно настроить [режим управления целевыми группами](../../managed-kubernetes/concepts/load-balancer-target-groups.md) `v2`. Контроллер создаст для сетевого балансировщика отдельную целевую группу с узлами, на которых размещены поды приложения, и будет обновлять ее. Вы можете задать режим при создании сервиса или настроить в уже существующем.

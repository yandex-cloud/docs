{% note info %}

Информацию о пользовательских метках узлов {{ k8s-ca }} получает только после создания первого узла в группе. Поэтому если начальное и минимальное количество узлов равны `0`, автоскейлер будет знать только служебные метки.

Если в `nodeSelector` пода указана пользовательская метка, автоскейлер будет считать, что создание нового узла в группе не позволит разместить под. В результате появление такого пода не запустит создание узла, и под останется в статусе `Pending`.

Чтобы избежать этой ситуации, выберите один из способов:

* Задайте начальное количество узлов `1`, а минимальное — `0`. Автоскейлер сохранит информацию о пользовательских метках и позже удалит единственный узел, если нагрузки не будет.
* Используйте в `nodeSelector` только служебные метки, заранее известные автоскейлеру: `yandex.cloud/node-group-id: "<идентификатор_группы_узлов>"` для выбора группы узлов, `yandex.cloud/preemptible: "<true_или_false>"` для выбора прерываемых или непрерываемых узлов.

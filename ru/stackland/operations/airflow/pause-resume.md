# Приостановить или возобновить кластер {{ AF }}

Приостановка останавливает основные компоненты {{ AF }}. Конфигурация кластера, база метаданных, бакеты и учетные данные сохраняются.

Еженедельная [очистка метаданных старше 90 дней](../../concepts/components/airflow.md#metadata-retention) продолжается и во время приостановки.

{% note warning %}

Приостановка завершает работающие поды основных компонентов. Не используйте ее во время выполнения важных задач.

{% endnote %}

## Приостановка кластера {#pause}

1. Установите `spec.pause: true`:

    ```bash
    kubectl patch airflowcluster <имя_кластера> \
      -n <пространство_имен> \
      --type=merge \
      -p '{"spec":{"pause":true}}'
    ```

1. Дождитесь состояния `Paused`:

    ```bash
    kubectl get airflowcluster <имя_кластера> \
      -n <пространство_имен> \
      -w
    ```

## Возобновление кластера {#resume}

1. Установите `spec.pause: false`:

    ```bash
    kubectl patch airflowcluster <имя_кластера> \
      -n <пространство_имен> \
      --type=merge \
      -p '{"spec":{"pause":false}}'
    ```

1. Дождитесь состояния `Ready`:

    ```bash
    kubectl get airflowcluster <имя_кластера> \
      -n <пространство_имен> \
      -w
    ```

После возобновления планировщик снова обрабатывает DAG-файлы. Проверьте расписания и состояние задач в веб-интерфейсе.

# Изменить базу данных

После создания [база данных](create-database.md) [{{ CH }}](../../concepts/components/clickhouse.md) **изменить нельзя** ни одно поле `spec`.


## Через CLI {#cli}

1. Получите список баз данных в проекте: `kubectl get clickhousedatabase -n <название_проекта>`.
1. Просмотрите текущую конфигурацию: `kubectl get clickhousedatabase <название_ресурса> -n <название_проекта> -o yaml`.

Для изменения комментария или имени базы [удалите](delete-database.md) ресурс и создайте новый.

## Через консоль управления {#console}

1. Если вы еще не открыли проект, выберите проект.
1. В левом меню выберите **{{ CH }} Clusters**.
1. Выберите кластер.
1. Перейдите на вкладку **Базы данных**.
1. Нажмите на имя базы данных, чтобы открыть карточку. Чтобы посмотреть манифест ресурса, перейдите на вкладку **YAML**.

Редактирование комментария после создания недоступно. Чтобы задать другой комментарий, удалите базу данных и создайте новую с нужным значением поля **Комментарий**.

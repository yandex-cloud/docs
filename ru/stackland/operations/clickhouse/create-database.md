# Создать базу данных

Если у вас есть [кластер](create-cluster.md) [{{ CH }}](../../concepts/components/clickhouse.md), вы можете создать в нем базу данных с помощью кастомного ресурса `ClickhouseDatabase`.

Ресурс `ClickhouseDatabase` должен находиться в том же пространстве имен, что и кластер `ClickhouseCluster`. Имя ресурса должно соответствовать шаблону `<название_кластера>-<имя_базы>`.

## Через CLI {#cli}

1. Создайте файл ресурса `ClickhouseDatabase`. Например, с помощью команды `touch clickhousedatabase.yaml`.
1. Откройте файл и вставьте конфигурацию ниже:

    {% include notitle [YAML-файл](../../_includes/yamls/operations/clickhouse/clickhousedatabase.md) %}

    Где:

    * `spec.cluster` — название кластера `ClickhouseCluster`, в котором создается база.
    * `spec.name` — имя базы данных в {{ CH }}.
    * `spec.comment` — необязательный комментарий к базе данных. После создания изменить нельзя.

1. Примените манифест: `kubectl apply -f clickhousedatabase.yaml -n <название_проекта>`.

## Через консоль управления {#console}

1. Если вы еще не открыли проект, выберите проект.
1. В левом меню выберите **{{ CH }} Clusters**.
1. Выберите кластер.
1. Перейдите на вкладку **Базы данных**.
1. Нажмите **Создать**.
1. Заполните поля:

    * **Имя** — имя базы данных в {{ CH }}.
    * **Комментарий** — необязательное описание базы данных.

1. Нажмите **Создать**.

Готово, база данных появится в списке на вкладке **Базы данных**.

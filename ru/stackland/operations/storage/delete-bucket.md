# Удалить бакет

Если у вас есть [бакет](../../concepts/components/storage.md) и он пуст, вы можете его удалить.

{% note warning %}

Перед удалением бакета удалите все объекты, включая предыдущие версии и маркеры удаления, а также завершите или прервите составные загрузки. Бакет, в котором остались такие данные, удалить нельзя. Если версия защищена Object Lock, учитывайте режим и срок ее блокировки.

{% endnote %}

{% list tabs group=instructions %}

- CLI {#cli}

  1. Получите список бакетов в проекте:

      ```bash
      kubectl get bucket -n <название_проекта>
      ```

  1. Убедитесь, что бакет пуст. При необходимости удалите все объекты и их версии через S3 API. Для проверки версий, маркеров удаления и незавершенных составных загрузок используйте AWS CLI с [ключом доступа](create-accesskey.md):

      ```bash
      aws --endpoint-url=https://storage.sys.<домен_кластера> s3api list-object-versions \
        --bucket <название_бакета>
      aws --endpoint-url=https://storage.sys.<домен_кластера> s3api list-multipart-uploads \
        --bucket <название_бакета>
      ```

      Обычное удаление объекта из бакета с версионированием оставляет предыдущие версии и создает маркер удаления. Их также необходимо удалить перед удалением бакета.

  1. Удалите ресурс бакета:

      ```bash
      kubectl delete bucket <название_бакета> -n <название_проекта>
      ```

  1. Убедитесь, что бакет удален:

      ```bash
      kubectl get bucket -n <название_проекта>
      ```


- Консоль управления {#console}

  1. Если вы еще не открыли проект, выберите проект.
  1. В левом меню выберите **Object Storage**.
  1. Выберите бакет.
  1. Нажмите **Удалить бакет**.
  1. Подтвердите удаление.

{% endlist %}

Если не удалось проверить содержимое бакета из-за недоступности хранилища, удаление будет отклонено. Повторите запрос после восстановления доступа. Если ресурс перешел в состояние `DeletionFailed`, получите описание ошибки в поле `status.message`:

```bash
kubectl get bucket <название_бакета> -n <название_проекта> -o yaml
```

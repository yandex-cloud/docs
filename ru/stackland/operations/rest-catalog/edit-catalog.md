# Изменить настройки каталога

Вы можете изменить описание и защиту от удаления существующего каталога [{{ rest-catalog-name }}](../../concepts/components/rest-catalog.md). Имя каталога (`metadata.name`) и метки `spec.labels` после создания изменить нельзя.

## Через CLI {#cli}

1. Откройте ресурс `StacklandRestCatalog` для редактирования:

    ```bash
    kubectl edit stacklandrestcatalog <имя_каталога> -n <пространство_имен>
    ```

1. Измените нужные параметры:

    * `spec.description` — описание каталога длиной до 256 символов.
    * `spec.deletionProtection` — защита от удаления: `true` включает защиту, `false` отключает.

1. Сохраните изменения.

Также можно отредактировать локальный манифест и применить его повторно:

```bash
kubectl apply -f stacklandrestcatalog.yaml -n <пространство_имен>
```

Для изменения доступа к данным используйте инструкции [Назначить права на каталог](create-principal.md) и [Отозвать права на каталог](delete-principal.md).

## Через консоль управления {#console}

1. Откройте проект и выберите пространство имен каталога.
1. В левом меню выберите **REST Catalog** → **Каталоги**.
1. Откройте каталог и нажмите **Редактировать**.
1. Измените **Описание** или состояние переключателя **Защита от удаления**. Поля **Имя**, **Бакет** и **Метки** доступны только для чтения.
1. Нажмите **Сохранить**.

Чтобы изменить роль или область доступа пользователя либо группы, [отредактируйте назначение прав](create-principal.md#edit).

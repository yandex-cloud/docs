# Загрузить образы {{ ai-studio-name }}

Образы компонентов {{ model-gallery-name }} и {{ agent-atelier-name }} поставляются в отдельных наборах `model-gallery` и `agent-atelier` и не входят в пакет `full`.

Перед включением {{ ai-studio-name }} убедитесь, что образы доступны в реестре, который использует кластер. Эта инструкция описывает их загрузку в локальный реестр, например для изолированного кластера. Если нужные образы уже доступны кластеру, повторная загрузка не требуется.

## Перед началом работы {#before-you-begin}

1. Убедитесь, что сервисный аккаунт имеет доступ к лицензируемым образам {{ model-gallery-name }} и {{ agent-atelier-name }} в реестре контейнеров.
1. Скачайте утилиту `sladm` для версии вашего кластера, как описано в [Руководстве по установке](../../quickstart.md#download-files).
1. Подготовьте конфигурацию кластера и достаточно свободного места для образов, включая веса моделей.

## Загрузить образы из реестра {#download-images}

На машине с доступом в интернет выполните команду:

```bash
sladm pull \
  --image-bundle model-gallery,agent-atelier \
  --image-bundle-folder ai-studio-images \
  --config config/
```

Где:

* `--image-bundle` — имена наборов образов через запятую: `model-gallery` и `agent-atelier`.
* `--image-bundle-folder` — путь к папке для сохранения образов в формате OCI. Укажите путь к новой папке.
* `--config` — путь к конфигурации кластера.

## Загрузить образы в локальный реестр {#push-images}

Если кластер изолирован от интернета, перенесите папку `ai-studio-images` и бинарный файл `sladm` на машину с доступом к кластеру.

{% note info %}

Команда `sladm push` может выполняться продолжительное время из-за большого размера образов. Дождитесь ее завершения, прежде чем включать компоненты {{ ai-studio-name }}.

{% endnote %}

На машине с доступом к кластеру выполните команду:

```bash
sladm push \
  --local-registry \
  --kubeconfig=<путь_к_kubeconfig> \
  --image-bundle-folder ai-studio-images
```

Где:

* `--local-registry` — указывает на использование локального реестра кластера.
* `--kubeconfig` — путь к файлу kubeconfig для доступа к кластеру.
* `--image-bundle-folder` — путь к папке с загруженными образами.

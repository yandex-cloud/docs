# Удалить каталог {{ mtr-name }}

Если у вас есть [каталог](../../concepts/components/trino.md#catalogs) в кластере [{{ TR }}](../../concepts/components/trino.md), вы можете удалить его. После удаления каталога источник данных перестанет быть доступен в SQL-запросах кластера.

{% note info %}

При удалении каталога {{ mtr-name }} пересоздает кластер. На время применения новой конфигурации кластер переходит в состояние `Updating`, активные запросы прерываются. Подробнее см. в разделе [Обновление кластера](../../concepts/components/trino.md#cluster-update).

{% endnote %}

{% list tabs group=instructions %}

- CLI {#cli}

  1. Найдите имя нужного каталога в списке каталогов: `kubectl get TrinoCatalog -n <пространство_имен>`.
  1. Удалите ресурс каталога: `kubectl delete TrinoCatalog <имя_каталога> -n <пространство_имен>`.


- Консоль управления {#console}

  1. Если вы еще не открыли проект, выберите проект.
  1. Выберите пространство имен, в котором создан кластер.
  1. В левом меню выберите **Trino** → **Кластеры**.
  1. Выберите кластер и откройте вкладку **Каталоги**.
  1. Выберите каталог.
  1. Нажмите **Удалить**.
  1. В окне подтверждения введите имя каталога и нажмите **Удалить**.

{% endlist %}

Пока ресурс удаляется, в списке каталогов отображается состояние `Deleting`. После полного удаления строка исчезает из таблицы.

Связанные Secret с учетными данными оператор удаляет вместе с каталогом, если они были созданы через консоль управления и не используются другими ресурсами.

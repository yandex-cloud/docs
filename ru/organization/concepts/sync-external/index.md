# Синхронизация пользователей и групп с внешними службами каталогов


Если для управления пользователями ваша компания использует службу каталогов и вы хотите организовать для ваших пользователей доступ к {{ yandex-cloud }}, вам не нужно создавать учетные записи для них вручную. Вместо этого вы можете [синхронизировать](../../operations/sync-external/index.md) с {{ org-full-name }} пользователей и группы из каталога вашей компании.

{% include [ad-sync-userpoolonly-notice](../../../_includes/organization/external-sync/ad-sync-userpoolonly-notice.md) %}

Синхронизация пользователей и групп выполняется специальной утилитой — _агентом синхронизации {{ ad-sync-agent }}_. Агент синхронизации может быть запущен на любом сервере под управлением ОС [Linux](https://ru.wikipedia.org/wiki/Linux) или [Windows](https://ru.wikipedia.org/wiki/Windows). При этом схема синхронизации, синхронизируемые атрибуты и настройки агента зависят от типа службы каталогов и операционной системы хоста, на котором запущен агент.

{{ org-full-name }} поддерживает синхронизацию со следующими типами служб каталогов:

* [{{ microsoft-idp.ad-full }}](./ad-sync.md);
* [LDAP-совместимые каталоги](./ldap-sync.md).

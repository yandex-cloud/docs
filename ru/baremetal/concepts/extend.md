# BareMetal Extend

*BareMetal Extend* — это линейка готовых инфраструктурных продуктов на базе [серверов](./servers.md) {{ baremetal-full-name }}. Продукты объединяют выделенные физические ресурсы с программными платформами и средствами управления {{ yandex-cloud }}, что позволяет значительно упростить и ускорить развертывание инфраструктуры.

## Продукты {#products}

На данный момент в BareMetal Extend доступны следующие продукты:

* [{{ baremetal-extend-virtualization-name }}](./extend/virtualization.md) — коммерческая платформа виртуализации для создания виртуальных машин и распределенного хранилища данных на кластере серверов {{ baremetal-name }}.
* [{{ baremetal-extend-stackland-name }}](./extend/stackland.md) — платформа контейнеризации с интегрированными PaaS-сервисами {{ yandex-cloud }}, развернутая на серверах {{ baremetal-name }}.
* [{{ baremetal-extend-managed-k8s-name }}](./extend/managed-kubernetes.md) — группы рабочих узлов {{ managed-k8s-name }} на выделенных физических серверах {{ baremetal-name }}.

Линейка BareMetal Extend будет расширяться. Доступность продуктов, поддерживаемые конфигурации и условия предоставления могут различаться. Если создание ресурса недоступно, отправьте заявку из соответствующего подраздела **{{ ui-key.yacloud.baremetal.label_extend }}**.

# {{ baremetal-extend-virtualization-name }}

*{{ baremetal-extend-virtualization-name }}* — платформа коммерческой виртуализации в линейке BareMetal Extend для создания виртуальных машин и распределенного хранилища данных. Платформа автоматически устанавливается и настраивается индивидуально для каждого пользователя на физическом кластере из серверов {{ baremetal-name }}.

Состав платформы, вычислительные ресурсы, хранилище и требования к публичным и приватным сетям прорабатываются совместно с архитекторами {{ yandex-cloud }} при обработке заявки. Платформа разворачивается и поддерживается в партнерстве с K2 Cloud.

# BareMetal API, gRPC: BootImageService

A set of methods for managing BootImage resources.

## Methods

#|
||Method | Description ||
|| [GetBootImage](getBootImage.md) | Returns the specific BootImage resource. ||
|| [ListBootImages](listBootImages.md) | Retrieves the list of BootImage resources in the specified folder. ||
|| [CreateBootImage](createBootImage.md) | Creates a boot image in the specified folder. ||
|| [UpdateBootImage](updateBootImage.md) | Updates the specified boot image. ||
|| [DeleteBootImage](deleteBootImage.md) | Deletes the specified boot image. ||
|| [ListBootImageOperations](listBootImageOperations.md) | Lists operations for the specified boot image. ||
|#

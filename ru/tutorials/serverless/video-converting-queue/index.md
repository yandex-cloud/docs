Вы можете создать инфраструктуру для видеоконвертера с FFmpeg и {{ message-queue-full-name }} с помощью одного из инструментов:

* [Консоль управления](console.md) — создайте инфраструктуру в пошаговом режиме с помощью консоли управления {{ yandex-cloud }}.
* [{{ TF }}](terraform.md) — упростите создание ресурсов и управление ими, используя подход «инфраструктура как код» (IaC). Скачайте пример конфигурации {{ TF }} из репозитория GitHub, а затем разверните инфраструктуру с помощью [{{ TF }}-провайдера {{ yandex-cloud }}]({{ tf-docs-link }}).

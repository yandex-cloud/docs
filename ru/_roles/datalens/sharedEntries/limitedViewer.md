Роль `datalens.sharedEntries.limitedViewer` назначается на общий объект и позволяет просматривать [чарты]({{ link-datalens-docs }}/concepts/chart/) и [дашборды]({{ link-datalens-docs }}/concepts/dashboard), которые используют его, без прямого доступа к самому общему объекту. В интерфейсе {{ datalens-name }} эта роль называется `Ограниченный просмотр`. Рекомендуем выдавать эту роль только через интерфейс {{ datalens-name }}.

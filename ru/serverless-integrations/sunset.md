# Закрытие сервиса {{ si-full-name }}

{% note warning %}

Сервис {{ si-full-name }} прекращает работу. На этой странице описаны сроки, порядок закрытия и рекомендации по миграции.

{% endnote %}

## Что происходит {#what-happens}

Сервис {{ si-full-name }}, который объединял несколько функциональностей, прекращает работу. Сами возможности при этом сохраняются в других сервисах платформы:

* {{ sw-full-name }} переезжает в [{{ ai-studio-name }}]({{ link-docs-ai }}ai-studio/concepts/workflows/workflow). Все рабочие процессы и логика работы с ними сохраняются.

* {{ er-name }} прекращает работу. Вместо него можно использовать триггеры для функций {{ sf-name }}, контейнеров {{ serverless-containers-name }}, API-шлюзов {{ api-gw-name }} и рабочих процессов {{ sw-name }}.

* {{ api-gw-full-name }} продолжит работать как отдельный сервис.

## Ключевые даты {#key-dates}

Закрытие {{ si-full-name }} пройдет в три этапа:

* **3 сентября 2026** — {{ sw-name }} перестает поддерживаться в интерфейсе {{ yandex-cloud }}. Для создания рабочих процессов и управления ими используйте [интерфейс {{ ai-studio-name }}]({{ link-console-ai }}/link//workflows).

* **15 сентября 2026** — {{ er-name }} переходит в режим read-only. Создание новых шин, коннекторов и правил станет недоступно.

* **8 октября 2026** — сервис {{ si-full-name }} полностью прекращает работу. Доступ к интерфейсу сервиса будет закрыт для всех пользователей.

## Что будет с вашими данными {#data}

Ваши данные (шины, коннекторы, правила) не будут потеряны. После закрытия сервиса резервные копии ваших данных будут храниться до 31 января 2027 года — их можно будет запросить через [техническую поддержку]({{ link-console-support }}).

Все рабочие процессы будут автоматически перенесены в {{ ai-studio-name }}.

## Миграция {#migration}

В качестве альтернативы шинам {{ er-name }} можно использовать триггеры. Некоторые шины будут перенесены автоматически, некоторые — потребуется перенести самостоятельно.

Мы подготовили руководство, которое поможет при миграции: [{#T}](tutorials/eventrouter-migration.md).

{% note warning %}

Мы рекомендуем перенести все шины самостоятельно. Автоматический перенос не гарантирует полную идентичность функционирования системы после миграции.

{% endnote %}

## Если у вас есть вопросы {#support}

Если у вас остались вопросы по закрытию сервиса:

* Обратитесь в [техническую поддержку]({{ link-console-support }}).
* Свяжитесь с вашим аккаунт-менеджером.

Спасибо, что пользовались {{ si-full-name }}.

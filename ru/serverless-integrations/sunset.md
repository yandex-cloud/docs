# Cервис {{ si-full-name }} закрыт

{% note warning %}

Сервис {{ si-full-name }} прекратил работу 8 октября 2026 года.

{% endnote %}

## Что произошло {#what-happens}

Сервис {{ si-full-name }}, который объединял несколько функциональностей, прекратил работу. Сами возможности при этом сохранились в других сервисах платформы:

* {{ sw-full-name }} переехал в [{{ ai-studio-name }}]({{ link-docs-ai }}ai-studio/concepts/workflows/workflow). Все рабочие процессы и логика работы с ними сохранились.

* {{ er-name }} прекратил работу. Вместо него можно использовать триггеры для функций {{ sf-name }}, контейнеров {{ serverless-containers-name }}, API-шлюзов {{ api-gw-name }} и рабочих процессов {{ sw-name }}.

* {{ api-gw-full-name }} продолжает работать как отдельный сервис.

## Что будет с вашими данными {#data}

Резервные копии ваших данных (шины, коннекторы, правила) будут храниться до 31 января 2027 года — их можно запросить через [техническую поддержку]({{ link-console-support }}).

## Миграция {#migration}

В качестве альтернативы шинам {{ er-name }} можно использовать триггеры. Некоторые шины были перенесены автоматически, некоторые — нужно перенести самостоятельно.

Мы подготовили руководство, которое поможет при миграции: [{#T}](tutorials/eventrouter-migration.md).

{% note warning %}

Мы рекомендуем перенести все шины самостоятельно. Автоматический перенос не гарантирует полную идентичность функционирования системы после миграции.

{% endnote %}

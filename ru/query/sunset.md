# Закрытие сервиса {{ yq-full-name }}

## Отключение сервиса {#what-happens}

Сервис {{ yq-full-name }} будет отключен 1 декабря 2026 года и станет недоступен. После отключения выполнять запросы, создавать и изменять сущности сервиса будет нельзя.

## Что с вашими данными {#data}

Исходные данные остаются в подключенных источниках. {{ yq-full-name }} читал данные напрямую из этих источников и не хранил их. Соединения, привязки к данным, сохраненные запросы и история запросов автоматически не переносятся.

## Миграция {#migration}

В качестве альтернативы используйте {{ ydb-full-name }} или работайте с данными в {{ objstorage-name }} напрямую.

Мы подготовили руководство, которое поможет при миграции: [{#T}](tutorials/migration.md).

## Если у вас есть вопросы {#support}

Если у вас остались вопросы по закрытию сервиса:

* Обратитесь в [техническую поддержку]({{ link-console-support }}).
* Свяжитесь с вашим аккаунт-менеджером.

Спасибо, что пользовались {{ yq-full-name }}.

# Закрытие сервиса {{ yq-full-name }}

{% note warning %}

Сервис {{ yq-full-name }} прекращает работу. На этой странице описаны сроки, порядок закрытия и рекомендации по миграции.

{% endnote %}

## Что происходит {#what-happens}

Мы приняли решение закрыть сервис {{ yq-full-name }}. Понимаем, что это изменение может затронуть ваши рабочие процессы, и постараемся сделать переход комфортным.

## Ключевые даты {#key-dates}

Закрытие сервиса пройдет в три этапа:

* **13 октября 2026** — прекращение новых продаж сервиса {{ yq-full-name }}. Клиенты, подключившие сервис ранее, смогут пользоваться им до 10 ноября 2026 года.

* **10 ноября 2026** — сервис переходит в режим read-only. Создание новых сущностей сервиса станет недоступно. Текущие пользователи {{ yq-full-name }} смогут выполнять запросы, но не смогут создавать и изменять сущности сервиса.

* **14 декабря 2026** — сервис полностью прекращает работу. Доступ к интерфейсу сервиса будет закрыт для всех пользователей.

## Что будет с вашими данными {#data}

Исходные данные не будут удалены. {{ yq-full-name }} читает данные напрямую из подключенных источников и не хранит их, поэтому после закрытия сервиса они останутся в источниках. Соединения, привязки к данным, сохраненные запросы и история запросов автоматически не переносятся.

## Миграция {#migration}

В качестве альтернативы используйте {{ ydb-full-name }} или работайте с данными в {{ objstorage-name }} напрямую.

Мы подготовили руководство, которое поможет при миграции: [{#T}](tutorials/migration.md).

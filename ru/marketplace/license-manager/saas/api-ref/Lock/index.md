A set of methods for managing subscription locks.

## Methods

#|
||Method | Description ||
|| [Get](get.md) | Returns the specified subscription lock. ||
|| [GetByResourceID](getByResourceID.md) | Returns the subscription lock for given resource and subscription. ||

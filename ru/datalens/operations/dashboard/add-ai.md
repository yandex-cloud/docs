# Добавление виджета с инсайтом на дашборд в {{ datalens-full-name }}

Для добавления виджета с инсайтом от Нейроаналитика на дашборд выполните следующее:


{% include [datalens-workbooks-collections-select-note](../../../_includes/datalens/operations/datalens-workbooks-collections-select-note.md) %}


1. На панели слева нажмите ![image](../../../_assets/console-icons/layout-cells-large.svg) **Дашборды** и выберите нужный дашборд.
1. В верхней части страницы нажмите кнопку **Редактировать**.
1. На панели в нижней части страницы зажмите ![image](../../../_assets/console-icons/sparkles-fill.svg) **Инсайт** и перетащите его в нужную область.

   ![image](../../../_assets/datalens/operations/widget-select-ai.png =687x90)

1. Укажите основные настройки виджета:

   * **Чарты для анализа**. Нажмите кнопку ![image](../../../_assets/console-icons/plus.svg) **Добавить** и выберите чарт из списка чартов на текущей вкладке дашборда. В одном инсайте можно указать до пяти чартов с текущей вкладки дашборда.  С помощью Нейроаналитика можно обнаружить взаимосвязи в данных, которые не видны на отдельных графиках.
   * **Заголовок**. Задает имя виджета (по умолчанию — название выбранного чарта). Отображается в верхней части виджета, если опция **Заголовок** в блоке **Внешний вид** включена (по умолчанию).
   * **Промпт**. Введите вопрос, на который будет отвечать Нейроаналитик.


   Укажите настройки внешнего вида виджета:

   * **Заголовок**. Опция задает отображение заголовка инсайта.
   * **Действия с инсайтом**. Опция задает отображение внизу инсайта панели действий:

     * ![image](../../../_assets/console-icons/copy.svg) **Копировать**. Копирует содержимое инсайта в буфер.
     * ![image](../../../_assets/console-icons/arrow-rotate-left.svg) **Ещё раз**. Обновляет ответ инсайта.
     * ![image](../../../_assets/console-icons/thumbs-up.svg) **Хороший ответ**. Положительно оценивает ответ инсайта.
     * ![image](../../../_assets/console-icons/thumbs-down.svg) **Плохой ответ**. Отрицательно оценивает ответ инсайта.

   * **Фон**. Задает цвет фона и прозрачность виджета отдельно для светлой и темной темы.
   * **Скругление**. Задает скругление виджета.

   {% cut "Пример настроек виджета с инсайтом" %}

      
   ![image](../../../_assets/datalens/dashboard/ai-settings.png =452x432)
   

   {% endcut %}

1. Нажмите кнопку **Добавить**. Виджет отобразится на дашборде.
1. В правом верхнем углу дашборда нажмите кнопку **Сохранить**. Нейроаналитик проанализирует указанный чарт и сформирует выводы на основе данных и пользовательского промпта. Результат в **Инсайте** будет обновляться каждый раз при открытии дашборда. Если в чарте, с которым связан виджет **Инсайт**, изменятся данные, в верхней части виджета появится кнопка ![image](../../../_assets/console-icons/arrow-rotate-left.svg) **Обновить**.

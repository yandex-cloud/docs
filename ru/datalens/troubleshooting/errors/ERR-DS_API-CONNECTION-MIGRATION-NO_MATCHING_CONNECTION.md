# [{{ datalens-full-name }}] Не удалось подобрать подключение {{ connection-manager-name }}

`ERR.DS_API.CONNECTION.MIGRATION.NO_MATCHING_CONNECTION`

Не удалось подобрать подключение {{ connection-manager-name }}. Для кластера нет доступных вам подключений с тем пользователем базы данных, который указан в подключении.

Чтобы исправить ошибку, создайте подключение для этого пользователя или укажите в подключении одного из пользователей, для которых уже есть подключения, и повторите миграцию.

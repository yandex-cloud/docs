# [{{ datalens-full-name }}] Invalid parameter value

`ERR.DS_API.SOURCE_CONFIG.PARAMETER_VALUE_INVALID`

Переданное значение параметра или значение по умолчанию не соответствует его типу или заданному ограничению. 

Чтобы устранить ошибку, исправьте значение в датасете, чарте или селекторе и сверьте тип и допустимые значения параметра.

# [{{ datalens-full-name }}] Number out of range

`ERR.DS_API.DB.NUMBER_OUT_OF_RANGE`

Числовое значение вышло за допустимый диапазон при обработке запроса.

Чтобы исправить ошибку:

1. Найдите значение и операцию по подробному сообщению БД.
1. Исправьте данные или преобразование либо используйте подходящий числовой тип.

# [{{ datalens-full-name }}] {{ CH }} could not parse the data in the specified source

`ERR.DS_API.DB.CH.INCORRECT_DATA`

Ошибка возникает, когда {{ CH }} не может разобрать данные источника.

Чтобы исправить ошибку, проверьте, что фактические значения, их формат и типы соответствуют схеме таблицы. Исправьте некорректные данные или схему.


Если источник выглядит корректно, обратитесь к администратору {{ CH }} или в [техническую поддержку]({{ link-console-support }}) {{ yandex-cloud }}. В сообщении опишите, когда возникает ошибка.

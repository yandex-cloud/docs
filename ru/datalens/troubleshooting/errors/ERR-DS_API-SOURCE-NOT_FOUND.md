# [{{ datalens-full-name }}] Data source not found

`ERR.DS_API.SOURCE.NOT_FOUND`

Датасет ссылается на таблицу, которой нет среди его добавленных источников.

Чтобы исправить ошибку:

1. Обновите страницу.
1. Проверьте, не был ли источник удален или заменен.
1. Восстановите источник или выберите существующий источник в датасете.


Если ошибка сохраняется после исправления связей, обратитесь в [техническую поддержку]({{ link-console-support }}) {{ yandex-cloud }}. В сообщении опишите, когда возникает ошибка.

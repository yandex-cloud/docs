# [{{ datalens-full-name }}] Internal Server Error

`ERR.DS_API.SOURCE_ACCESS_DENIED`

{{ datalens-name }} получил отказ от источника по причине отсутствия прав.

Проверьте права на источник, права учетной записи или сервисного аккаунта.


Если доступ есть, но ошибка повторяется, обратитесь в [техническую поддержку]({{ link-console-support }}) {{ yandex-cloud }}. В сообщении опишите, когда возникает ошибка.

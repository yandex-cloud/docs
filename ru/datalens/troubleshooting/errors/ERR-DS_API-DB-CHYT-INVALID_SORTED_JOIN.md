# [{{ datalens-full-name }}] Invalid sorted JOIN

`ERR.DS_API.DB.CHYT.INVALID_SORTED_JOIN`

Ошибка сортировки при пересечении таблиц в CHYT.

Для сортировки при пересечении таблиц (JOIN) обе таблицы должны быть отсортированы, а условие `ON`/`USING` — сопоставлять простыми равенствами одинаковые префиксы ключевых колонок.

Чтобы исправить ошибку, попробуйте выполнить действия:

* Исправьте сортировку таблиц или условие соединения.
* Для SQL-запроса выберите другую стратегию соединения, например `GLOBAL JOIN` или подзапрос.
* Для датасета подготовьте промежуточную таблицу или SQL-источник.

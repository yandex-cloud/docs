# [{{ datalens-full-name }}] Unknown function

`ERR.DS_API.DB.INVALID_FUNCTION`

База данных не распознала вызванную функцию.

Чтобы исправить ошибку, проверьте название функции, ее наличие в используемой БД, число и типы аргументов.


Если ошибка возникает в автоматически сформированном запросе, обратитесь в [техническую поддержку]({{ link-console-support }}) {{ yandex-cloud }}. В сообщении приложите подробности ошибки.

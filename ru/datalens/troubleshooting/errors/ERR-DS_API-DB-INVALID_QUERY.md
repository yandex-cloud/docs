# [{{ datalens-full-name }}] Invalid SQL query to the database

`ERR.DS_API.DB.INVALID_QUERY`

Источник данных отклонил SQL-запрос, например из-за синтаксиса, неподдерживаемой конструкции или несовместимости с диалектом БД.

Чтобы исправить ошибку, проверьте текст запроса и подробное сообщение БД и исправьте запрос.


Если ошибка возникает в автоматически сформированном запросе, обратитесь в [техническую поддержку]({{ link-console-support }}) {{ yandex-cloud }}. В сообщении приложите подробности ошибки.

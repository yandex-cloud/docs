# [{{ datalens-full-name }}] Invalid template

`ERR.DS_API.SOURCE_CONFIG.TEMPLATE_INVALID`

При подстановке параметров в шаблон источника не найдено значение для указанного ключа.

Чтобы устранить ошибку:

1. Проверьте имена параметров в выражениях `{{...}}`, их наличие в датасете и значения по умолчанию.
1. Исправьте шаблон или добавьте отсутствующий параметр.

# Воронка ![](../../_assets/datalens/funnel.svg) в {{ datalens-full-name }}

Воронка показывает последовательное уменьшение значений показателя по этапам. Каждый этап воронки представляет собой сегмент, ширина которого соответствует значению показателя.

Подходит для анализа процессов, где данные последовательно проходят через несколько этапов. Например, для анализа воронки продаж от просмотра товара до покупки или для анализа конверсии пользователей на разных этапах регистрации.

## Секции в визарде {#wizard-sections}

Секция<br/> в визарде | Описание
----- | ----
Категории | Измерение. Может быть указано только одно поле. По нему производится группировка данных.
Показатели | Показатель. Может быть указано одно поле или несколько полей. При добавлении в секцию более одного показателя в секции **Категории** появится измерение [Measure Names](../concepts/chart/measure-values.md).
Цвет | Измерение или показатель. Может быть указано измерение из секции **Категории** или любой показатель. Влияет на цвет сегментов воронки.
Сортировка | Измерение или показатель. Влияет на порядок отображения этапов воронки. Направление сортировки отмечено значком рядом с полем: по возрастанию ![image](../../_assets/console-icons/bars-ascending-align-left.svg) или по убыванию ![image](../../_assets/console-icons/bars-descending-align-left.svg). Чтобы изменить направление сортировки, нажмите значок.
Подписи | Показатель. Может быть указано одно поле или несколько полей. Отображает значения показателя на сегментах воронки. Если нужно добавить абсолютное значение и проценты по каждому сегменту — можно добавить несколько полей [Measure Values](../concepts/chart/measure-values.md) и указать в них соответствующий формат. Поддерживается использование [функций разметки](../function-ref/markup-functions.md).
Фильтры | Измерение или показатель. Используется в качестве фильтра.

## Настройки чарта {#chart-settings}

В настройках чарта можно выбрать:

* **Этап для расчёта процентов** — какие проценты отображаются в подсказке чарта:
  * от начального этапа (по умолчанию);
  * от предыдущего этапа.
* **Расстояние между сегментами** — размер отступа между сегментами воронки.
* **Форма** — форма сегментов воронки:
  * прямоугольник (по умолчанию);
  * трапеция.

## Рекомендации {#recommendations}

* **Этапы воронки.** Располагайте этапы воронки в логическом порядке — от первого к последнему. Для этого используйте секцию **Сортировка**.
* **Количество этапов.** Не используйте слишком много этапов в одной воронке — оптимальное количество от 3 до 7. Большее количество этапов делает визуализацию сложной для восприятия.
* **Цвета.** Используйте секцию **Цвета** для выделения важных этапов или группировки связанных этапов.
* **Подписи.** Добавляйте подписи с абсолютными значениями и процентами для лучшего понимания данных. Для этого перетащите в секцию **Подписи** несколько полей [Measure Values](../concepts/chart/measure-values.md) с разными форматами.

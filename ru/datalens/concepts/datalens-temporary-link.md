# Публикация по временной ссылке

С помощью временной ссылки можно открыть публичный доступ к дашборду в [воркбуке](../workbooks-collections/index.md) на ограниченное время. Создать такую ссылку может пользователь с [ролью](../security/roles.md#datalens-workbooks-admin) `Администрирование` на воркбук.

Пока ссылка активна, любой пользователь сможет перейти по ней и посмотреть дашборд без авторизации. При этом пользователь не сможет посмотреть настройки чарта, подключения, датасета или выполнить произвольный SQL-запрос.

{% include [share-note](../../_includes/datalens/datalens-share-note.md) %}

[Правила](./datalens-public.md#rules) предоставления доступа к дашборду по временной ссылке те же, что и при публикации объектов. Когда срок действия ссылки закончится, по ней уже не получится попасть на дашборд.

Пользователь с [ролью](../security/roles.md#datalens-workbooks-admin) `Администрирование` на воркбук, в котором создана временная ссылка, может [отозвать](#link-disable) ссылку до окончания ее срока действия.

Просмотры дашбордов по временной ссылке учитываются в тарификации, так как расходуют лимит на количество запросов из [непублично встроенных объектов](../pricing.md#embeds).

## Создать временную ссылку {#create-link}

1. На панели слева выберите ![collections](../../_assets/console-icons/rectangles-4.svg) **Коллекции и воркбуки**.
1. Откройте нужный воркбук и выберите дашборд.
1. В верхней части объекта нажмите значок ![image](../../_assets/console-icons/ellipsis.svg) и выберите ![image](../../_assets/console-icons/arrow-shape-turn-up-right.svg) **Поделиться**.
1. В открывшемся окне перейдите на вкладку ![image](../../_assets/console-icons/globe.svg) **Публично**.
1. В блоке **Временная ссылка** нажмите ![image](../../_assets/console-icons/plus.svg) **Создать**. В открывшемся окне:

   1. Выберите из раскрывающегося списка время, в течение которого будет активна временная ссылка: `1 час`, `2 часа`, `3 часа`, `5 часов`, `10 часов` или `24 часа`. Максимальный срок действия временной ссылки — `24 часа`. Значение по умолчанию — `10 часов`.
   1. Нажмите кнопку **Создать**. Временная ссылка будет создана и скопирована в буфер обмена.

      {% note info %}

      * По временной ссылке дашборд и все связанные объекты будут доступны любому пользователю в интернете.
      * По ссылке из адресной строки браузера дашборд и связанные с ним объекты доступны только авторизованным пользователям с учетом прав доступа к ним.

      {% endnote %}

## Отозвать временную ссылку {#link-disable}

Пользователь с [ролью](../security/roles.md#datalens-workbooks-admin) `Администрирование` на воркбук, в котором создана временная ссылка, может отозвать ссылку до окончания ее срока действия.

1. Откройте нужный воркбук и выберите дашборд.
1. В верхней части объекта нажмите значок ![image](../../_assets/console-icons/ellipsis.svg) и выберите ![image](../../_assets/console-icons/arrow-shape-turn-up-right.svg) **Поделиться**.
1. В открывшемся окне перейдите на вкладку ![image](../../_assets/console-icons/globe.svg) **Публично**.
1. Если для текущего дашборда активна хотя бы одна временная ссылка, в блоке **Временная ссылка** доступна кнопка, на которой отображается, сколько ссылок активно и общее их количество. Нажмите кнопку. В открывшемся окне:

   1. Напротив нужной ссылки нажмите ![image](../../_assets/console-icons/trash-bin.svg) (Отозвать). Временная ссылка будет отозвана, и ни один пользователь не сможет перейти по ней и посмотреть дашборд.
   1. Нажмите кнопку **Закрыть**.

      {% endcut %}

## Скопировать временную ссылку {#link-copy}

Пользователь с [ролью](../security/roles.md#datalens-workbooks-admin) `Администрирование` на воркбук, в котором создана временная ссылка, может скопировать ссылку и передать ее другому пользователю.

1. Откройте нужный воркбук и выберите дашборд.
1. В верхней части объекта нажмите значок ![image](../../_assets/console-icons/ellipsis.svg) и выберите ![image](../../_assets/console-icons/arrow-shape-turn-up-right.svg) **Поделиться**.
1. В открывшемся окне перейдите на вкладку ![image](../../_assets/console-icons/globe.svg) **Публично**.
1. Если для текущего дашборда активна хотя бы одна временная ссылка, в блоке **Временная ссылка** доступна кнопка, на которой отображается, сколько ссылок активно и общее их количество. Нажмите на кнопку. В открывшемся окне:

   1. Напротив нужной ссылки нажмите ![image](../../_assets/console-icons/link.svg) (Скопировать ссылку). Временная ссылка будет скопирована в буфер обмена.
   1. Нажмите кнопку **Закрыть**.

      {% note info %}

      * По временной ссылке дашборд и все связанные объекты будут доступны любому пользователю в интернете.
      * По ссылке из адресной строки браузера дашборд и связанные с ним объекты доступны только авторизованным пользователям с учетом прав доступа к ним.

      {% endnote %}

      {% cut "Временные ссылки" %}
   
      ![image](../../_assets/datalens/concepts/datalens-public/temporary-link-list.png =465x300)

      {% endcut %}

    Если активных ссылок нет, [создайте](#create-link) новую.

# Настройка подключения для работы в Редакторе SQL {{ datalens-platform-full-name }}

Чтобы работать с Редактором SQL в {{ datalens-platform-short-name }}, настройте подключение к базе данных.

Для работы с Редактором SQL в настройках подключения включите опцию **Уровень доступа SQL-запросов** → **SQL на чтение**. Опцию можно включить при создании или изменении подключения.

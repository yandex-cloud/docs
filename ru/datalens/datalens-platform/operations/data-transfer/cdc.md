# Создание поставки данных в режиме CDC

{% include [cdc-pg](../../../../_includes/dlp/transfer/cdc-pg.md) %}

[CDC (непрерывная передача изменений)](../../concepts/data-transfer/index.md#cdc) — это отслеживание изменений в базе данных и передача этих изменений в режиме почти реального времени. Используйте этот режим, когда важно поддерживать актуальность данных с минимальной задержкой.

Чтобы создать поставку данных в режиме CDC:

1. Перейдите в раздел ![image](../../../../_assets/console-icons/database-arrow-right.svg) **Поставки данных** и нажмите ![image](../../../../_assets/console-icons/plus.svg) **Создать поставку данных**.
1. На шаге **Выбор подключения** укажите [подключение-источник](../../../concepts/connection/index.md) PostgreSQL и перейдите к шагу **Настройка поставки данных**.
1. В переключателе типа поставки выберите **CDC** — непрерывная передача изменений.
1. Задайте основные параметры поставки:
   * В поле **Название поставки** введите имя поставки.
   * (Опционально) В поле **Описание** укажите, для чего нужна поставка.
   * В поле **База данных** укажите имя базы данных в выбранном подключении-источнике.
   * В поле **Коллекция** выберите коллекцию из списка.
   * (Опционально) Нажмите **Добавить метку**, чтобы добавить метку для поиска и фильтрации поставки.
1. В блоке **Назначение** укажите, куда переносить данные:
   * В поле **REST-каталог** выберите [REST-каталог](../../concepts/rest-catalog/index.md).
   * В поле **Пространство имён** выберите пространство имен внутри выбранного каталога. Поле становится доступным только после выбора REST-каталога. Если подходящего пространства имен нет, нажмите **Создать** и [создайте новое](../rest-catalog/create-namespace.md).
1. В блоке **Параметры поставки** в поле **Таблица для поставки** укажите таблицу источника, изменения которой нужно передавать.
1. В блоке **Настройки CDC** задайте параметры:
   * В поле **Максимальный размер WAL** укажите максимальный размер журнала предзаписи (Write-Ahead Log) и выберите единицу измерения. По умолчанию указано **50 ГБ**.
   * (Опционально) Включите **Объединять унаследованные таблицы**, если требуется объединять унаследованные таблицы {{ PG }} в родительскую таблицу при репликации.
1. Нажмите **Создать поставку**.

{% note info %}

Для запуска поставки данных нажмите **Активировать**.

{% endnote %}

Чтобы проверить результат:

1. Откройте указанное пространство имен в REST-каталоге.
1. Убедитесь, что в нем появилась таблица с данными.
1. Откройте таблицу и проверьте ее структуру и данные в блоке **Предпросмотр**.
1. После изменения данных в источнике убедитесь, что соответствующие изменения появились в таблице назначения.

# Закрытие сервиса {{ cloud-desktop-full-name }}

{% note warning %}

Сервис {{ cloud-desktop-full-name }} выведен из эксплуатации. Рабочие столы остановлены, доступ к сервису через консоль управления, API и CLI закрыт.

{% endnote %}

## Что происходит {#what-happens}

Сервис закрыт в связи с изменением продуктовой стратегии. Ниже описано, как запросить возврат данных и выбрать другое решение для виртуальных рабочих столов.

## Как вернуть данные {#data}

Для возврата ваших данных обратитесь в [техническую поддержку]({{ link-console-support }}).

## Миграция {#migration}

Прямой замены {{ cloud-desktop-name }} в {{ yandex-cloud }} нет. В качестве альтернативы рассмотрите [{{ baremetal-name }} {{ baremetal-extend-virtualization-name }}](../baremetal/concepts/extend/virtualization.md) — платформу виртуализации на выделенных серверах. На платформе можно создавать и настраивать выделенные кластеры для виртуальных рабочих столов (VDI).

Важно учитывать, что решение рассчитано на сотни рабочих столов. Стоимость рассчитывается индивидуально.

Чтобы обсудить тестирование и переход, [отправьте заявку](../baremetal/operations/extend/virtualization.md) или свяжитесь с вашим аккаунт-менеджером.

## Если у вас есть вопросы {#support}

Если вам нужна консультация по миграции или остались вопросы по закрытию сервиса:

* Обратитесь в [техническую поддержку]({{ link-console-support }}).
* Свяжитесь с вашим аккаунт-менеджером.

Спасибо, что пользовались {{ cloud-desktop-name }}.

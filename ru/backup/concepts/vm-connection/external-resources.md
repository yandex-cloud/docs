# Подключение к {{ backup-name }} виртуальных машин и серверов, расположенных за пределами {{ yandex-cloud }} 


С помощью сервиса {{ backup-full-name }} вы можете создавать резервные копии внешних ресурсов — серверов или виртуальных машин, расположенных за пределами {{ yandex-cloud }}.

Сервис {{ backup-name }} позволяет хранить резервные копии ваших ресурсов в нашем высокодоступном и отказоустойчивом хранилище [{{ objstorage-full-name }}](../../../storage/index.yaml), а также управлять резервными копиями и восстановлением ресурсов из резервных копий с помощью [интерфейсов](../../../overview/concepts/interfaces.md), доступных в {{ yandex-cloud }}. Кроме того, использование резервных копий {{ backup-name }} позволяет удобно переносить виртуальные машины и серверы из вашей инфраструктуры или инфраструктуры стороннего провайдера в облачную инфраструктуру {{ yandex-cloud }}.

Чтобы создавать резервные копии внешних виртуальных машин или серверов, на эти ВМ или серверы необходимо установить [агент {{ backup-name }}](../agent.md).

{% note info %}

Чтобы установить агент {{ backup-name }}, необходима [роль](../../security/index.md#backup-user) `backup.user` или выше.

{% endnote %}

Подробнее об установке агента {{ backup-name }} на ВМ или сервер, расположенные за пределами {{ yandex-cloud }}, читайте в разделе [{#T}](../../operations/external/connect.md).

После установки агента {{ backup-name }} [привяжите](../../operations/policy-vm/attach-and-detach-vm.md#attach-vm) ВМ или сервер к [политике резервного копирования](../policy.md).

{% note tip %}

При установке агента {{ backup-name }} на ВМ или сервер может понадобиться доустановить отсутствующие компоненты ПО из интернета. Для этого на время установки разрешите для сетевого интерфейса любой исходящий сетевой трафик. После установки агента {{ backup-name }} вы можете вновь ограничить сетевой трафик с учетом [необходимых](#vm-network-access) для работы агента разрешений.

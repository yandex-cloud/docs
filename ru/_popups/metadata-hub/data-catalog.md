#### {#catalog}

Каталог метаданных — основная сущность сервиса {{ data-catalog-name }}. Одновременно является местом сбора и хранения метаданных из различных источников и рабочим пространством для их разметки. Подробнее в разделе [{#T}](../../metadata-hub/concepts/data-catalog.md).

#### {#ingestion}

Загрузка — процесс, который подключается к указанному в источнике хранилищу данных или сервису и загружает его метаданные в каталог. Загрузку можно запускать вручную или по расписанию. Подробнее в разделе [{#T}](../../metadata-hub/concepts/data-catalog.md#metadata-upload).

#### {#source}

Источник — подключение, через которое загружаются метаданные. В подключении хранится информация о БД или другом сервисе, из которого загружаются метаданные, а также данные для аутентификации. Подробнее в разделе [{#T}](../../metadata-hub/concepts/data-catalog.md#metadata-upload).

#### {#data-store}

Хранилище данных (data store) — сущность, которая объединяет метаданные источников, относящихся к одному кластеру управляемых баз данных или к одной пользовательской инсталляции базы данных. Подробнее в разделе [{#T}](../../metadata-hub/concepts/data-catalog.md#data-store).

#### {#domain}

Домен — группа метаданных для первичного распределения по потребностям рабочего процесса, например по принадлежности к отделу компании или направлению бизнеса. Для каждого домена можно создать поддомен. Подробнее в разделе [{#T}](../../metadata-hub/concepts/data-catalog.md#domains-and-subdomains).

#### {#subdomain}

Поддомен — вложенная группа метаданных внутри домена, которая позволяет более гранулярно распределить метаданные. Подробнее в разделе [{#T}](../../metadata-hub/concepts/data-catalog.md#domains-and-subdomains).

#### {#classification}

Классификация — группа тегов, которые используются для разметки метаданных. Подробнее в разделе [{#T}](../../metadata-hub/concepts/data-catalog.md#classifications-and-tags).

#### {#tag}

Тег — метка, которая используется для разметки метаданных по их типам, например чувствительные данные или характеристики таблиц. Подробнее в разделе [{#T}](../../metadata-hub/concepts/data-catalog.md#classifications-and-tags).

#### {#glossary}

Глоссарий — словарь узкоспециализированных терминов для определенной отрасли с толкованием этих терминов. Позволяет сформировать в компании единое понимание общей терминологии. Подробнее в разделе [{#T}](../../metadata-hub/concepts/data-catalog.md#glossaries-and-terms).

#### {#term}

Термин — понятие, которое используется для разметки данных по их семантическому значению в рамках бизнеса, например «выручка» или «расходы». Подробнее в разделе [{#T}](../../metadata-hub/concepts/data-catalog.md#glossaries-and-terms).

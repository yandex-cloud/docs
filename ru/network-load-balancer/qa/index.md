# Общие вопросы про {{ network-load-balancer-name }}

{% include [logs](../../_qa/logs.md) %}

#### Можно ли записывать логи ресурсов {{ network-load-balancer-name }}? {#write-logs}

Вы можете отслеживать [события уровня конфигурации](../at-ref.md) в {{ at-full-name }}. Для этого [создайте](../../audit-trails/operations/create-trail.md) трейл и включите в нем сбор логов с управляющего слоя.

Подключить лог-группу {{ cloud-logging-full-name }} напрямую к балансировщику нельзя.

#### Могу ли я защитить сетевой балансировщик от случайного удаления? {#deletion-protection}

Да, сетевой балансировщик можно [защитить от случайного удаления](../operations/deletion-protection.md).

#### Что означает «обработка входящего/исходящего трафика балансировщиком»? {#traffic-processing}

Под «обработкой трафика» в {{ network-load-balancer-name }} в правилах тарификации понимается объем данных, который проходит через [обработчики трафика балансировщика](../concepts/listener.md). 

При этом «обработка трафика» и «трафик передачи данных» — две разные сущности. Если у балансировщика настроен публичный IP-адрес, то параллельно тарифицируется: обработка трафика балансировщиком по правилам [тарификации NLB](../../vpc/pricing.md#prices-traffic) и передача данных из облака в интернет по [правилам тарификации исходящего трафика](../../vpc/pricing.md#prices-traffic). 

Для входящего трафика ситуация отличается: входящий трафик из интернета не тарифицируется, поэтому применяются только правила тарификации NLB.

#### Как защитить сетевой балансировщик от DDoS-атак и перебора IP-адресов? {#ddos-protection}

Чтобы защитить сетевой балансировщик, вы можете использовать сервис [{{ ddos-protection-full-name }}](../../vpc/ddos-protection/index.md). Для этого включите опцию **{{ ui-key.yacloud.common.field_ddos-protection-provider }}** при [создании](../operations/load-balancer-create.md) балансировщика. Защита от DDoS-атак применяется к его публичным IP-адресам. [Тарифицируется](../../vpc/pricing.md#prices-ddos-protection) каждый гигабайт очищенного входящего трафика.

Для дополнительного ограничения доступа по IP-адресам к целевым ресурсам балансировщика используйте [группы безопасности](../../vpc/concepts/security-groups.md).

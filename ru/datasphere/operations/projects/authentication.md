# Аутентификация в {{ ds-jobs }}

Для работы с {{ ds-jobs }} вам необходимо аутентифицироваться от имени пользовательского аккаунта. Для этого установите и настройте [{{ yandex-cloud }} CLI](../../../cli/quickstart.md). 

Запустить задание от имени пользовательского аккаунта на локальном компьютере без графической оболочки не получится: для прохождения аутентификации {{ yandex-cloud }} CLI перенаправит ваш запрос в браузер.

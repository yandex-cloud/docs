# Виджет

_Виджет_ — это элемент дашборда, отображающий информацию в виде графика или текста.

В сервисе {{ monitoring-full-name }} можно добавить виджеты:

* [График](#chart)
* [Текст](#text)
* [Заголовок](#heading)
* [Эскалация](#escalation)
* [Алерт](#alert)
* [Секция](#group)

## График {#chart}

Визуальное отображение одной или нескольких метрик за определенный временной интервал. Каждая метрика отображается отдельным [цветом графика](#color-schemes).

{{ monitoring-full-name }} позволяет отображать на графиках метрики сервисов {{ yandex-cloud }} и пользовательские метрики, загруженные с помощью API.

### Типы графиков {#chart-types}

Есть две группы графиков: **Временные ряды** показывают изменение метрик во времени, **Агрегации** — итоговые значения за выбранный период.

#### Временные ряды {#time-series}

По оси X отображается время, по оси Y — значение метрики.

* ![image](../../../_assets/console-icons/chart-line.svg) **{{ ui-key.yacloud_monitoring.wizard.chart.line }}** — значения метрик соединены линиями.
* ![image](../../../_assets/console-icons/chart-area-stacked.svg) **{{ ui-key.yacloud_monitoring.wizard.chart.area }}** — значения метрик показаны как заполненные цветом области.
* ![image](../../../_assets/console-icons/chart-column.svg) **{{ ui-key.yacloud_monitoring.wizard.chart.column }}** — значения метрик показаны столбцами равной ширины. Высота столбца равна сумме значений метрик в момент времени, а высота каждого сегмента — значению соответствующей метрики.
* ![image](../../../_assets/console-icons/grip-horizontal.svg) **{{ ui-key.yacloud_monitoring.wizard.chart.points }}** — значения метрик показаны отдельными точками.

#### Агрегации {#aggregations}

Для каждого элемента графика рассчитывается одно значение за выбранный период. В настройке **{{ ui-key.yacloud_monitoring.wizard.vis.aggregation-key-value }}** можно выбрать среднее, минимум, максимум, последнее значение, сумму или количество точек.

* ![image](../../../_assets/console-icons/chart-pie.svg) **{{ ui-key.yacloud_monitoring.wizard.chart.pie }}** — агрегированные значения показаны секторами круга.
* ![image](../../../_assets/console-icons/rectangles-4.svg) **{{ ui-key.yacloud_monitoring.wizard.chart.tiles }}** — агрегированные значения показаны на отдельных плитках.
* ![image](../../../_assets/console-icons/chart-bar.svg) **Столбцы** — метрики объединяются в категории и подгруппы по значениям меток. Агрегированное значение определяет высоту вертикального или длину горизонтального столбца. Для этого графика доступны сортировка, выбор ориентации и расположения столбцов внутри категории. Подробнее в разделе [Настроить график «Столбцы»](../../metrics/metric-explorer.md#bar-chart).

### Цветовые схемы {#color-schemes}

* **{{ ui-key.yacloud_monitoring.wizard.vis.scheme-auto }}** — назначается одна из цветовых схем:
  * **{{ ui-key.yacloud_monitoring.wizard.vis.scheme-gradient }}** — для графика типа **{{ ui-key.yacloud_monitoring.wizard.chart.area }}**, если все линии имеют хотя бы одно числовое значение.
  * **{{ ui-key.yacloud_monitoring.wizard.vis.scheme-standard }}** — во всех остальных случаях.
* **{{ ui-key.yacloud_monitoring.wizard.vis.scheme-standard }}** — цвет рассчитывается по установленному в системе алгоритму.
* **{{ ui-key.yacloud_monitoring.wizard.vis.scheme-gradient }}** — плавный цветовой переход в зависимости от значения метрик: от красного (высокие значения) к зеленому (низкие).
* **{{ ui-key.yacloud_monitoring.wizard.vis.scheme-hash }}** — в этом случае для каждой линии будет рассчитано уникальное значение (хеш), на основе которого будет сгенерирован цвет. Линии с одинаковым названием почти всегда будут отображаться одинаково.
* **{{ ui-key.yacloud_monitoring.wizard.vis.scheme-thresholds }}** — цвет линий определяется на основе заданных пользователем [пороговых значений](../../operations/dashboard/add-widget.md#thresholds) и выбранного метода агрегации данных. Позволяет визуально выделить линии, соответствующие критическим или целевым значениям.

### Время на графике {#time-period-on-charts}

Метрики на графике отображаются за определенный временной интервал, который может быть задан с помощью пресетов с заранее заданным диапазоном (`1h 3h 1d 1w 1mo`). Также вы можете указать время и дату для начала и конца интервала.

Для более тонкой настройки используйте таймлайн, расположенный над графиком.

## Алерт {#alert}

Виджет показывает на дашборде текущий статус выбранного алерта. Если для алерта добавлены [аннотации](../alerting/annotation.md), их также можно отобразить в виджете.

## Список алертов {#alert-list}

Виджет показывает на дашборде актуальное состояние алертов или подалертов мультиалертов, найденных по селектору, в виде цветной плитки. На дашборд можно добавить алерты из любого проекта, к которому у вас есть доступ.

## SLO {#slo}

Виджет для отображения списка [SLO](../../slo/index.md) с актуальными значениями SLI и остатка Error Budget. При нажатии на название SLO откроется страница просмотра.

Изменение временного интервала дашборда не влияет на виджет SLO, он всегда отображает значения показателей на данный момент.

## Эскалация {#escalation}

Виджет показывает на дашборде запущенные экземпляры эскалаций по выбранной политике эскалаций. С помощью виджета можно остановить одну или несколько эскалаций.

## Текст {#text}
Текст в формате [YFM](https://ydocs.tech/ru/), который позволяет вывести дополнительную информацию на дашборд. Например, вы можете разместить ссылки на другие дашборды.

## Заголовок {#heading}
Текст, который позволяет подписать дашборд или группу графиков.

## Секция {#group}
Секция позволяет объединить несколько виджетов в группу.

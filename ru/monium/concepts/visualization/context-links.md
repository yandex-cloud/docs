# Контекстные ссылки

_Контекстные ссылки_ — это быстрые переходы из данных на графике. Они отображаются во всплывающей подсказке в [обзоре метрик](../../metrics/metric-explorer.md) и на [дашбордах](dashboard.md), если точка графика соответствует условиям ссылки.

Контекстные ссылки помогают быстрее переходить от метрики к связанному источнику информации. Например, из метрики хоста можно открыть дашборд этого хоста, систему управления сервисом или страницу инцидента.

## Условия отображения {#display-conditions}

Условия отображения определяют, когда ссылка появится во всплывающей подсказке. Условие можно задать по наличию [меток](../data-model.md#label) или по значениям меток в результате запроса.

Примеры условий:

* `host=*` — ссылка отображается, если в результате запроса есть метка `host`;
* `{service="alerting", host="*vla*"}` — ссылка отображается, если в результате есть метка `service` со значением `alerting` и метка `host`, в значении которой есть строка `vla`.

Используйте условия, чтобы не показывать лишние ссылки. Например, ссылка на дашборд хоста нужна только для метрик с меткой `host`, а ссылка на дашборд кластера — только для метрик с меткой `cluster`.

## Параметры ссылки {#parameters}

Для контекстной ссылки настраиваются общие параметры:

* **Название ссылки** — текст, который отображается во всплывающей подсказке.
* **Условия отображения контекстной ссылки** — правило, по которому {{ monium-name }} показывает ссылку для точки графика.
* **Тип контекстной ссылки** — назначение перехода: дашборд или внешний URL.

Название ссылки должно объяснять действие. Например, используйте «Открыть дашборд хоста», а не «Ссылка».

## Типы контекстных ссылок {#type}

### Ссылка на дашборд {#dashboard}

Ссылка на дашборд открывает другой дашборд в текущем проекте. Используйте ее, чтобы переходить от обзорного графика к детальной странице.

Например, на общем дашборде сервиса можно добавить к метрике CPU ссылку на дашборд конкретного хоста. При переходе {{ monium-name }} передаст значения параметров, и дашборд откроется с нужным фильтром.

Для ссылки на дашборд укажите:

* **Дашборд** — целевой дашборд в текущем проекте.
* **Параметры дашборда** — значения параметров, если целевой дашборд их использует.

Параметр дашборда может быть статическим или динамическим. Статическое значение задается напрямую, например `production`. Динамическое значение подставляется из метки результата запроса.

Чтобы передать значение метки, укажите ее имя в двойных фигурных скобках. Например, вместо `not_var{{cluster}}` подставляется значение метки `cluster` из точки графика.

### Внешняя ссылка {#url}

Внешняя ссылка открывает произвольный URL. Используйте ее для перехода к системе эксплуатации, репозиторию, тикету, графику в другой системе или странице сервиса.

Для внешней ссылки укажите **Ссылку для перехода**. В URL можно использовать динамические значения из меток. Например, ссылка `https://example.com/hosts/not_var{{host}}` откроет страницу хоста, указанного в метке `host`.

Во внешних ссылках можно использовать специальные параметры времени:

#|
|| **Параметр** | **Описание** | **Пример значения** ||
|| `__from:iso` | Начало временного интервала в формате ISO 8601 | `2024-05-30T13:12:56Z` ||
|| `__to:iso` | Конец временного интервала в формате ISO 8601 | `2024-05-30T14:12:56Z` ||
|| `__from:seconds` | Начало временного интервала в секундах от начала Unix Epoch | `1717076276` ||
|| `__to:milliseconds` | Конец временного интервала в миллисекундах от начала Unix Epoch | `1717079876000` ||
|#

Например, ссылка `https://example.com/logs?host=not_var{{host}}&from=not_var{{__from:iso}}&to=not_var{{__to:iso}}` откроет логи выбранного хоста за тот же интервал, который используется на графике.

# Канал уведомлений

Чтобы получать уведомления о переходе алерта в другой статус, необходимо указать канал уведомлений. Канал содержит информацию о получателях, методе отправки и параметрах уведомлений.

Один канал можно использовать в нескольких алертах, а один алерт может отправлять уведомления в несколько каналов.

## Параметры канала уведомлений {#channel-parameters}

* **{{ ui-key.yacloud_monitoring.channel.field_name }}**. Название канала уведомлений.
* **ID**. Уникальный идентификатор канала. По умолчанию формируется из идентификатора проекта и имени канала.
* **По умолчанию для уровней**. Уровни алертов, для которых будут отправляться уведомления в этот канал без добавления канала к каждому алерту.
* **{{ ui-key.yacloud_monitoring.channel.field_recipients }}**. Список пользователей, которые должны получить уведомление при срабатывании алерта.

После создания канала доступны дополнительные параметры:

* **{{ ui-key.yacloud_monitoring.monitoring-alerts.label.sent-notify-statuses }}**. Статусы алерта, при которых {{ monium-name }} отправит уведомление.
* **{{ ui-key.yacloud_monitoring.monitoring-alerts.channel-table.repeat }}**. Интервал повторной отправки уведомления, если алерт остается в том же статусе. Не действует для статуса `OK`.

Для уведомлений в **{{ messenger-full-name }}** можно включить отправку скриншота графика с метриками алерта.

## Статусы отправки {#dispatch-statuses}

Каждая отправка может находиться в одном из следующих статусов:

Статус | Описание
----- | -----
`{{ ui-key.yacloud_monitoring.channel.status-description_success }}` | Уведомление успешно отправлено.
`{{ ui-key.yacloud_monitoring.channel.status-description_error }}` | Не удалось отправить уведомление из-за ошибки.
`Invalid request` | Не удалось отправить уведомление из-за некорректных параметров канала. Повторные попытки не выполняются.
`Retry error` | Не удалось отправить уведомление из-за временной ошибки метода отправки. {{ monium-name }} будет выполнять повторные попытки.
`Obsolete` | Уведомление не было отправлено до следующего события в канале.
`{{ ui-key.yacloud_monitoring.channel.status-description_resource_exhausted }}` | Не удалось отправить уведомление из-за ограничения метода отправки.

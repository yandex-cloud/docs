# Визуализация данных телеметрии

Инструменты визуализации представляют метрики и логи на графиках и диаграммах, которые помогают анализировать состояние системы и находить проблемы.

Визуализация решает три основные задачи:

* Мониторинг текущего состояния — отслеживание ключевых показателей в реальном времени.
* Анализ инцидентов — поиск причин сбоев через корреляцию данных из разных источников.
* Планирование ресурсов — оценка трендов потребления и прогнозирование нагрузки.

Инструменты визуализации:

* [Дашборды](../operations/dashboard/create.md) — объединяют несколько виджетов на одном экране для комплексного представления данных.
* Страница обзора — просмотр данных в реальном времени. Страницы обзора есть для каждого типа данных: [метрики](../metrics/metric-explorer.md), [логи](../logs/logs-explorer.md) и [трейсы](../traces/operations/traces-explorer.md).
* [Блокноты](../concepts/visualization/notebooks.md) — помогают собрать графики, логи, заметки и ссылки для анализа инцидента.
* [Ссылки](../concepts/visualization/context-links.md) — помогают переходить из меню проекта, дашбордов и графиков к связанным данным и внешним ресурсам.

Данные на графиках можно фильтровать по временным интервалам, сервисам, окружениям и другим параметрам. Также их можно разбивать по определенным параметрам для более детального исследования.

Дашборды можно создавать вручную, [импортировать из Grafana](../operations/dashboard/grafana-import.md) или использовать готовые дашборды сервисов {{ yandex-cloud }}.

Для анализа инцидентов можно сохранить [снапшот графика или дашборда](../concepts/visualization/snapshots.md). Данные снапшота останутся доступными после удаления или прореживания исходных метрик.

## Сервисные дашборды {#service-dashboards}

Сервисные дашборды содержат готовые графики с метриками ресурсов {{ yandex-cloud }}. В {{ monium-name }} они находятся в разделе **Дашборды**, на вкладке **Сервисные дашборды**. В консоли управления их можно открыть в разделе или на вкладке **Мониторинг** нужного сервиса.

Сервисный дашборд нельзя изменить, но можно сохранить измененный график на другой дашборд или создать редактируемую копию всего дашборда. Порядок действий приведен в инструкции [Посмотреть сервисные дашборды](../operations/dashboard/service-dashboards.md).

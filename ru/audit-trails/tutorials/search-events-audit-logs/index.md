# Поиск событий в аудитных логах

Выберите способ поиска в зависимости от объекта назначения трейла.

* Если трейл отправляет события в {{ monium-logs-name }}, [откройте аудитные логи](../search-monium.md) и выполните [запрос для нужного сценария](examples.md).
* Для логов в бакете {{ objstorage-name }} [выполните команду поиска с jq](../search-bucket.md#search).

Подробнее об [инструментах для работы с аудитными логами](tools.md).

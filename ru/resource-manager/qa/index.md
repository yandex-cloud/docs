# Общие вопросы про {{ resmgr-name }}

#### Почему у меня не получается перенести облако в другую организацию? {#transfer-issue}

Ошибка `publicAccessBindings` может возникнуть, если у пользователя есть роли на переносимое облако, его каталоги или ресурсы, но сам пользователь не добавлен в новую организацию.

Перед переносом для каждого такого пользователя нужно выполнить одно из действий:

* Добавить пользователя в новую организацию, если ему по-прежнему нужен доступ к ресурсам.
* Отозвать его роли на переносимое облако, каталоги и ресурсы, если доступ больше не нужен.

После этого можно повторить перенос. Роли федеративных пользователей в новой организации нужно назначить заново.

Подробнее — в инструкции [Изменение организации для облака](../operations/cloud/change-organization.md).

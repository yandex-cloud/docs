# Закрытие сервиса {{ container-registry-full-name }}

{% note warning %}

Сервис {{ container-registry-full-name }} прекращает работу. На этой странице описаны сроки, порядок закрытия и рекомендации по миграции.

{% endnote %}

## Что происходит {#what-happens}

Мы приняли решение закрыть сервис {{ container-registry-full-name }}. Понимаем, что это изменение может затронуть ваши рабочие процессы, и постараемся сделать переход комфортным.

## Ключевые даты {#key-dates}

Закрытие сервиса пройдет в три этапа:

* **13 октября 2026** — прекращение новых продаж сервиса {{ container-registry-full-name }}. Клиенты, подключившие сервис ранее, смогут пользоваться им до 10 ноября 2026 года.

* **10 ноября 2026** — сервис переходит в режим read-only. Создание новых реестров станет недоступно. Текущие пользователи {{ container-registry-full-name }} смогут только просматривать ранее созданные реестры и выгружать данные из них.

* **14 декабря 2026** — сервис полностью прекращает работу. Доступ к интерфейсу сервиса будет закрыт для всех пользователей.

## Что будет с вашими данными {#data}

Ваши данные (метаданные реестров, настройки прав доступа к реестру, политики доступа для IP-адресов, политики жизненного цикла, настройки сканирования, алиасы для реестров) не будут потеряны. После закрытия сервиса резервные копии ваших данных будут храниться до 30 июня 2027 года — их можно будет запросить через [техническую поддержку]({{ link-console-support }}).

## Миграция {#migration}

В качестве альтернативы перенесите свои реестры в [{{ cloud-registry-full-name }}](../cloud-registry/).

Мы подготовили руководство, которое поможет при миграции: [{#T}](tutorials/container-registry-migration.md).

Если у вас остались вопросы по закрытию сервиса:

* Обратитесь в [техническую поддержку]({{ link-console-support }}).
* Свяжитесь с вашим аккаунт-менеджером.

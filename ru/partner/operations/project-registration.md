# Зарегистрировать проект

[Проект](../program/var-tools.md#project-reg) доступен для регистрации, если он удовлетворяет условиям подачи.

Чтобы зарегистрировать проект:

{% list tabs group=instructions %}

- Партнёрский портал {#partner}

  1. Войдите на [Партнёрский портал]({{ link-cloud-partners }}).
  1. На панели слева выберите ![icon](../../_assets/console-icons/briefcase.svg) **Сделки**.
  1. Выберите из списка сделку, которую вы хотите зарегистрировать. Тип сделки должен быть **Проект**. Откройте страницу с информацией о проекте.

     Если регистрация проекта возможна, сверху вы увидите баннер с доступными партнерскими инструментами.

  1. Нажмите кнопку **Воспользоваться**. Откроется форма подачи заявки.
  1. Заполните форму, нажмите кнопку **Отправить** и дождитесь согласования заявки — это может занять до 20 рабочих дней. Вы получите уведомление на панели слева в разделе ![icon](../../_assets/console-icons/bell-dot.svg) **Уведомления**.
  1. После получения уведомления о регистрации сделки на панели слева выберите ![icon](../../_assets/console-icons/briefcase.svg) **Сделки**.
  
  1. Выберите из списка зарегистрированную сделку и нажмите на нее. Откроется раздел с информацией о сделке.
  1. Внутри сделки перейдите в раздел ![icon](../../_assets/console-icons/list-timeline.svg) **Активности** и в соответствующей заявке укажите сабаккаунт для выдачи дополнительной премии.

{% endlist %}

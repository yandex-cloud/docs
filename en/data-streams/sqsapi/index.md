# Amazon SQS-compatible HTTP API

In limited mode, {{ yds-name }} supports data stream processing via an [Amazon SQS-compatible](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/welcome.html) protocol (SQS over Topics).

For details on using {{ yds-name }} via an Amazon SQS-compatible HTTP API and examples, refer to the [YDB guides]({{ ydb.docs }}/reference/sqs-api/?version=v26.3).

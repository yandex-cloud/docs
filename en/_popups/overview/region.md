#### {#regions}

A region is a geographic area that combines [availability zones](../../overview/concepts/geo-scope.md). Each region has its own infrastructure and [services](../../overview/concepts/services.md).
For more information, see [{#T}](../../overview/concepts/region.md).

#### {#zones}

An availability zone is an infrastructure within a data center that hosts {{ yandex-cloud }}. {{ yandex-cloud }} resources are either _zonal_ (linked to an availability zone) or _global_ (not linked to any zone).
For more information, see [{#T}](../../overview/concepts/geo-scope.md).

#### {#services}

In {{ yandex-cloud }}, services allow you to manage specific cloud resources and access to them.
For more information, see [{#T}](../../overview/concepts/services.md).

#### {#network-flow}

A network flow is a sequence of packets between a source and a destination. Each flow is uniquely identified by these five parameters: source IP address, source port, destination IP address, destination port, and network protocol. The source and destination order is ignored.
For more information, see [Monitoring network connections](../../vpc/concepts/monitoring-connections.md).

#### {#subnet}

A subnet is a range of IP addresses in a cloud network. Addresses from this range can be assigned to cloud resources, such as VMs and DB clusters.
For more information, see [{#T}](../../vpc/concepts/network.md#subnet).

#### {#internal-ip}

An internal IP address is assigned to each network interface of a VM instance. You can specify the internal IP address manually when creating the VM, or it will be assigned automatically from the IP address range of the relevant subnet.
For more information, see [{#T}](../../compute/concepts/network.md#internal-ip).

#### {#hostname}

When creating a VM, it is assigned a host name and internal FQDN that can be used to access a certain VM from another VM within the same [cloud network](../../vpc/concepts/network.md).
For more information, see [{#T}](../../compute/concepts/network.md#hostname).

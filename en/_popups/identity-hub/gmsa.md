A gMSA (group Managed Service Account) is a type of account in {{ microsoft-idp.ad-full }} with passwords managed automatically by the domain controller. This simplifies running and operating the same service (SPN) on different servers. For more information, see [this Microsoft article](https://learn.microsoft.com/en-us/windows-server/identity/ad-ds/manage/group-managed-service-accounts/group-managed-service-accounts/group-managed-service-accounts-overview).

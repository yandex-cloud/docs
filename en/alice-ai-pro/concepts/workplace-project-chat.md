# Workspace, projects, and chats

To use {{ alice-ai-pro-name.p }}, the administrator assigns a user a *workspace*, i.e., a separate space where {{ alice-ai-pro-name.i }} stores projects, chats, and files, and runs tasks.

Each user has their own workspace. Other organization employees, including administrators, do not see your projects and chats.

A *project* combines chats and files belonging to a single task. For example, you can create separate projects for report preparation, document analysis, and event planning. Chats in one project are not shown in any other project.

A *chat* is a dialog with {{ alice-ai-pro-name.t }}. The chat saves messages, attached files, and work results. You can create a chat within a project or work without a project.

## File access {#file-access}

Attach a file from your computer to your message so that {{ alice-ai-pro-name.i }} can use it. The file will be uploaded to your workspace.

In a project, {{ alice-ai-pro-name.i }} can use folders this project has access to. All the project's chats get access to folders added to the project. A full chat history from other projects is neither shown nor added to the current chat context. If you enabled cross-chat memory, {{ alice-ai-pro-name.i }} may make use of saved information from your previous work.

## Use cases {#examples}

Create a separate project if you plan to have multiple chats on the common subject or want to use the same files in them. Create a chat without a project for a one-off task that does not require the project's materials.

# Getting started with {{ alice-ai-pro-name.t }}

You can communicate with {{ alice-ai-pro-name.t }} in a natural language, i.e., using simple words, as if it were your colleague you want to explain a task to. Describe what you want to get, add the required information or files, and continue the dialog to refine the result.

{{ alice-ai-pro-name.i }} can draft an email or document, summarize a large text, compare files, suggest a plan, and perform other routine tasks. You do not need to compose an ideal prompt or know special commands: if the first result is not good, explain the required changes.

To evaluate {{ alice-ai-pro-name.r }}, start with a small real-world task where the result is easy to verify. For example, ask it to shorten an email, summarize the main outtakes of a document, or prepare questions for a meeting.

{% note info %}

{{ alice-ai-pro-name.i }} can make mistakes. Verify important facts, calculations, and decisions before using the result.

{% endnote %}

To get started:

1. [Log in to {{ alice-ai-pro-name.v }}](#sign-in).
1. [Select a workspace](#select-workplace).
1. [Start your first chat](#start-chat).

## Getting started {#before-you-begin}

Ask your organization administrator to provide you with a workspace and complete its configuration. Use an organization account for logging in.

## Log in to {{ alice-ai-pro-name.v }} {#sign-in}

1. Open [{{ alice-ai-pro-name.v }}]({{ link-ai-agent }}).
1. Log in using an organization account. If the login page opens, select the appropriate account and go back to {{ alice-ai-pro-name.v }}.

After you log in, the workspace selection page will open.

## Select a workspace {#select-workplace}

1. Select a workspace from the list of those available to you.
1. Continue working with the selected workspace.

The administrator configures your workspace. You do not need to select a cloud or folder and enter their IDs.

If the required workspace is not on the list, contact the organization's administrator. If the workspace is still being configured, wait until its configuration is completed and retry logging in later.

## Start your first chat {#start-chat}

{% include [task-formulation-basics](../_includes/alice-ai-pro/task-formulation-basics.md) %}

1. Open a new chat.
1. [Select a model and operating mode](concepts/models.md), if needed. If you do not know which settings will suit you, leave the default settings.
1. Describe the task in your own words, e.g.:

   * `Write a short summary of the document and list its key outtakes`.
   * `Prepare the plan of a meeting for starting a new project`.
   * `Edit the email text: make it shorter and clearer`.

1. If a file is required to perform the task, attach it to the message.
1. Send the message.

{{ alice-ai-pro-name.i }} will respond in the chat. To refine the result, continue the dialog in the same chat. For another task, you can create another chat.

Learn more about building queries in [{#T}](operations/formulate-task.md).

The list of features available to you depends on your workspace settings and connected plugins. The available plugins are set up by the organization administrator. If you need a plugin that is not in the catalog, contact the administrator.

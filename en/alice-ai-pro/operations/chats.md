# Working with chats and files

In the chat, you can set a task for {{ alice-ai-pro-name.d }}, add source files, and get a result. For a separate task, create a new chat so that messages and assets from your earlier conversation do not affect the response.

## Creating a chat {#create-chat}

1. Select a new chat.
1. Select a project or continue without a project.
1. [Describe the task](formulate-task.md) in your own words.
1. If required, attach files or enable web search.
1. Send a message.

To interrupt response generation, use the stop response option.

## Using commands {#commands}

To open the list of commands and skills, enter `/` in the message input field. In an active chat, you can use the following commands:

- **Status**: View your chat ID, context usage, and the remainder of your 5-hour and weekly limits.
- **Planning mode**: Enable or disable [task planning](formulate-task.md#plan).
- **Memory**: [Configure memory](../concepts/memory.md#configure-chat) for this chat.

Available skills are displayed below the commands. Select a skill to attach it to your prompt. To add a plugin, type `@` and select one from the list.

## Attaching files {#attach-files}

1. In the message input field, select the attach file option.
1. Select the files from your computer.
1. Wait for the files to upload and send your message.

You can attach up to 20 files per message. A single file must not exceed 25 MB.

Before sending the message, you can remove any unwanted attachments. If a file fails to upload, try uploading it again.

## Using voice input {#voice-input}

1. Select voice input.
1. Speak your message.
1. Stop the recording and wait for the system to transcribe your text.
1. Check the text and send your message.

If the system fails to recognize your text, try recording the message again or type it in.

## Downloading a result {#download-result}

All documents generated during a chat session are displayed among the chat results. Open the file you need and save it to your computer.

## Renaming or deleting a chat {#manage-chat}

To rename or delete a chat, open chat actions and select the relevant option. Deleting a chat may be irreversible, so make sure to download any important results first.

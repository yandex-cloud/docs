# Working with projects

A project brings chats and files together for a common task. All project chats can use the folders added to this project.

## Creating a project {#create-project}

1. In the projects section, initiate creating a project.
1. Enter a name for the project.
1. If necessary, add available folders and select the main one.
1. Save the project.

Once the project is created, you can start a new chat or move an existing chat into it.

## Editing a project {#edit-project}

1. Open the actions for the project.
1. Select a project change.
1. Change the name or available folders.
1. Save your changes.

If you add a folder, all project chats will gain access to it.

## Moving a chat {#move-chat}

1. Open the actions for the chat.
1. Choose moving to a project.
1. Select an available project.

The chat will appear in the selected project. To work without a project, remove the chat from the project.

## Deleting a project from the list {#remove-project}

1. Open the project actions.
1. Select deleting the project from the list.
1. Confirm the action.

The project will be deleted only from the app. The project folder and existing chats will not be deleted.

If the project cannot be accessed due to an unavailable or deleted workspace, contact your organization's administrator. Deleting the project from the list will not restore access.

# Managed Spark Environment API, gRPC: EnvironmentService

A set of methods for managing Environments.

## Methods

#|
||Method | Description ||
|| [Get](get.md) | Returns the specified Environment. ||
|| [GetBase](getBase.md) | Returns the specified Base Environment. ||
|| [List](list.md) | Retrieves a list of Environments. ||
|| [ListBase](listBase.md) | Retrieves a list of Base Environments. ||
|| [Create](create.md) | Creates a Environment. ||
|| [Update](update.md) | Updates the specified Environment. ||
|| [Delete](delete.md) | Deletes the specified Environment. ||
|| [ListOperations](listOperations.md) | Retrieves a list of Environment operations. ||
|#

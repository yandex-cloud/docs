The cost of infrastructure support for linking a domain name to a VM includes:

* Fee for a continuously running [VM](../../../compute/concepts/vm.md) (see [{{ compute-full-name }} pricing](../../../compute/pricing.md)).
* Fee for a [public IP address](../../../vpc/concepts/address.md#public-addresses) (see [{{ vpc-full-name }} pricing](../../../vpc/pricing.md)).
* Fee for using a public [DNS zone](../../../dns/concepts/dns-zone.md) and public DNS requests (see [{{ dns-full-name }} pricing](../../../dns/pricing.md)).

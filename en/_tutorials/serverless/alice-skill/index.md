# Creating a skill for Alice


In this tutorial, you will create a skill for Alice based on a [function](*functions) from {{ sf-full-name }}. As an example, we will create a skill called <q>Parrot</q>, which repeats everything a user writes or says. The example can be implemented in two programming languages: Python and Node.js.

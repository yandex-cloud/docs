For the `standard` and `memory-optimized` host classes, part of the VM's resources is allocated to {{ mtr-name }} service components. To find the resources available for a {{ TR }} coordinator or worker, use the tables in [Host classes](../../managed-trino/concepts/instance-types.md). For the `legacy` classes, the number of vCPUs and amount of RAM in the class name match the resources available to the {{ TR }} component.

Set up rule display:

1. To adjust column visibility, click ![gear](../../_assets/console-icons/gear.svg) on the right side of the table header. Select the values you need and click **{{ ui-key.yacloud_org.common.apply }}**.
1. To filter rules, use the panel above the table. In drop-down lists, select the required values.

    To configure filter visibility, click ![plus](../../_assets/console-icons/plus.svg) to the right of the filter and select the values to show or hide.

[{{ kspm-full-name }} ({{ kspm-name }})](../../security-deck/concepts/kspm.md) ensures the security of containerized applications.

The {{ kspm-name }} module automatically detects all {{ k8s }} clusters and containers within a given [workspace](../../security-deck/concepts/workspace.md) and installs their [security components](../../security-deck/operations/kspm/requirements.md#component-consumption) as per the configuration. New clusters automatically get security coverage, without requiring manual search or installation of any components. For the {{ kspm-name }} components to be installed, the clusters must satisfy [system and technical requirements](../../security-deck/operations/kspm/requirements.md).

The module continuously assesses workloads for misconfigurations and provides runtime security monitoring through sensors that detect attacks targeting nodes and containers.

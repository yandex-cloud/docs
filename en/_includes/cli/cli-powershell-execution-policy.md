If PowerShell denies running scripts, check the active execution policies using the `Get-ExecutionPolicy -List` command. Only modify policies if this is allowed by your organization's security protocol. If the policy is enforced by the administrator or running scripts is prohibited, [install the CLI without a script](../../cli/operations/install-cli.md#bin).

For more information about PowerShell execution policies, see the relevant [Microsoft guides](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_execution_policies).

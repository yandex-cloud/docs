## Getting started {#before-you-begin}

Set up the following:

1. [Registry](../../iot-core/operations/registry/registry-create.md).
1. [Registry certificate](../../iot-core/operations/certificates/registry-certificates.md).
1. [Device](../../iot-core/operations/device/device-create.md).
1. [Device certificate](../../iot-core/operations/certificates/device-certificates.md).
1. [Mosquitto](https://mosquitto.org), an open source MQTT message broker. This guide uses it for sending messages and subscribing to devices. [Download and install](https://mosquitto.org/download/) it to work with commands provided in this guide.

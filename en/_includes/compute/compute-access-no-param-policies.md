#### compute.denyMultipleNic {#compute-denyMultipleNic}

This policy prohibits creating {{ compute-full-name }} virtual machines with multiple [network interfaces](../../compute/concepts/network.md) or adding additional network interfaces to existing VMs.

#### compute.denyPublicIpAssigning {#compute-denyPublicIpAssigning}

This policy prohibits creating virtual machines with [public IP addresses](../../vpc/concepts/address.md#public-addresses) or assigning public IP addresses to the [network interfaces](../../compute/concepts/network.md) of existing {{ compute-full-name }} VMs.

#### compute.denySerialPortEnabling {#compute-denySerialPortEnabling}

This policy prohibits enabling access to the {{ compute-full-name }} VM [serial console](../../compute/concepts/serial-console.md).

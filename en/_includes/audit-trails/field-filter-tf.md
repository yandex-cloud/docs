Optionally, supplement the filter with [conditions based on field values](../../audit-trails/concepts/trail.md#field-filters) for the relevant service. To do this, under `filtering_policy.data_events_filter`, set the `include_rule` and `exclude_rule`. Use the {{ yandex-cloud }} provider version 0.225.0 or higher. For filter configuration examples, see [Creating a trail](../../audit-trails/operations/create-trail.md#filter-examples).

Optionally, supplement the filter with [conditions based on field values](../../audit-trails/concepts/trail.md#field-filters) for the relevant service. Do it by setting the `includeRules` and `excludeRules` rules in the `filteringPolicy.dataEventsFilters` list item in the REST API request. In the gRPC API, use `include_rules` and `exclude_rules` in `filtering_policy.data_events_filters`. For a filter configuration example, see [Creating a trail](../../audit-trails/operations/create-trail.md#example-control-data-planes).

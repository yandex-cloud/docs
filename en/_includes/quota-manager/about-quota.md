There are quotas and resource usage limits in {{ yandex-cloud }}. {{ quota-manager-name }} allows you to manage quotas using different interfaces. Some services, e.g., {{ speechkit-name }}, are not available in {{ quota-manager-name }}.

**Quotas**: Resource usage limits in the cloud or organization. Quotas can be changed upon request. They help manage resource usage, avoid overspending, and plan budgets.

The key concepts in quota management are:

* **Quota limit** or just **quota**: Current limit in place for a resource for a cloud or organization.

* **Quota usage**: Amount of the actually used resource.

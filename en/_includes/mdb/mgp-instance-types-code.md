
* **s2**, **s3**, **s4a**, **s4af**: Standard configurations with a 4:1 RAM GB to vCPU ratio.
* **i2**, **i3**: Configurations with 8 GB:1 RAM-to-vCPU ratio. These configurations are well suited for clusters with high cache requirements. Hosts with this configuration run in a [software-accelerated network](../../vpc/concepts/software-accelerated-network.md), which substantially affects [cluster costs](../../managed-greenplum/pricing/index.md#prices-hosts).
* **m4a**, **m4af**: Configurations with an increased RAM GB to vCPU ratio (8:1). These configurations are well suited for clusters with high cache requirements.
* **c4a**, **c4af**: Configurations with a reduced RAM GB to vCPU ratio (2:1). These configurations may be useful for clusters with higher processor performance requirements.

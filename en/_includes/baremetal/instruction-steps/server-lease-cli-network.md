`--network-interfaces`: Server network interfaces:

* `private-interface`: Private interface. Specify the [private subnet](../../../baremetal/concepts/private-network.md#private-subnet) ID in the `native-subnet-id` parameter.
* `public-interface`: Public interface. Specify the [dedicated public subnet](../../../baremetal/concepts/public-network.md#public-subnet) ID in the `subnet-id` parameter under `native-subnet`. This is an optional setting.

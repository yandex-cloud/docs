[Workload identity federations](../../iam/concepts/workload-identity.md) enable you to set up integration between external systems and {{ yandex-cloud }} via [OpenID Connect](https://openid.net/developers/how-connect-works/) (OIDC). This allows external systems to perform actions with {{ yandex-cloud }} resources under {{ iam-short-name }} [service accounts](../../iam/concepts/users/service-accounts.md) without using [authorized keys](../../iam/concepts/authorization/key.md). This is a more secure method that minimizes the risk of credential leakage and unauthorized access.

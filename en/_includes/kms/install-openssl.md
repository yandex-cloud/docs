{% list tabs group=operating_system %}

- Linux {#linux}

  Run this command:
  
  ```bash
  sudo apt-get install openssl
  ```

- Windows {#windows}

  Use [Chocolatey](https://chocolatey.org/install). Run the following command in PowerShell as an admin:

  ```powershell
  choco install openssl
  ```

A user with the `Administrator` (`datalens.workbooks.admin`) role for the workbook can add any user to the mailing list. If the added user does not have a role for the workbook yet, the system automatically assigns them the minimum `Limited viewer` (`datalens.workbooks.limitedViewer`) role.

A user with the `Editor` (`datalens.workbooks.editor`) role for the workbook can only add users who already have a role for that workbook. Adding other users is blocked.

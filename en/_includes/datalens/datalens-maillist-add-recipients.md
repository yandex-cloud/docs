A user with the `Admin` role (`datalens.workbooks.admin`) for the workbook can add any user to the mailing list. If a user without a role for the workbook is added to the mailing list, they will automatically be assigned the minimum `Limited viewer` role (`datalens.workbooks.limitedViewer`) for that workbook.

A user with the `Editor` role (`datalens.workbooks.editor`) for the workbook can only add users who already have a role for the workbook to the mailing list. Other users cannot be added to the mailing list.

* **Raw SQL level**: Enables you to use an ad-hoc SQL query to [generate a dataset](../../datalens/dataset/settings.md#sql-request-in-datatset). This option is disabled by default. When enabling it, you will need to select the raw SQL level:

   * **Subqueries only**: Describe dataset sources using [SQL queries](../../datalens/dataset/settings.md#sql-request-in-datatset).
   * **SQL to read**: Describe dataset sources using SQL queries, [create QL charts](../../datalens/concepts/chart/ql-charts.md), and execute read-only SQL queries.

To execute data-modifying queries, enable **Raw SQL level** → **SQL to write**.

{% note info %}

* For connections to {{ CH }} with active **Raw SQL level** → **SQL to write**, set `Readonly` to `0` in the connection's advanced settings.

* If you do not have permissions to edit the connection settings, contact the administrator.

{% endnote %}


To open a connection in SQL Editor:

1. Open the connection of interest.
1. In the top-right corner of the page, click **Open in SQL Editor**.

This will open a window for data operations and queries.

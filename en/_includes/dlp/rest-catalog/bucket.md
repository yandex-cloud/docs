* In the **Name** field, specify a name for the bucket.
* In the **Maximum size** field, select the bucket usage mode:
  * **Limit**: Specify the maximum size and the unit of measurement: **GB**, **TB**, or **PB**.
  * **Unlimited**: Remove the limit on the bucket size.
* In the **Storage class** field, select a class based on how frequently the data is accessed:
  * **Standard**: For frequently used data.
  * **Cold**: For data that is accessed less frequently.
  * **Icy**: For rarely accessed data.

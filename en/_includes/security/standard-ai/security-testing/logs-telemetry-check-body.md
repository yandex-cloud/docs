For a significant operation, the reviewer first looks for it in the official event reference pertaining to the specific service at hand. Then they determine whether the required area and filter are enabled for the actual trail. If the event is missing or does not contain the required context, application or service telemetry is used.

The minimum result record contains:

* Requirement ID.
* Check date and time.
* Exact resource and version.
* Checked subject.
* Interface or verification command.
* Expected and observed result.
* Link to the minimal evidence.
* Output with one of the _met_, _not met_, _not applicable_, or _not checked_ statuses and, if required, the associated exception.

For an active test, the test data, permitted scope, rollback method, and cleanup confirmation are additionally recorded. Secrets, full personal data, raw dialogs, and other extraneous contents are not included in the report.

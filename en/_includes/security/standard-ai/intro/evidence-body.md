The evidence must relate to the exact resource, version, subject, and time of verification. The record must specify the interface or command, expected and observed results, and a reference to the minimum required artifact: a configuration export, bindings, an event, an application trace, or safe test result. A design description without mapping to the actual configuration does not constitute evidence of implementation.

The evidence must not disclose secret values, excessive personal data, full conversation, or restricted documents. If the service does not publish the required event or configuration setting, this must be recorded as a blind spot and, where necessary, addressed through application logging or a manual test; lack of telemetry cannot be treated as a successful result.

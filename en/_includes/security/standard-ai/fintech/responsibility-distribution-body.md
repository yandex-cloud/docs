The matrix uses the following roles:

| Role | Responsibility |
|---|---|
| **User** | The organization leveraging {{ yandex-cloud }} services and using an AI solution is responsible for the solution architecture, service settings, data, accesses, processes, and compliance with this Standard. |
| **{{ yandex-cloud }}** | The cloud infrastructure and managed services provider is responsible for the cloud platform's security under the shared responsibility model and terms for providing the relevant service. |
| **Shared responsibility** | {{ yandex-cloud }} fulfills the requirement at the platform level, while the user fulfills it by using a specific service setting, restricting access, enabling logging, applying encryption keys, and taking other measures offered by the relevant service. |

> If the **User actions** column specifies that {{ yandex-cloud }} is responsible for fulfilling the requirement, this applies solely to protecting the platform component of the relevant managed service. The user remains responsible for the service configuration, accounts, access permissions, data, integrations, application code, and compliance with the requirements for their AI solution.

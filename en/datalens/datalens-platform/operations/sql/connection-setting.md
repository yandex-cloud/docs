# Configuring a connection to use SQL Editor in {{ datalens-platform-full-name }}

To use SQL Editor in {{ datalens-platform-short-name }}, first configure a connection to your database.

To use SQL Editor, enable **Raw SQL level** → **SQL to read** in the connection settings. You can enable the option when creating or updating a connection.

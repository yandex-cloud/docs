# AI tools in {{ datalens-platform-full-name }}

Neuroanalyst in {{ datalens-platform-full-name }} is an AI agent that helps you analyze projects, write queries, suggests improvements and edits, and streamlines the creation and editing of visualizations. Besides, Neuroanalyst can build visualizations to meet your demands.

Neuroanalyst uses only those objects that the user sending the request to Neuroanalyst has access to.

## Data security and processing {#security}

* Neuroanalyst is based on the cloud service called [{{ ai-studio-full-name }}]({{ link-docs-ai }}).
* Your data and queries stay within the {{ yandex-cloud }} infrastructure.
* Your data and queries are not used for model fine-tuning.
* The administrator can disable the Neuroanalyst feature at the platform level.

See more about Neuroanalyst limits [here](../../../concepts/limits.md#datalens-ai-limits).

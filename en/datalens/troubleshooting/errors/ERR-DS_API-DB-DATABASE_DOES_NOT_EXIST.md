# [{{ datalens-full-name }}] Data source database does not exist

`ERR.DS_API.DB.DATABASE_DOES_NOT_EXIST`

This error occurs when trying to access a non-existent database.

To fix the error, check the database name considering the case, and make sure the database has not been deleted or renamed. Specify an existing database or ask the administrator to create or restore the required one.

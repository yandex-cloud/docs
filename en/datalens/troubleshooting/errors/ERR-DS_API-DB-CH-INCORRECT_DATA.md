# [{{ datalens-full-name }}] {{ CH }} could not parse the data in the specified source

`ERR.DS_API.DB.CH.INCORRECT_DATA`

This error occurs when {{ CH }} cannot parse the source data.

To fix the error, verify that the actual values, their formats, and their types match the table schema. Correct the invalid data or schema.


If the source appears valid, contact the {{ CH }} administrator or {{ yandex-cloud }} [support]({{ link-console-support }}). In your message, describe when the error occurs.

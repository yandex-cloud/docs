# [{{ datalens-full-name }}] Data preparation not complete yet

`ERR.DS_API.DB.MATERIALIZATION_NOT_FINISHED`

Data preparation is not complete yet; wait a few more minutes or reupload the data.


You get this error if an uploaded file is not yet fully processed in the [file](../../operations/connection/create-file.md), [Google Sheets](../../operations/connection/create-google-sheets.md), or [Yandex Documents](../../operations/connection/create-yadocs.md) connection.


It also occurs when [importing workbooks](../../workbooks-collections/export-and-import.md#import-workbook) with such connections. To fix this error, reupload the data after importing the workbook.

# [{{ datalens-full-name }}] Clique <clique_name> is suspended

`ERR.DS_API.DB.CHYT.CLIQUE.SUSPENDED`

The CHYT clique specified in this message has been suspended.

To fix this error, try the following:

* Resume the clique's operation or switch the connection to an active clique, then retry the request.
* If are not the manager of the clique, contact its owner. You can find the person responsible for the clique in its [access permission settings interface](https://ytsaurus.tech/docs/ru/user-guide/data-processing/chyt/cliques/access#ui).
* If the clique owner is missing or difficult to find, contact the administrator of the connection where the clique is used.

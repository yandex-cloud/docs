# Enabling and disabling a check under a custom rule set

{% include [custom-reuirements-role](../../../_includes/security-deck/custom-reuirements-role.md) %}

{% list tabs group=instructions %}

- {{ sd-name }} UI {#cloud-sd}

  1. Go to [{{ sd-full-name }}]({{ link-sd-main }}).
  1. In the left-hand panel, select ![seal-check](../../../_assets/console-icons/seal-check.svg) **{{ ui-key.yacloud_org.security-center.label_comp }}**.
  1. At the top of the window, select the workspace.
  1. In the row with the custom rule set, click ![ellipsis](../../../_assets/console-icons/ellipsis.svg) and select ![check](../../../_assets/console-icons/check.svg) **{{ ui-key.yacloud_org.security.comp.CompSetPageLayout.turn_on_checking_button_bWBXb }}** or ![xmark](../../../_assets/console-icons/xmark.svg) **{{ ui-key.yacloud_org.security.comp.CompSetPage.urn_off_checking_button }}**.

{% endlist %}

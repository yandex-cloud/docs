

The `datalens.sharedEntries.limitedViewer` role is assigned for a common object and enables viewing its [charts]({{ link-datalens-docs }}/concepts/chart/) and the [dashboards]({{ link-datalens-docs }}/concepts/dashboard) that use it, without direct access to the common object itself. In the {{ datalens-name }} UI, this role is referred to as `Limited viewer`. We recommend assigning this role only via the {{ datalens-name }} UI.

The `ai.models.editor` role enables using {{ responses-api }} configurations, text and image generation models, text embedding models and classification models, as well as speech recognition and synthesis, optical character recognition, and text translation in {{ ai-studio-full-name }}.

Users with this role can:


* View info on {{ ai-studio-full-name }} [text generation models]({{ link-docs-ai }}ai-studio/concepts/generation/models).
* Use [{{ responses-api }} configurations]({{ link-docs-ai }}ai-studio/operations/generation/create-prompt), text and image generation models, [text embedding models]({{ link-docs-ai }}ai-studio/concepts/embeddings#yandexgpt-embeddings), and [classifier models]({{ link-docs-ai }}ai-studio/concepts/classifier/models) in {{ ai-studio-full-name }}.
* Use [text translation]({{ link-docs-ai }}translate/concepts/) features in {{ ai-studio-full-name }}.
* Use [optical character recognition]({{ link-docs-ai }}vision/concepts/ocr/) in {{ ai-studio-full-name }}.
* Use speech [recognition]({{ link-docs-ai }}speechkit/stt/) and [synthesis]({{ link-docs-ai }}speechkit/tts/) in {{ ai-studio-full-name }}.


This role includes the `ai.models.user` permissions.

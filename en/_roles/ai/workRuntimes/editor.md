The `ai.workRuntimes.editor` role enables users to create seats and use their seat.

Users with this role can:

* View info on user [seats]({{ link-docs-ai }}ai-studio/manage/concepts/#work-runtime).
* View info on [access permissions](../../../iam/concepts/access-control/index.md)granted for user seats.
* Create seats.
* Use their seat.

This role includes the `ai.workRuntimes.user` permissions.

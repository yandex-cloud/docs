The `ai.workRuntimes.admin` role enables managing user seats and access to them.

Users with this role can:

* View info on user [seats]({{ link-docs-ai }}ai-studio/manage/concepts/#work-runtime).
* View info on [access permissions](../../../iam/concepts/access-control/index.md) granted for user seats and modify such permissions.
* Create and delete seats.
* Use their seat.

This role includes the `ai.workRuntimes.editor` permissions.

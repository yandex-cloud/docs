The `ai.workProfiles.user` role enables employing user seat profiles.

Users with this role can:

* View info on user [seat profiles]({{ link-docs-ai }}ai-studio/manage/concepts/#runtime-profile).
* View info on [access permissions](../../../iam/concepts/access-control/index.md) granted for user seat profiles.
* Utilize user seat profiles.

This role includes the `ai.workProfiles.viewer` permissions.

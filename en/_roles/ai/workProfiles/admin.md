The `ai.workProfiles.admin` role enables managing user seat profiles and access to them.

Users with this role can:

* View info on user [seat profiles]({{ link-docs-ai }}ai-studio/manage/concepts/#runtime-profile).
* View info on [access permissions](../../../iam/concepts/access-control/index.md) granted for user seat profiles and modify such permissions.
* Create, use, modify, and delete user seat profiles.

This role includes the `ai.workProfiles.editor` permissions.

# Managed Service for Redis API, gRPC: UserService

A set of methods for managing Valkey User resources.

## Methods

#|
||Method | Description ||
|| [Get](get.md) | Returns the specified Valkey User resource. ||
|| [List](list.md) | Retrieves the list of Valkey User resources in the specified cluster. ||
|| [Create](create.md) | Creates a Valkey user in the specified cluster. ||
|| [Update](update.md) | Updates the specified Valkey user. ||
|| [Delete](delete.md) | Deletes the specified Valkey user. ||
|#

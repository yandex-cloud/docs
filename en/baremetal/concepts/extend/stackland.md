# {{ baremetal-extend-stackland-name }}

*{{ baremetal-extend-stackland-name }}* is a BareMetal Extend product for automatic [{{ stackland-full-name }}](../../../stackland/index.yaml) deployment on dedicated physical [{{ baremetal-name }} servers](../servers.md).

{{ stackland-full-name }} is a containerization platform with {{ yandex-cloud }} PaaS services on board. It features [components](../../../stackland/concepts/components/overview.md) for centralized management of microservice and AI apps. {{ stackland-full-name }} is based on [{{ k8s }}](https://kubernetes.io/), so you can use familiar tools and {{ k8s }} APIs to manage your applications.

{{ baremetal-extend-stackland-name }} automates server provisioning and platform installation. You get a cluster on dedicated resources where you can run containerized applications and access [{{ yandex-cloud }} platform services](../../../stackland/concepts/components/overview.md), including databases, object storage, tools for monitoring, business analytics, and AI.

[Creating an {{ baremetal-extend-stackland-name }} cluster](../../operations/extend/stackland.md).

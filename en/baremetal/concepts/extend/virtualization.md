# {{ baremetal-extend-virtualization-name }}

*{{ baremetal-extend-virtualization-name }}* is a commercial virtualization platform in the BareMetal Extend product line for creating virtual machines and distributed data storage. It is automatically installed and configured individually for each user on a physical cluster of {{ baremetal-name }} servers.

The platform components, computing resources, storage, as well as public and private network requirements are worked out jointly with the {{ yandex-cloud }} architects when processing requests. {{ baremetal-extend-virtualization-name }} is deployed and maintained together with K2 Cloud.

# BareMetal Extend

*BareMetal Extend* is a line of ready-made infrastructure products based on {{ baremetal-full-name }} [servers](./servers.md). These products combine dedicated physical resources with {{ yandex-cloud }} software platforms and management tools to greatly simplify and accelerate infrastructure deployment.

## Products {#products}

BareMetal Extend currently offers the following products:

* [{{ baremetal-extend-virtualization-name }}](./extend/virtualization.md), a commercial virtualization platform for creation of virtual machines and distributed data storage based on a {{ baremetal-name }} server cluster.
* [{{ baremetal-extend-stackland-name }}](./extend/stackland.md), a {{ baremetal-name }} server-based containerization platform with integrated PaaS services by {{ yandex-cloud }}.
* [{{ baremetal-extend-managed-k8s-name }}](./extend/managed-kubernetes.md), groups of {{ managed-k8s-name }} worker nodes on dedicated {{ baremetal-name }} physical servers.

The BareMetal Extend line will be expanding further. The product availability status, supported configurations, and terms of service may vary. If a resource cannot be created, submit a request from the appropriate **{{ ui-key.yacloud.baremetal.label_extend }}** subsection.

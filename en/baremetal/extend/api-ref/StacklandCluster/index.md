# Extend API, REST: StacklandCluster

A set of methods for managing StacklandCluster resources.

## Methods

#|
||Method | Description ||
|| [GetStacklandCluster](getStacklandCluster.md) | Gets Stackland cluster by it's id. ||
|| [ListStacklandClusters](listStacklandClusters.md) | List Stackland clusters in the specified folder. ||
|| [CreateStacklandCluster](createStacklandCluster.md) | Creates new Stackland cluster. ||
|| [UpdateStacklandCluster](updateStacklandCluster.md) | Updates the specified Stackland cluster. ||
|| [DeleteStacklandCluster](deleteStacklandCluster.md) | Deletes the specified Stackland cluster. ||
|| [GetStacklandClusterConfigs](getStacklandClusterConfigs.md) | Returns a zip archive with the cluster config.yaml and secrets.yaml. ||
|| [ListStacklandClusterOperations](listStacklandClusterOperations.md) | Lists operations for the specified Stackland cluster. ||
|#

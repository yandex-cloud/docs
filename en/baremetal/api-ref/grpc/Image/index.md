# BareMetal API, gRPC: ImageService

A set of methods to retrieve information about image.

## Methods

#|
||Method | Description ||
|| [GetImage](getImage.md) | Returns the specific Image resource. ||
|| [ListImages](listImages.md) | Retrieves the list of Image resources. ||
|| [ListCompatibleImages](listCompatibleImages.md) | Lists images available for installation on the selected configuration. ||
|| [ResolveImages](resolveImages.md) | Resolves the latest published Image for each available family within the specified folder. ||
|#

# yc adviser v1

Manage recommendations for managed database clusters.
Each recommendation is an issue detected by regular checks of a cluster.
Recommendations are available at the cluster, folder, and cloud levels.

#### Command Usage

Syntax:

`yc adviser v1 <group>`

#### Command Tree

- [yc adviser v1 issue](issue/index.md) — A set of methods for working with issues detected by Advisor on cloud resources.

  - [yc adviser v1 issue dismiss](issue/dismiss.md) — Dismisses the specified issue for the specified period of time.

  - [yc adviser v1 issue get-dismissal-info](issue/get-dismissal-info.md) — Returns the specified dismissal.

  - [yc adviser v1 issue list](issue/list.md) — List issues detected on the resources of the specified cloud, folder or resource

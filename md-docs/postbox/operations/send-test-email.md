# Отправка тестового письма

Вы можете отправить тестовое письмо в консоли управления. Чтобы проверить отправку без реального получателя, отправьте письмо на один из адресов [симулятора доставки](../concepts/mail-simulator.md).

## Перед началом работы {#before-begin}

1. [Создайте](../../iam/operations/sa/create.md) сервисный аккаунт в том же каталоге, в котором находится адрес. Если вы создадите сервисный аккаунт и адрес в разных каталогах, при попытке отправить письмо возникнет ошибка.
1. [Назначьте](../../iam/operations/sa/assign-role-for-sa.md) сервисному аккаунту [роль](../security/index.md#postbox-sender) `postbox.sender`.

## Отправка тестового письма

{% list tabs group=instructions %}

- Консоль управления {#console}

    1. В [консоли управления](https://console.yandex.cloud) перейдите в каталог, в котором находится адрес.
    1. [Перейдите](https://console.yandex.cloud/link/postbox) в сервис **Cloud Postbox**.
    1. На панели слева выберите ![image](../../_assets/console-icons/at.svg) **Адреса**.
    1. Выберите адрес и нажмите кнопку **Тестовое письмо**.
    1. В поле **Отправитель** введите имя почтового ящика отправителя — часть адреса до знака `@`. По умолчанию домен совпадает с выбранным адресом. Чтобы отправить письмо с другого адреса в каталоге, выберите его домен в списке. Отправить письмо можно только с адреса, для которого [подтверждено владение доменом](check-domain.md).
    1. В поле **Сценарий** выберите получателя:
        * Адрес [симулятора доставки](../concepts/mail-simulator.md), чтобы проверить результат доставки без отправки письма реальному получателю.
        * `Произвольный получатель`, чтобы отправить письмо на любой адрес электронной почты. Укажите адрес в поле **Получатель**.
    1. Введите тему письма в поле **Тема** и текст письма в поле **Содержимое**.
    1. (Опционально) В поле **Конфигурация** выберите [конфигурацию](../concepts/configuration.md), которую нужно применить к письму.
    1. В поле **Сервисный аккаунт** выберите сервисный аккаунт с ролью `postbox.sender`.
    1. (Опционально) Включите опцию **Дополнительные параметры** и заполните поля:
        * **Адреса для ответов (Reply-To)** — адреса, на которые будут отправляться ответы от получателей тестового письма. Можно указать несколько адресов через запятую.
        * **Адрес для уведомлений о недоставке (Return-Path)** — адрес, на который будут отправляться уведомления о недоставке тестового письма получателям.
        * **Дополнительные получатели (CC)** — адреса, на которые будут отправляться копии тестового письма. Можно указать несколько адресов через запятую.
        * **Скрытые копии (BCC)** — адреса, на которые будут отправляться скрытые копии тестового письма. Можно указать несколько адресов через запятую.
    1. Нажмите кнопку **Отправить**.

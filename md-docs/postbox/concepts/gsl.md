# Глобальный стоп-лист

Yandex Cloud Postbox использует глобальный стоп-лист (Global Suppression List, GSL) — системный список электронных адресов, при отправке писем на которые ранее происходили постоянные ошибки доставки. Список общий для всех [адресов](glossary.md#adress) Yandex Cloud Postbox и обновляется автоматически.

## Как электронный адрес попадает в глобальный стоп-лист {#adding-address}

Если почтовый сервер получателя возвращает ошибку, которую Yandex Cloud Postbox классифицирует как постоянную и не требующую повторной попытки доставки, сервис фиксирует отказ по этому адресу.

В глобальный стоп-лист попадают только электронные адреса с постоянными отказами. Из-за временных ошибок доставки адрес не попадает в глобальный стоп-лист.

## Как работает блокировка {#blocking}

Блокировка зависит от количества отказов. Первый отказ фиксируется, но попытки отправки при этом продолжаются. Если отказы повторяются, Yandex Cloud Postbox блокирует отправку на адрес. Срок блокировки увеличивается с каждым новым отказом и может достигать 14 дней.

Yandex Cloud Postbox удалит адрес из глобального стоп-листа, если после истечения срока блокировки будет сделана попытка отправки на адрес, которая окажется успешной.

## Что происходит при отправке на заблокированный адрес {#sending}

Запрос на отправку письма принимается: Yandex Cloud Postbox возвращает идентификатор письма, но не передает письмо на почтовый сервер получателя. Вместо доставки сервис фиксирует подавление отправки. Это событие отражается:

* в [уведомлениях об операциях с письмами](notification.md#bounce). Приходит событие `Bounce` с подтипом ошибки `bounceSubType: Suppressed`.
* в логах доставки, например:

    ```json
    {
      "message": {
        "mail": { "recipient": "recipient@example.com" },
        "reason": "Recipient is on the global suppression list"
      }
    }
    ```

## Управление {#management}

* Глобальный стоп-лист включен по умолчанию для всех аккаунтов, выключить его нельзя.
* Содержимое глобального стоп-листа недоступно через публичный API, изменить список вручную нельзя.

## Рекомендации {#recommendation}

Если отправка на электронный адрес была заблокирована глобальным стоп-листом, удалите этот адрес из рассылки, пока не убедитесь, что он актуален и принимает почту.

# yc managed-greenplum pxf-datasource update s3

Update s3 pxf-datasource for specified Greenplum cluster

#### Command Usage

Syntax:

`yc managed-greenplum pxf-datasource update s3 <DATASOURCE-NAME> [Flags...]`

#### Flags

#|
||Flag | Description ||
|| `--cluster-id` | `string`

Greenplum cluster id. ||
|| `--cluster-name` | `string`

Greenplum cluster name. ||
|| `--async` | Display information about the operation in progress, without waiting for the operation to complete. ||
|| `--access-key` | `string`

Access key for s3 ||
|| `--secret-key` | `string`

Secret key for s3 ||
|| `--endpoint` | `string`

Endpoint for s3 ||
|| `--fast-upload` | Store data in RAM when uploading ||
|| `--xml` | `[]string`

Load datasource from xml files ||
|| `--force` | Ignore xml errors ||
|#

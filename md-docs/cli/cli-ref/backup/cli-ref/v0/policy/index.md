# yc backup v0 policy

Manage policies

#### Command Usage

Syntax:

`yc backup v0 policy <command>`

Aliases:

- `policies`

#### Command Tree

- [yc backup v0 policy apply](apply.md) — Apply policy to vm(-s)

- [yc backup v0 policy create](create.md) — Create policy

- [yc backup v0 policy delete](delete.md) — Delete policy(-es)

- [yc backup v0 policy execute](execute.md) — Execute policy for vm

- [yc backup v0 policy get](get.md) — Show policy by id

- [yc backup v0 policy list](list.md) — Lists available policies

- [yc backup v0 policy list-applications](list-applications.md) — Lists policy applications

- [yc backup v0 policy revoke](revoke.md) — Revoke policy from vm(-s)

- [yc backup v0 policy update](update.md) — Update the policy

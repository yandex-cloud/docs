# Метрики Yandex BareMetal

В этом разделе описаны метрики сервиса [BareMetal](../../baremetal/index.md), поставляемые в Monitoring.

Метрики сервиса BareMetal автоматически передаются в [Monium](../../monium/metrics/overview.md) в [проект каталога](*monium-folder-project), в котором находится сервер.

Если вы просматриваете метрики в интерфейсе сервиса или переходите к графику из [сервисного дашборда](../../monium/operations/dashboard/service-dashboards.md), значение метки `service` используется без подчеркиваний.

Если вы создаете запрос в Monium в [разделе метрик](../../monium/metrics/metric-explorer.md#add-graph) или в редакторе алерта, укажите проект каталога с ресурсом (`project = folder__<идентификатор_каталога>`), `cluster = default` и `service = __<идентификатор_сервиса>__`.


Имя метрики пишется в метку `name`.

Чтобы посмотреть графики в консоли управления, [откройте страницу сервера](../../baremetal/operations/servers/get-info.md) и перейдите на вкладку **Мониторинг**.

Чтобы открыть готовый дашборд, в [Monium](https://monium.yandex.cloud) выберите проект каталога с сервером. Откройте раздел **Дашборды**. На вкладке **Сервисные дашборды** найдите дашборд по названию сервиса BareMetal.

Общие метки для метрик сервиса BareMetal:

Метка | Значение
----|----
service | Идентификатор сервиса: `baremetal`.
server_id | Идентификатор [сервера BareMetal](../../baremetal/concepts/servers.md).
server_subnet_type | Тип [подсети](../../baremetal/concepts/network.md): `private` или `public`.

`server_fan2_speed_rpm`<br/>`DGAUGE`, тыс. об./мин. | Скорость вращения второго вентилятора сервера.

`server_fan4_speed_rpm`<br/>`DGAUGE`, тыс. об./мин. | Скорость вращения четвертого вентилятора сервера.

`server_power_status`<br/>`DGAUGE` | Статус питания сервера: `1`, если питание сервера включено.

`server_received_drop_packets`<br/>`DGAUGE`, пакеты/с | Количество пакетов в секунду, потерянных и не полученных на сетевом интерфейсе.

`server_sent_drop_packets`<br/>`DGAUGE`, пакеты/с | Количество пакетов в секунду, потерянных при отправке с сетевого интерфейса.
`server_sent_error_packets`<br/>`DGAUGE`, пакеты/с | Количество пакетов в секунду, отправленных с ошибками с сетевого интерфейса.
`server_sent_packets`<br/>`DGAUGE`, пакеты/с | Количество пакетов в секунду, отправленных с сетевого интерфейса.

[*monium-folder-project]: Проект Monium с идентификатором `folder__<идентификатор_каталога>` создается автоматически для каждого каталога и содержит телеметрию его ресурсов.

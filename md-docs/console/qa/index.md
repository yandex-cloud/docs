# Вопросы и ответы

#### Что делать, если Yandex Cloud Console не открывается? {#console-connection-timeout}

Попытка обращения к странице [консоли управления](https://console.yandex.cloud) через браузер заканчивается таймаутом.

Выполните следующие действия:

1. Временно отключите поддержку протокола IPv6.

   Проверить настройки IPv6 можно с помощью команд:

   * `ip addr | grep inet6` — для устройств с ОС на базе ядра Linux;
   * `netsh interface ipv6 show config` — для устройств с Microsoft Windows®.

1. Перезагрузите устройство и откройте [страницу консоли управления](https://console.yandex.cloud) повторно.

Если это не помогло, [создайте запрос в техническую поддержку](https://center.yandex.cloud/support). При создании запроса укажите следующую информацию:

1. Название и версию ОС на вашем устройстве.
1. Название и версию используемого браузера — собрать информацию можно с помощью этого [сайта](https://whatmyuseragent.com/).
1. Результат выполнения команд: `ping console.yandex.cloud -c 10` и `ping -6 console.yandex.cloud -c 10`.
1. Результат выполнения команд: `mtr -rzbw console.yandex.cloud --tcp -P 443 -c 100` и `mtr -6 -rzbw console.yandex.cloud --tcp -P 443 -c 100`.

{% note info %}

Утилита MTR не входит в набор стандартных утилит операционной системы. Вы можете установить ее с помощью менеджера пакетов вашего Linux-дистрибутива.

Если на вашем устройстве установлена ОС Microsoft Windows®, вы можете воспользоваться встроенной в нее утилитой `tracert`.

{% endnote %}

# Закрытие сервиса Yandex Cloud Desktop

{% note warning %}

Сервис Yandex Cloud Desktop прекратит работу 14 декабря 2026 года. До этой даты сохраните нужные данные и перенесите рабочие столы в другое решение.

{% endnote %}

## Что происходит {#what-happens}

Мы приняли решение закрыть сервис Yandex Cloud Desktop в связи с изменением продуктовой стратегии. Ниже описаны сроки закрытия и рекомендации по переходу на другое решение для виртуальных рабочих столов.

## Ключевые даты {#key-dates}

Закрытие сервиса пройдет в три этапа:

* **13 октября 2026** — сервис станет недоступен для подключения новым пользователям. Пользователи, подключившие сервис ранее, смогут продолжить работу.

* **10 ноября 2026** — сервис перейдет в режим только для чтения (read-only). Изменение ресурсов станет недоступно. При этом вы сможете скопировать данные и удалить ресурсы.

* **14 декабря 2026** — сервис полностью прекратит работу. Рабочие столы будут остановлены, доступ к сервису через консоль управления, API и CLI будет закрыт.

## Что будет с вашими данными {#data}

Резервные копии данных и логи будут сохранены в долговременном хранилище. Для восстановления данных после закрытия сервиса обратитесь в [техническую поддержку](https://center.yandex.cloud/support).

Рекомендуем заранее скопировать нужные файлы и настройки с рабочих столов в другое хранилище, чтобы сохранить доступ к ним после закрытия сервиса.

## Миграция {#migration}

Прямой замены Cloud Desktop в Yandex Cloud нет. В качестве альтернативы рассмотрите [BareMetal Extend: Virtualization](../baremetal/concepts/extend/virtualization.md) — платформу виртуализации на выделенных серверах. На платформе можно создавать и настраивать выделенные кластеры для виртуальных рабочих столов (VDI).

Важно учитывать, что решение рассчитано на сотни рабочих столов. Стоимость рассчитывается индивидуально.

Чтобы обсудить тестирование и переход, [отправьте заявку](../baremetal/operations/extend/virtualization.md) или свяжитесь с вашим аккаунт-менеджером.

До закрытия сервиса:

1. Сохраните копии нужных файлов и настроек рабочих столов.
1. Перенесите рабочую среду в выбранное решение и проверьте работу приложений и доступ к данным.
1. После проверки [удалите рабочие столы](operations/desktops/delete.md), которые больше не нужны.

## Если у вас есть вопросы {#support}

Если вам нужна консультация по миграции или остались вопросы по закрытию сервиса:

* Обратитесь в [техническую поддержку](https://center.yandex.cloud/support).
* Свяжитесь с вашим аккаунт-менеджером.

Спасибо, что пользовались Cloud Desktop.

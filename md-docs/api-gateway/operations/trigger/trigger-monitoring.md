# Посмотреть графики мониторинга триггера в Yandex API Gateway

 Вы можете отслеживать работу триггеров по графикам в консоли управления. Метрики собирает и отображает [Monium](../../../monium/index.md). 

Период обновления графиков — 15 секунд.

## Посмотреть графики мониторинга {#charts}

{% list tabs group=instructions %}

- Консоль управления {#console}

    1. В [консоли управления](https://console.yandex.cloud) перейдите в каталог, в котором находится триггер.

    1. [Перейдите](https://console.yandex.cloud/link/api-gateway) в сервис **API Gateway**.

    1. Выберите триггер, графики мониторинга которого хотите посмотреть.

    1. Перейдите на вкладку **Мониторинг**.

    1. На странице появятся следующие графики:

        * **Request latency** — среднее время обработки запроса триггером.
        * **Read events** — количество событий, после которых сработал триггер.
        * **Function access errors** — количество ошибок доступа при рассылке сообщений в веб-сокет соединения.
        * **Function call errors** — количество ошибок при рассылке сообщений в веб-сокет соединения.

    Вы можете выбрать период, за который необходимо отобразить информацию на графике: час, день, неделя, месяц или произвольный период.

{% endlist %}

## Посмотреть метрики в Monium {#metrics}

Чтобы открыть готовые графики в Monium, в правом верхнем углу нажмите кнопку **Открыть в Monium**. В Monium также можно [строить графики по отдельным метрикам](../../../monium/metrics/metric-explorer.md), создавать [дашборды](../../../monium/concepts/visualization/dashboard.md) и настраивать [алерты](../../../monium/concepts/alerting/alert.md).

Описание метрик приведено в [справочнике](../../metrics.md).

# Добавить расширение x-yc-apigateway-integration:http

{% list tabs %}

- Консоль управления

    1. В [консоли управления](https://console.yandex.cloud) выберите [каталог](../../../resource-manager/concepts/resources-hierarchy.md#folder), в котором создали или хотите создать [API-шлюз](../../concepts/index.md).
    1. [Перейдите](https://console.yandex.cloud/link/api-gateway) в сервис **API Gateway**.
    1. Выберите API-шлюз или нажмите кнопку **Создать API-шлюз**, чтобы создать новый.
    1. Нажмите кнопку ![image](../../../_assets/console-icons/pencil.svg) **Редактировать**.
    1. В поле **Спецификация** нажмите значок ![image](../../../_assets/api-gateway/spec-constructor/http.svg).
    1. Укажите в поле:

        * **Путь** — относительный путь к интеграции, который будет добавлен к URL-адресу API Gateway. Переменные указывайте в фигурных скобках, например `/static/{function_id}`. Подробнее в спецификации [OpenAPI 3.0](https://github.com/OAI/OpenAPI-Specification).
        * **HTTP-метод** — метод, который будет использоваться для взаимодействия с интеграцией.

        * (Опционально) **Сервисный аккаунт** — сервисный аккаунт, который будет использоваться для авторизации при обращении к API Yandex Cloud. Если у вас нет сервисного аккаунта, [создайте](../../../iam/operations/sa/create.md) его.
        * **URL** — URL, по которому необходимо перенаправить вызов. Должен быть доступен из интернета.
        * (Опционально) **Метод** — HTTP-метод, который будет использоваться для вызова. Если параметр не задан, используется метод, указанный в поле **HTTP-метод**.
        * (Опционально) **HTTP-заголовки** — HTTP-заголовки, которые будут передаваться в запросе.
          
           Включите опцию **Заголовки исходного запроса**. По умолчанию все заголовки исходного запроса, кроме `User-Agent`, не передаются.

        Если необходимо, выключите опцию **Пустые заголовки**. По умолчанию пустые HTTP-заголовки передаются.
        * (Опционально) **Query-параметры** — query-параметры, которые будут передаваться в запросе.

           Включите опцию **Query-параметры исходного запроса**. По умолчанию query-параметры исходного запроса не передаются.

        Если необходимо, выключите опцию **Пустые query-параметры**. По умолчанию пустые query-параметры передаются.
        * (Опционально) **Таймаут чтения** — таймаут чтения для выполнения вызова, в секундах.
        * (Опционально) **Таймаут соединения** — таймаут соединения для выполнения вызова, в секундах.
    1. Нажмите кнопку **Добавить**.

{% endlist %}

В поле **Спецификация** отобразится OpenAPI-спецификация с указанными значениями параметров.

# Удалить пользовательское правило

Для работы с [пользовательскими правилами](../../concepts/custom-rules.md) необходима [роль](../../security/cspm-roles.md) `security-deck.rules.editor` или выше.

{% list tabs group=instructions %}

- Интерфейс Security Deck {#cloud-sd}

  1. Перейдите в сервис [Yandex Security Deck](https://center.yandex.cloud/security/).
  1. На панели слева выберите ![file-text](../../../_assets/console-icons/file-text.svg) **Правила и исключения**.
  1. В верхней части окна выберите [окружение](../../concepts/workspace.md).
  1. Перейдите на вкладку **Пользовательские**.
  1. Справа от правила нажмите ![image](../../../_assets/console-icons/ellipsis.svg) и выберите ![image](../../../_assets/console-icons/trash-bin.svg) **Удалить**.
  1. В открывшемся окне подтвердите удаление.

{% endlist %}

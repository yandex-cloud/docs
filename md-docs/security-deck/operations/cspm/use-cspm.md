# Работать с дашбордом модуля CSPM

Для работы с дашбордом необходима роль `security-deck.viewer` или выше на каталог, в котором находятся ресурсы модуля CSPM.

{% list tabs group=instructions %}

- Интерфейс Security Deck {#cloud-sd}

  1. Перейдите в сервис [Yandex Security Deck](https://center.yandex.cloud/security/).
  1. На панели слева выберите **Контроль облачной конфигурации**.
  1. В верхней части окна выберите [окружение](../../concepts/workspace.md).
  1. Изучите вкладку **Дашборд**. На ней размещены следующие блоки:
     * **Топ алертов** — содержит наиболее часто встречающиеся алерты.
     * **Топ правил с нарушениями** — содержит наиболее часто встречающиеся правила с нарушениями.
     * Список алертов с указанием типа угрозы, статуса и времени последнего обновления. В верхней части списка доступны фильтры по критичности, типам угрозы, статусу, дате создания и изменения. Также можно воспользоваться выбором приемника и сортировкой.

     Для управления проверкой доступны следующие кнопки:

     * **Проверить окружение** — запуск [проверки](check-environment.md) окружения на соответствие правилам контроля.
     * ![image](../../../_assets/console-icons/chevron-down.svg) **Ещё** → ![image](../../../_assets/console-icons/file-arrow-down.svg) **Скачать отчёт** — [получение](work-with-results.md#download) CSV-файла с отчетом о последней проверке.
     * ![image](../../../_assets/console-icons/chevron-down.svg) **Ещё** → ![image](../../../_assets/console-icons/file-arrow-down.svg) **Настроить контроль** — переход в [настройки окружения](../workspaces/update.md), где можно выбрать модули контроля и наборы требований, которым должны соответствовать ресурсы в окружении.

  1. Вкладка **История проверок** содержит информацию о всех выполненных проверках. Отчет о каждой проверке можно [скачать](work-with-results.md#download).
  1. На вкладке **Уведомления** убедитесь, что все ресурсы подключены к CSPM и находятся в активном статусе контроля.
  1. На вкладке **О сервисе** можно просмотреть общую информацию о модуле CSPM.

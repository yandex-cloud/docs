# Удалить пользовательский набор правил {#delete-set}

{% note info %}

Для операций с пользовательскими наборами правил нужна [роль](../../security/index.md#security-deck-editor) `security-deck.editor` или выше.

{% endnote %}

{% list tabs group=instructions %}

- Интерфейс Security Deck {#cloud-sd}

  1. Перейдите в сервис [Yandex Security Deck](https://center.yandex.cloud/security/).
  1. На панели слева выберите ![seal-check](../../../_assets/console-icons/seal-check.svg) **Соответствие требованиям**.
  1. В верхней части окна выберите окружение.
  1. В строке с пользовательским набором правил нажмите значок ![ellipsis](../../../_assets/console-icons/ellipsis.svg) и выберите ![trash-bin](../../../_assets/console-icons/trash-bin.svg) **Удалить**.

{% endlist %}

# Управлять тегами алертов

Теги упрощают поиск алертов и позволяют добавить к ним контекст.

## Добавить теги алерту {#add-tag}

{% list tabs group=instructions %}

- Интерфейс Security Deck {#cloud-sd}

  1. Перейдите в сервис [Yandex Security Deck](https://center.yandex.cloud/security/).
  1. На панели слева выберите ![alerts](../../../_assets/security-deck/alerts.svg) **Алерты**.
  1. В верхней части окна выберите [окружение](../../concepts/workspace.md).
  1. Выберите алерт.
  1. В поле **Теги**:
  
     * Если у алерта нет тегов, нажмите **Добавить тег**.
     * Если у алерта есть теги, нажмите значок ![image](../../../_assets/security-deck/add-tag.svg).

  1. Введите название тега или выберите из списка.

{% endlist %}

## Добавить теги нескольким алертам {#add-tag-multiple}

{% list tabs group=instructions %}

- Интерфейс Security Deck {#cloud-sd}

  1. Перейдите в сервис [Yandex Security Deck](https://center.yandex.cloud/security/).
  1. На панели слева выберите ![alerts](../../../_assets/security-deck/alerts.svg) **Алерты**.
  1. В верхней части окна выберите [окружение](../../concepts/workspace.md).
  1. Отметьте ![image](../../../_assets/console-icons/check.svg) необходимые алерты и нажмите ![image](../../../_assets/console-icons/tag.svg) **Добавить теги**.
  1. В открывшемся окне нажмите **Добавить тег** и введите название тега или выберите из списка.

{% endlist %}

## Удалить теги алерта {#remove-tag}

{% list tabs group=instructions %}

- Интерфейс Security Deck {#cloud-sd}

  1. Перейдите в сервис [Yandex Security Deck](https://center.yandex.cloud/security/).
  1. На панели слева выберите ![alerts](../../../_assets/security-deck/alerts.svg) **Алерты**.
  1. В верхней части окна выберите [окружение](../../concepts/workspace.md).
  1. Выберите алерт.
  1. В поле **Теги** нажмите значок ![image](../../../_assets/security-deck/xmark.svg) рядом с тегом, который необходимо удалить.

{% endlist %}

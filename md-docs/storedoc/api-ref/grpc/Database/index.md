# Managed Service for MongoDB API, gRPC: DatabaseService

A set of methods for managing StoreDoc Database resources.

## Methods

#|
||Method | Description ||
|| [Get](get.md) | Returns the specified StoreDoc Database resource. ||
|| [List](list.md) | Retrieves the list of StoreDoc Database resources in the specified cluster. ||
|| [Create](create.md) | Creates a new StoreDoc database in the specified cluster. ||
|| [Update](update.md) | Updates the specified StoreDoc database. ||
|| [Delete](delete.md) | Deletes the specified StoreDoc database. ||
|#

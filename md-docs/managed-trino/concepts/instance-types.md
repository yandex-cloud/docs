# Классы хостов Managed Service for Trino

_Класс хостов_ определяет вычислительные мощности, выделяемые для каждого хоста в кластере.

Ограничения приведены в разделе [Квоты и лимиты](limits.md).

## Доступные классы хостов {#available-flavors}

Доступны классы хостов следующих типов:

* `standard`;
* `memory-optimized`;
* `legacy`.

Классы `standard` и `memory-optimized` размещаются на платформе AMD Zen 4. Их имена имеют префикс `v4a-`. Тип `legacy` объединяет классы предыдущего поколения на платформе Intel Ice Lake. Подробнее о платформах в разделе [Платформы](../../compute/concepts/vm-platforms.md#standard-platforms).

### Классы standard и memory-optimized на AMD Zen 4 {#amd-zen4}

Для классов `standard` и `memory-optimized` число vCPU и объем RAM в имени класса соответствуют ресурсам ВМ. Часть этих ресурсов резервируется для служебных компонентов Managed Service for Trino. При расчете требуемых ресурсов кластера используйте значения из столбцов «Доступно компоненту Trino».

Это связано с особенностями архитектуры платформы и не влияет на биллинг: списание производится в соответствии со значениями из столбцов «Доступно компоненту Trino». Например, для класса хоста `v4a-c8-m32` компоненту Trino доступно 6 vCPU и 26 ГБ RAM; биллинг учитывает те же значения.

Чтобы выбрать класс хостов, сопоставьте требования рабочей нагрузки с ресурсами, доступными компоненту Trino. Используйте эти значения при настройке рабочих нагрузок и ресурсных групп.

#### standard {#amd-standard}

| Имя класса хостов | Виртуальная машина, vCPU | Виртуальная машина, RAM, ГБ | Доступно компоненту Trino, vCPU | Доступно компоненту Trino, RAM, ГБ |
| --- | ---: | ---: | ---: | ---: |
| `v4a-c8-m32` | 8 | 32 | 6 | 26 |
| `v4a-c16-m64` | 16 | 64 | 13 | 54 |
| `v4a-c32-m128` | 32 | 128 | 28 | 112 |
| `v4a-c64-m256` | 64 | 256 | 60 | 236 |

#### memory-optimized {#amd-memory-optimized}

| Имя класса хостов | Виртуальная машина, vCPU | Виртуальная машина, RAM, ГБ | Доступно компоненту Trino, vCPU | Доступно компоненту Trino, RAM, ГБ |
| --- | ---: | ---: | ---: | ---: |
| `v4a-c8-m64` | 8 | 64 | 6 | 52 |
| `v4a-c16-m128` | 16 | 128 | 13 | 108 |
| `v4a-c32-m256` | 32 | 256 | 28 | 224 |
| `v4a-c64-m512` | 64 | 512 | 60 | 472 |

### Классы legacy на Intel Ice Lake {#legacy}

Для классов `legacy` числа в имени класса соответствуют ресурсам, доступным компоненту Trino. Например, в классе `c16-m64` компоненту доступно 16 vCPU и 64 ГБ RAM.

| Имя класса хостов | Доступно компоненту Trino, vCPU | Доступно компоненту Trino, RAM, ГБ |
| --- | ---: | ---: |
| `c4-m16` | 4 | 16 |
| `c8-m32` | 8 | 32 |
| `c16-m64` | 16 | 64 |
| `c32-m128` | 32 | 128 |
| `c4-m32` | 4 | 32 |
| `c8-m64` | 8 | 64 |
| `c16-m128` | 16 | 128 |
| `c32-m256` | 32 | 256 |

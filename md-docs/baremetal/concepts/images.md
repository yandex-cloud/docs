# Образы в Yandex BareMetal

_Образы_ в Yandex BareMetal позволяют устанавливать или запускать на [серверах](servers.md) операционные системы и другие программные продукты. В сервисе используются два типа образов:

* [Образы Marketplace](#marketplace-images) — для автоматической установки операционной системы или приложения при аренде сервера или переустановке ОС.
* [Загрузочные образы](#user-images) — для запуска сервера с ISO-образа и самостоятельной установки ПО, диагностики или устранения неполадок.

## Образы Marketplace {#marketplace-images}

_Образ Marketplace_ для BareMetal содержит программный продукт, подготовленный для использования на серверах BareMetal. Это может быть операционная система, например Ubuntu или AlmaLinux, либо готовое приложение на базе ОС, например сервер OpenVPN.

Образы содержат необходимые драйверы оборудования и настройки и протестированы для работы на серверах BareMetal. Они устанавливаются автоматически при [аренде сервера](../operations/servers/server-lease.md) или [переустановке ОС](../operations/servers/reinstall-os-from-marketplace.md).

Актуальный список доступных образов приведен в [консоли управления](https://console.yandex.cloud/link/marketplace/products?productTypes=BAREMETAL) и на [сайте Marketplace](https://yandex.cloud/ru/marketplace?type=BAREMETAL).

{% note info %}

Образы BareMetal — отдельный тип продуктов Marketplace, который отличается от образов виртуальных машин. Для автоматической установки на серверы BareMetal можно использовать только продукты этого типа.

{% endnote %}

{% note warning %}

Использование некоторых образов может тарифицироваться дополнительно. Стоимость продукта отображается в консоли управления при аренде сервера.

{% endnote %}

Образы в Marketplace добавляют партнеры Yandex Cloud. Пользователи не могут самостоятельно добавлять образы для автоматической установки на серверы BareMetal.

## Загрузочные образы {#user-images}

_Загрузочный образ_, или _пользовательский ISO-образ_, — образ в формате [ISO](https://ru.wikipedia.org/wiki/ISO-образ), с которого можно запустить сервер. Такой образ монтируется через [KVM-консоль](../operations/servers/server-kvm.md) в виде виртуального CD-дисковода или флеш-накопителя и используется для самостоятельной установки операционной системы, диагностики или устранения неполадок.

Вы можете самостоятельно [создать загрузочный образ](../operations/image-upload.md) в BareMetal из собственного ISO-файла. Загрузочный образ не используется для автоматической установки ОС при аренде сервера.

Подробнее о монтировании ISO-образа — в инструкции [Запустите сервер с собственного ISO-образа в режиме UEFI](../operations/servers/reinstall-os-from-own-image.md#boot-from-image).

# BareMetal Extend

*BareMetal Extend* — это линейка готовых инфраструктурных продуктов на базе [серверов](servers.md) Yandex BareMetal. Продукты объединяют выделенные физические ресурсы с программными платформами и средствами управления Yandex Cloud, что позволяет значительно упростить и ускорить развертывание инфраструктуры.

## Продукты {#products}

На данный момент в BareMetal Extend доступны следующие продукты:

* [Extend: Virtualization](extend/virtualization.md) — коммерческая платформа виртуализации для создания виртуальных машин и распределенного хранилища данных на кластере серверов BareMetal.
* [Extend: Yandex Cloud Stackland](extend/stackland.md) — платформа контейнеризации с интегрированными PaaS-сервисами Yandex Cloud, развернутая на серверах BareMetal.
* [Extend: Managed Service for Kubernetes®](extend/managed-kubernetes.md) — группы рабочих узлов Managed Service for Kubernetes на выделенных физических серверах BareMetal.

Линейка BareMetal Extend будет расширяться. Доступность продуктов, поддерживаемые конфигурации и условия предоставления могут различаться. Если создание ресурса недоступно, отправьте заявку из соответствующего подраздела **BareMetal Extend**.

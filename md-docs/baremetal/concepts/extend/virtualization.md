# Extend: Virtualization

*Extend: Virtualization* — платформа коммерческой виртуализации в линейке BareMetal Extend для создания виртуальных машин и распределенного хранилища данных. Платформа автоматически устанавливается и настраивается индивидуально для каждого пользователя на физическом кластере из серверов BareMetal.

Состав платформы, вычислительные ресурсы, хранилище и требования к публичным и приватным сетям прорабатываются совместно с архитекторами Yandex Cloud при обработке заявки. Платформа разворачивается и поддерживается в партнерстве с K2 Cloud.

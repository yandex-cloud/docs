# yc baremetal v0 private-cloud-connection create

Create a private cloud connection

#### Command Usage

Syntax:

`yc baremetal v0 private-cloud-connection create [Flags...] [Global Flags...]`

#### Flags

#|
||Flag | Description ||
|| `--routing-instance-id` | `string`

ID of Cloud Router Routing Instance. ||
|| `--vrf-id` | `string`

ID of VRF that is connected to routing Instance. ||
|| `--async` | Display information about the operation in progress, without waiting for the operation to complete. ||
|#

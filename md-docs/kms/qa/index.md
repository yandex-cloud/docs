# Общие вопросы про Key Management Service

#### Почему статус ключа не меняется на `Inactive`?

Изменение статуса ключа с `Active` на `Inactive` относится к [eventually consistent](../concepts/consistency.md) операциям. Изменения, вызванные такими операциями, вступают в силу с задержкой до трех часов.

#### Почему ключи продолжают тарифицироваться после удаления? {#keys-charged-after-deletion}

После запроса на [удаление ключа](../operations/key.md#delete) его версии переходят в статус `Scheduled For Destruction` на три дня и продолжают [тарифицироваться](../pricing.md). В течение этого срока ключ вместе с версиями можно восстановить по запросу в [техническую поддержку](https://center.yandex.cloud/support).

Через три дня ключ и его версии удаляются безвозвратно. После этого расшифровать данные, зашифрованные этим ключом, невозможно.

#### Я могу получить логи моей работы в сервисах? {#logs}

Да, вы можете запросить информацию о работе с вашими ресурсами из логов сервисов Yandex Cloud. Для этого обратитесь в [техническую поддержку](https://center.yandex.cloud/support).

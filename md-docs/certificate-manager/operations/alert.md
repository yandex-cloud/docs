# Добавить алерт для сертификата

Чтобы вовремя обновлять сертификаты и реагировать на проблемы с ними, создайте алерты:

* **О скором истечении срока действия** — переходит в статус `Warning`, когда до истечения срока действия сертификата остается 14 дней или меньше, и в `Alarm` — 4 дня или меньше.
* **О неработоспособности** — переходит в статус `Alarm`, если хотя бы один из отслеживаемых сертификатов не прошел проверку прав на домены (`Invalid`), отозван (`Revoked`) или срок его действия истек.

[Алерт](../../monium/concepts/alerting/alert.md) — периодическая проверка метрик по заданным условиям. `Warning` означает, что достигнут порог предупреждения, а `Alarm` — критический порог. При переходе в эти статусы Monium отправляет уведомления через настроенный канал, например, по электронной почте или в Яндекс Мессенджер. 

Инструкция ниже описывает создание одного алерта. Вам потребуется создать два отдельных алерта, выбрав соответствующий вариант настройки.

{% list tabs group=instructions %}

- Интерфейс Monium {#console}

  1. [Перейдите](https://monium.yandex.cloud) в **Monium** и на панели сверху выберите [проект](../../monium/concepts/glossary.md#project), в котором будет создан алерт.

     Это может быть проект, автоматически созданный для [каталога](../../resource-manager/concepts/resources-hierarchy.md#folder) (`folder__<идентификатор_каталога>`), или другой доступный проект.
  1. [Создайте канал уведомлений](../../monium/operations/alert/create-channel.md), если его нет. Для обоих алертов можно использовать один канал.
  1. На панели слева выберите ![shield-exclamation](../../_assets/console-icons/shield-exclamation.svg) **Алерты и SLO** → ![megaphone](../../_assets/console-icons/megaphone.svg) **Алерты**.
  1. Справа сверху нажмите кнопку **Создать** ![chevron-down](../../_assets/console-icons/chevron-down.svg) и выберите **Пользовательский**.
  1. В блоке **Основная информация** задайте название алерта и при необходимости добавьте описание.
  1. В блоке **Настройки алерта** последовательно задайте параметры запроса:

     * `project = folder__<идентификатор_каталога>` — укажите идентификатор каталога, в котором находятся сертификаты.

       {% note info %}
       
       По умолчанию выбран текущий [проект](../../monium/concepts/glossary.md#project). Для запроса метрик другого проекта укажите его идентификатор.
       
       {% endnote %}

     * `cluster = default`.
     * `service = certificate-manager`.
     * `certificate = *`. Для отслеживания конкретного сертификата укажите его идентификатор.

  1. Для настройки алерта о скором истечении срока действия сертификата: {#expired}

       1. В запросе укажите `name = certificate.days_until_expiration`.
       1. Используйте функцию `series_min()`, чтобы получить наименьшее число оставшихся дней среди отслеживаемых сертификатов. Если отслеживаете один сертификат, пропустите этот шаг.
       1. В блоке **Условия срабатывания** задайте **Функция сравнения** — **Меньше или равно** и пороги: **Warning** = `14`, **Alarm** = `4`.

   1. Для настройки алерта о неработоспособности сертификата: {#inoperable}

       1. В запросе укажите `name = certificate.is_out_of_order`.
       1. Используйте функцию `series_sum()`, чтобы получить количество неработоспособных сертификатов. Если отслеживаете один сертификат, пропустите этот шаг.
       1. В блоке **Условия срабатывания** задайте **Функция сравнения** — **Больше** и порог **Alarm** = `0`.

  1. Выберите функцию агрегации **Последнее**, чтобы проверять последнее доступное значение метрики в окне вычисления. При необходимости измените **Окно вычисления** и **Задержка вычисления**.

     
     Подробнее в разделе [Условия срабатывания](../../monium/concepts/alerting/alert.md#condition).


  1. В блоке **Уведомления** выберите подготовленный канал уведомлений. В поле **Отправляемые статусы** укажите `Warning` и `Alarm` для алерта об истечении срока действия или `Alarm` для алерта о неработоспособности.
  1. Нажмите **Создать**.

{% endlist %}

Создайте второй алерт, повторив шаги с другим вариантом настройки.

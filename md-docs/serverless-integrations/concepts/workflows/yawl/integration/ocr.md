# OCR

Распознавание текста на изображениях с помощью сервиса [Yandex Vision OCR](https://aistudio.yandex.ru/docs/ru/vision/concepts/ocr/).

Поля `base64`, `url`, `objectStorage` и `disk` — взаимоисключающие, можно использовать только одно из них.

Имя поля | Тип | Обязательное | Значение по умолчанию | Поддерживается [шаблонизация](../../templating.md) | Описание
--- | --- | --- | --- | --- | ---
`recognizeText` | [OCR.RecognizeText](#OCR-RecognizeText) | Да | Нет | Нет | Настройки распознавания текста.
`base64` | `string` | Нет | Нет | Да | Изображение в кодировке Base64.
`url` | `string` | Нет | Нет | Да | Изображение по публичному URL.
`objectStorage` | [OCR.ObjectStorage](#OCR-ObjectStorage) | Нет | Нет | Нет | Изображение из [бакета](../../../../../storage/concepts/bucket.md) Object Storage.
`disk` | [OCR.Disk](#OCR-Disk) | Нет | Нет | Нет | Изображение на Яндекс Диске.

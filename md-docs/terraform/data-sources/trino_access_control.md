# yandex_trino_access_control (DataSource)

Access control configuration for Trino cluster.


## Arguments & Attributes Reference

- `catalog_session_properties` [Block]. Catalog session property access control rules.
  - `allow` (*Read-Only*) (String). Whether the rule allows setting the property. Valid values: `NO`, `YES`
  - `catalog` [Block]. Catalog matcher specifying what catalogs the rule is applied to.
    - `ids` (*Read-Only*) (List Of String). Catalog IDs rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Catalog name regexp the rule is applied to.
  - `description` (*Read-Only*) (String). Rule description.
  - `groups` (*Read-Only*) (List Of String). IAM group IDs the rule is applied to.
  - `property` [Block]. Matcher specifying what properties the rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Property name regexp the rule is applied to.
    - `names` (*Read-Only*) (List Of String). Property names rule is applied to.
  - `users` (*Read-Only*) (List Of String). IAM user IDs the rule is applied to.
- `catalogs` [Block]. Catalog access control rules.
  - `catalog` [Block]. Catalog matcher specifying what catalogs the rule is applied to.
    - `ids` (*Read-Only*) (List Of String). Catalog IDs rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Catalog name regexp the rule is applied to.
  - `description` (*Read-Only*) (String). Rule description.
  - `groups` (*Read-Only*) (List Of String). IAM group IDs the rule is applied to.
  - `permission` (*Read-Only*) (String). Permission granted by the rule. Valid values: `NONE`, `READ_ONLY`, `ALL`
  - `users` (*Read-Only*) (List Of String). IAM user IDs the rule is applied to.
- `cluster_id` (**Required**)(String). ID of the Trino cluster. Provided by the client when the Access Control is created.
- `functions` [Block]. Function access control rules.
  - `catalog` [Block]. Catalog matcher specifying what catalogs the rule is applied to.
    - `ids` (*Read-Only*) (List Of String). Catalog IDs rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Catalog name regexp the rule is applied to.
  - `description` (*Read-Only*) (String). Rule description.
  - `function` [Block]. Matcher specifying what functions the rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Function name regexp the rule is applied to.
    - `names` (*Read-Only*) (List Of String). Function names rule is applied to.
  - `groups` (*Read-Only*) (List Of String). IAM group IDs the rule is applied to.
  - `privileges` (*Read-Only*) (List Of String). Privileges granted by the rule. Valid values: `EXECUTE`, `GRANT_EXECUTE`, `OWNERSHIP`.
  - `schema` [Block]. Matcher specifying what Schemas the rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Schema name regexp the rule is applied to.
    - `names` (*Read-Only*) (List Of String). Schema names rule is applied to.
  - `users` (*Read-Only*) (List Of String). IAM user IDs the rule is applied to.
- `procedures` [Block]. Procedure access control rules.
  - `catalog` [Block]. Catalog matcher specifying what catalogs the rule is applied to.
    - `ids` (*Read-Only*) (List Of String). Catalog IDs rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Catalog name regexp the rule is applied to.
  - `description` (*Read-Only*) (String). Rule description.
  - `groups` (*Read-Only*) (List Of String). IAM group IDs the rule is applied to.
  - `privileges` (*Read-Only*) (List Of String). Privileges granted by the rule. Valid values: `EXECUTE`.
  - `procedure` [Block]. Matcher specifying what procedures the rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Procedure name regexp the rule is applied to.
    - `names` (*Read-Only*) (List Of String). Procedure names rule is applied to.
  - `schema` [Block]. Matcher specifying what Schemas the rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Schema name regexp the rule is applied to.
    - `names` (*Read-Only*) (List Of String). Schema names rule is applied to.
  - `users` (*Read-Only*) (List Of String). IAM user IDs the rule is applied to.
- `queries` [Block]. Query access control rules.
  - `description` (*Read-Only*) (String). Rule description.
  - `groups` (*Read-Only*) (List Of String). IAM group IDs the rule is applied to.
  - `privileges` (*Read-Only*) (List Of String). Privileges granted by the rule. Valid values: `VIEW`, `EXECUTE`, `KILL`.
  - `query_owners` (*Read-Only*) (List Of String). Owners of queries the rule is applied to.
  - `users` (*Read-Only*) (List Of String). IAM user IDs the rule is applied to.
- `schemas` [Block]. Schema access control rules.
  - `catalog` [Block]. Catalog matcher specifying what catalogs the rule is applied to.
    - `ids` (*Read-Only*) (List Of String). Catalog IDs rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Catalog name regexp the rule is applied to.
  - `description` (*Read-Only*) (String). Rule description.
  - `groups` (*Read-Only*) (List Of String). IAM group IDs the rule is applied to.
  - `owner` (*Read-Only*) (String). Ownership granted by the rule. Valid values: `NO`, `YES`
  - `schema` [Block]. Matcher specifying what schemas the rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Schema name regexp the rule is applied to.
    - `names` (*Read-Only*) (List Of String). Schema names rule is applied to.
  - `users` (*Read-Only*) (List Of String). IAM user IDs the rule is applied to.
- `system_session_properties` [Block]. System session property access control rules.
  - `allow` (*Read-Only*) (String). Whether the rule allows setting the property. Valid values: `NO`, `YES`
  - `description` (*Read-Only*) (String). Rule description.
  - `groups` (*Read-Only*) (List Of String). IAM group IDs the rule is applied to.
  - `property` [Block]. Matcher specifying what properties the rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Property name regexp the rule is applied to.
    - `names` (*Read-Only*) (List Of String). Property names rule is applied to.
  - `users` (*Read-Only*) (List Of String). IAM user IDs the rule is applied to.
- `tables` [Block]. Table access control rules.
  - `catalog` [Block]. Catalog matcher specifying what catalogs the rule is applied to.
    - `ids` (*Read-Only*) (List Of String). Catalog IDs rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Catalog name regexp the rule is applied to.
  - `columns` [Block]. Column rules.
    - `access` (*Read-Only*) (String). Column access mode. Valid values: `NONE`, `ALL`
    - `mask` (*Read-Only*) (String). SQL expression mask to evaluate instead of original column values.
    - `name` (*Read-Only*) (String). Column name.
  - `description` (*Read-Only*) (String). Rule description.
  - `filter` (*Read-Only*) (String). Boolean SQL expression to filter table rows for particular user.
  - `groups` (*Read-Only*) (List Of String). IAM group IDs the rule is applied to.
  - `privileges` (*Read-Only*) (List Of String). Privileges granted by the rule. Valid values: `SELECT`, `INSERT`, `DELETE`, `UPDATE`, `OWNERSHIP`, `GRANT_SELECT`.
  - `schema` [Block]. Matcher specifying what Schemas the rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Schema name regexp the rule is applied to.
    - `names` (*Read-Only*) (List Of String). Schema names rule is applied to.
  - `table` [Block]. Matcher specifying what tables the rule is applied to.
    - `name_regexp` (*Read-Only*) (String). Table name regexp the rule is applied to.
    - `names` (*Read-Only*) (List Of String). Table names rule is applied to.
  - `users` (*Read-Only*) (List Of String). IAM user IDs the rule is applied to.
- `timeouts` [Block]. 
  - `read` (String). A string that can be [parsed as a duration](https://pkg.go.dev/time#ParseDuration) consisting of numbers and unit suffixes, such as "30s" or "2h45m". Valid time units are "s" (seconds), "m" (minutes), "h" (hours). Read operations occur during any refresh or planning operation when refresh is enabled.

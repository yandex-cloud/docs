# История изменений в Monium

## Апрель — июнь 2026 {#apr-jun-2026}

* Обновлена навигация в интерфейсе [Monium](https://monium.yandex.cloud) — пункты сгруппированы по тематическим разделам.
* Добавлена возможность просматривать [квоты](concepts/limits.md) ресурсов проекта и управлять ими.

* Обновления в [логах](logs/quickstart.md):
  * Добавлена возможность создавать [метрики по логам](logs/aggregates.md) в интерфейсе без написания кода. При создании доступны превью на исторических данных, автоматическая группировка значений и функция агрегации `uniqueNewFound`. Функция позволяет находить уникальные записи, не встречавшиеся за последние 48 часов.
  * Доработан раздел [Ошибки и статистика](logs/errors-and-stats.md) в интерфейсе работы с логами. В режиме _Compare_ доступно сравнение двух временных периодов или двух срезов данных по значениям атрибута. Фильтр _Новые_ показывает паттерны, появившиеся в текущем периоде, но отсутствовавшие в базовом.
  * Добавлено [руководство по миграции](logs/logging-migration.md) с Cloud Logging на платформу Monium.
  * Обновлены [лимиты для логов](logs/limits.md).

* Обновления в [SLO](slo/index.md):
  * Добавлен расчет показателя _Burn Rate_ — скорости расхода бюджета ошибок на стандартных временных окнах (5 m, 30 m, 1h, 2h, 6h, 24h, 72h).
  * Добавлен алерт для показателя Burn Rate, уведомляющий о высокой скорости расхода бюджета ошибок.
  * Добавлена возможность создавать отдельные SLO для конкретных ресурсов из общего селектора.

* Обновления в алертах:
  * [Звонки и эскалации](concepts/alerting/escalations.md) перешли на стадию [General Availability](../overview/concepts/launch-stages.md). Добавлена возможность настраивать автоматические звонки и эскалации алертов в каналах уведомлений.
  * С 18 июня 2026 года [расчет алертов](pricing.md) стал платным. Стоимость зависит от количества вычислений алертов в месяц.
  * Добавлены композитные алерты, которые отправляют единый сигнал о проблеме при одновременном срабатывании нескольких алертов.
  * В мьютах добавлены зависимые проверки. Они отключают уведомления от одного набора алертов при срабатывании другого.
  * Улучшено применение политик отсутствия данных: алерт продолжает вычисляться при отсутствии данных по отдельным метрикам и переходит в статус `No data` только при отсутствии данных по всем метрикам.
  * Добавлена возможность включать ссылки на дашборды и внешние ресурсы в уведомления алертов.

* Обновления в [трейсах](traces/index.md):
  * В поиске по спанам отображаются графики RED-метрик: количества спанов по статусам и продолжительности их выполнения.
  * Добавлена встроенная поддержка пайпов (`|`) в языке запросов к трейсам — автодополнение атрибутов и значений работает даже при условиях с пайпами.
  * Улучшено определение спанов ИИ-агентов: в поисковую выдачу LLM-мониторинга попадают все такие спаны, дерево спанов отображается корректнее.
  * Операторы `>` и `<` работают для любых числовых атрибутов, а не только для `duration`.
  * В спанах LLM-мониторинга добавлен просмотр изображений от пользователя и агента.
  * Улучшено отображение спанов с вызовами инструментов в поиске LLM-мониторинга: отображаются название инструмента, входные и выходные данные.

* Обновления в [дашбордах](visualization/index.md):
  * Добавлены снапшоты графиков — полные копии данных с постоянной ссылкой, сохраняющие конфигурацию виджета и загруженные данные.
  * Добавлены типы параметров (запрос, набор значений, текстовое поле) и зависимости между параметрами.
  * Добавлена история изменений с возможностью сравнения и восстановления выбранной версии дашборда.
  * Добавлена вкладка **Недавно удаленные** для просмотра и восстановления удаленных дашбордов в течение 30 дней с момента удаления.
  * Добавлена возможность отключать подсветку неполных данных в настройках графика.
  * В модификациях добавлены настройки для скрытия линий на графике, в подсказке или легенде.
  * Добавлена возможность отображать тепловую карту логов над графиками с метриками для быстрого анализа аномалий.
  * Добавлена возможность сохранять временные интервалы для шкалы времени.


## Январь — март 2026 {#jan-mar-2026}

* Платформа Monium доступна на стадии [General Availability](../overview/concepts/launch-stages.md).
* В [каналах уведомлений](concepts/alerting/notification-channel.md) и политиках эскалаций добавлена поддержка [Яндекс Мессенджера](https://360.yandex.ru/business/messenger/).

* Обновления в [дашбордах](visualization/index.md):
  * Добавлен виджет состояния алертов. Виджет автоматически отображает все алерты в проекте по указанному запросу, а также добавляет новые по мере их появления.
  * Добавлена поддержка горячих клавиш для базовых действий: сворачивание и разворачивание секций, переход в полноэкранный режим, сохранение дашборда, управление шкалой времени и периодом.
  * Добавлена возможность задать произвольный временной интервал и интервал автообновления для дашборда.
  * Для графиков добавлена возможность отображать несколько подсказок одновременно и переносить их с помощью курсора.
  * В блокнотах добавлена поддержка графиков Prometheus и возможность настраивать графики внутри блокнота.
  * При копировании дашборда добавлена возможность изменить проект.
  * При разбивке графика шкала по умолчанию выравнивается для всех графиков, что позволяет лучше видеть корреляции данных.

* Обновления в [трейсах](traces/index.md):
  * В поиске по спанам и в LLM-мониторинге добавлена настройка отображаемых колонок. Теперь можно вывести нужные атрибуты в колонки и сразу видеть их значения, не открывая трейс.
  * Добавлена кнопка быстрого перехода в интерфейс LLM-мониторинга из полного трейса, если в нем есть спаны с атрибутами LLM-приложений (`gen_ai.*`).
  * Добавлена возможность быстро копировать значение любого атрибута спана: при наведении на атрибут появляется кнопка копирования.
  * Добавлена возможность копировать и передавать ссылку на конкретный спан в LLM-мониторинге.
  * Оптимизирована производительность интерфейса LLM-мониторинга при работе с большими трейсами.


## Октябрь — декабрь 2025 {#oct-dec-2025}

* Платформа Monium доступна на стадии [Technical Preview](../overview/concepts/launch-stages.md). Для получения доступа обратитесь в [службу поддержки](https://center.yandex.cloud/support).
* Реализован сбор, агрегация, поиск и хранение распределенных [трассировок](traces/index.md) по стандарту [OpenTelemetry (OTLP)](https://opentelemetry.io/docs/). Это позволяет отслеживать полный путь запроса через все микросервисы и системы, что упрощает диагностику проблем и анализ производительности.
* Инструменты телеметрии — метрики, логи и трейсы объединены в одном интерфейсе. Это позволяет исследовать данные, не переключаясь между разными сервисами, и быстрее находить причину проблем. А также проводить сквозную диагностику, быстро переходя между разными видами телеметрии и связывая их между собой для точечного и детального анализа.
* Добавлена возможность отслеживать уровень надежности ваших сервисов в определенные периоды времени — [SLO](slo/index.md) (Service Level Objective).
* Реализована поддержка сбора телеметрии по стандарту OTLP.
* При миграции на платформу Monium будут автоматически перенесены ваши данные, дашборды и алерты без ручного переноса и настройки.

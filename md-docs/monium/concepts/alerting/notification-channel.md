# Канал уведомлений

Чтобы получать уведомления о переходе алерта в другой статус, необходимо указать канал уведомлений. Канал содержит информацию о получателях, методе отправки и параметрах уведомлений.

Один канал можно использовать в нескольких алертах, а один алерт может отправлять уведомления в несколько каналов.

## Параметры канала уведомлений {#channel-parameters}

* **Имя**. Название канала уведомлений.
* **ID**. Уникальный идентификатор канала. По умолчанию формируется из идентификатора проекта и имени канала.
* **По умолчанию для уровней**. Уровни алертов, для которых будут отправляться уведомления в этот канал без добавления канала к каждому алерту.
* **Получатели**. Список пользователей, которые должны получить уведомление при срабатывании алерта.

  {% note info %}

  В качестве получателя почтовых уведомлений нужно указать аккаунт в Yandex Cloud. Это может быть аккаунт владельца или специально добавленный для этих целей [дополнительный аккаунт](../../../iam/concepts/index.md#accounts), например федеративный аккаунт или Яндекс ID.

  Чтобы получать уведомления, пользователь должен:
  
  * иметь роль `monitoring.viewer` на каталог, в котором настроен алерт;
  * в [настройках](https://console.yandex.cloud/settings) консоли управления:
      * включить опцию **Мониторинг**;
      * указать адрес электронной почты, номер телефона и Telegram-аккаунт или группу.

  {% endnote %}

* **Метод**. Метод, с помощью которого пользователи получат уведомление. Поддерживаются следующие методы уведомлений:

  * `Email`.
  * `SMS`.
  * `Push-уведомления` (в [мобильном приложении](../../../overview/mobile-app/index.md) Yandex Cloud).
  * `Яндекс Мессенджер`.
  * `Telegram`.
  * `Cloud Function`.

После создания канала доступны дополнительные параметры:

* **Отправляемые статусы**. Статусы алерта, при которых Monium отправит уведомление.
* **Повторная отправка**. Интервал повторной отправки уведомления, если алерт остается в том же статусе. Не действует для статуса `OK`.

Для уведомлений в **Яндекс Мессенджер** можно включить отправку скриншота графика с метриками алерта.

## Статусы отправки {#dispatch-statuses}

Каждая отправка может находиться в одном из следующих статусов:

Статус | Описание
----- | -----
`Успешно отправлено` | Уведомление успешно отправлено.
`Не удалось отправить` | Не удалось отправить уведомление из-за ошибки.
`Invalid request` | Не удалось отправить уведомление из-за некорректных параметров канала. Повторные попытки не выполняются.
`Retry error` | Не удалось отправить уведомление из-за временной ошибки метода отправки. Monium будет выполнять повторные попытки.
`Obsolete` | Уведомление не было отправлено до следующего события в канале.
`Ресурс исчерпан` | Не удалось отправить уведомление из-за ограничения метода отправки.

# Блокноты

_Блокнот_ — инструмент для анализа телеметрии и совместной работы. В одном документе можно объединить текстовые заметки, ссылки, изображения, интерактивные графики и логи.

Блокноты полезны при расследовании инцидентов. Они помогают собрать данные из разных источников, описать ход анализа и передать контекст коллегам. В отличие от скриншота, виджеты в блокноте остаются интерактивными: можно посмотреть значения на графике, изменить отображение или сопоставить метрики с логами.

## Режимы просмотра и редактирования {#modes}

Блокнот открывается в одном из режимов:

* **Режим просмотра** — используется по умолчанию при переходе по ссылке. Содержимое доступно только для чтения, а данные виджетов обновляются автоматически.
* **Режим редактирования** — позволяет менять текст, добавлять и настраивать виджеты, изменять структуру документа.

Чтобы изменить блокнот, переключитесь в режим редактирования.

## Глобальное время {#global-time}

_Глобальное время_ — общий временной интервал, который по умолчанию применяется ко всем виджетам блокнота. Оно помогает сопоставлять графики и логи на одном таймлайне.

Для отдельного виджета можно задать локальный временной интервал. Используйте локальный интервал, если график или логи нужно изучить за период, который отличается от общего периода расследования.

## Совместная работа {#collaboration}

Блокнотом можно поделиться с коллегами по ссылке. Доступ к блокноту, как и к другим объектам Monium, определяется правами на проект.

Блокноты поддерживают:

* автосохранение — изменения сохраняются автоматически;
* автообновление — в режиме просмотра содержимое и данные виджетов периодически обновляются.

Автообновление помогает использовать блокнот как общий рабочий документ во время инцидента. Коллеги видят актуальные графики, логи и комментарии без ручного обновления страницы.

## Работа с текстом {#text}

В блокноте можно добавлять заголовки, списки, цитаты, ссылки, изображения и скриншоты. Это помогает описывать гипотезы, фиксировать выводы и оставлять ссылки на связанные тикеты или дашборды.

Добавить новый блок можно двумя способами:

* через панель инструментов;
* с помощью команды `/` в тексте.

## Виджеты {#widgets}

В блокнот можно добавить интерактивные виджеты графиков и логов.

### Виджет графика {#chart-widget}

Виджет графика отображает данные метрик. С ним можно работать прямо в блокноте: смотреть точные значения точек, менять тип визуализации, показывать или скрывать легенду.

В режиме редактирования для виджета доступны настройки графика. Они применяются только к выбранному виджету. Измените настройки, если нужно скорректировать запросы, тип визуализации или отображение конкретного графика.

Для виджета графика можно:

* скрыть элементы управления и оставить только данные;
* задать локальный временной интервал;
* создать снапшот, чтобы сохранить данные графика.

### Виджет логов {#logs-widget}

Виджет логов отображает записи логов и помогает сопоставлять события с метриками. Например, можно разместить рядом график ошибок и логи приложения за тот же период.

Для виджета логов можно задать локальный временной интервал. Это полезно, если логи нужно изучить за более короткий период, чем остальные данные в блокноте.

## Добавление существующих графиков {#add-to-notebook}

В блокнот можно добавить существующий график из дашборда или из [обзора метрик](../../metrics/metric-explorer.md). Для этого в интерфейсе графика нажмите **Добавить в блокнот** и выберите нужный блокнот.

Используйте добавление существующего графика, если во время расследования уже есть дашборд с нужным запросом или визуализацией. Это быстрее, чем настраивать виджет заново.

## Снапшоты в блокнотах {#snapshots}

{% note warning %}

Метрики в Monium хранятся ограниченное время и удаляются после истечения [TTL](../common-ttl.md). Чтобы сохранить данные графика для расследования, создайте снапшот.

{% endnote %}

_Снапшот_ фиксирует состояние графика: конфигурацию и данные метрик. После создания снапшота для виджета задается локальный временной интервал с сохраненными данными. При открытии блокнота график загружает данные снапшота вместо актуальных метрик.

Каждый виджет графика в блокноте может иметь собственный снапшот. Снапшоты можно создавать и отключать независимо друг от друга.

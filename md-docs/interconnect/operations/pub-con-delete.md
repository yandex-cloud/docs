# Удалить публичное соединение

Сейчас вы можете удалить публичное соединение только через обращение в техническую поддержку.

[Получите информацию](pub-con-get-info.md) о публичном соединении и сохраните идентификаторы соединения и транкового подключения, в котором оно создано.

Создайте [обращение в поддержку](https://center.yandex.cloud/support) со следующим содержанием:

```text
Тема: [CIC] Удаление публичного соединения.

Прошу удалить публичное соединение.

trunk_id: euus5dfgchu23b******
pbc_id: cf3qxpv5pgf692******
```

Где:

* `trunk_id` — идентификатор транкового подключения;
* `pbc_id` — идентификатор удаляемого публичного соединения.

Поддержка сообщит вам о завершении операции.

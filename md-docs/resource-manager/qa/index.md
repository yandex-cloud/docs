# Общие вопросы про Resource Manager

#### Почему у меня не получается перенести облако в другую организацию? {#transfer-issue}

Ошибка `publicAccessBindings` может возникнуть, если у пользователя есть роли на переносимое облако, его каталоги или ресурсы, но сам пользователь не добавлен в новую организацию.

Перед переносом для каждого такого пользователя нужно выполнить одно из действий:

* Добавить пользователя в новую организацию, если ему по-прежнему нужен доступ к ресурсам.
* Отозвать его роли на переносимое облако, каталоги и ресурсы, если доступ больше не нужен.

После этого можно повторить перенос. Роли федеративных пользователей в новой организации нужно назначить заново.

Подробнее — в инструкции [Изменение организации для облака](../operations/cloud/change-organization.md).

#### Я могу получить логи моей работы в сервисах? {#logs}

Да, вы можете запросить информацию о работе с вашими ресурсами из логов сервисов Yandex Cloud. Для этого обратитесь в [техническую поддержку](https://center.yandex.cloud/support).

#### Как передать облако? {#transfer-cloud}

1. [Создайте](../../organization/operations/enable-org.md) новую организацию.
1. [Добавьте](../../organization/operations/add-account.md) в нее пользователей, для которых в исходной организации назначены роли на переносимое облако, каталоги или ресурсы.

    Убедитесь, что хотя бы у одного из пользователей есть роль `organization-manager.admin` или `organization-manager.organizations.owner`.

1. [Переместите](../operations/cloud/change-organization.md) облако в новую организацию.

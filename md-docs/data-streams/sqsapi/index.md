# HTTP API, совместимый с Amazon SQS

Data Streams в ограниченном режиме поддерживает работу с потоками данных по протоколу, [совместимому с Amazon SQS](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/welcome.html) (SQS over Topics).

Основную документацию по работе с Data Streams через HTTP API, совместимый с Amazon SQS, и примеры читайте в [документации YDB](https://ydb.tech/docs/ru//reference/sqs-api/?version=v26.3).

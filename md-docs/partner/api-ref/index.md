# Yandex B2B Tech Partner Portal Public API

##version: 2.0.0##

Public API V2 of the Yandex B2B Tech Partner portal.

Base URL: https://partners.api.cloud.yandex.net/api/public/

Filtering format:
- Single field: "filter":"<field name>=<operator> \"<value>\""
- Multiple fields: "filter":"<field name>=<operator> \"<value>\";<field name>=<operator> \"<value>\""
- Array of values: "filter":"<field name>=<operator> (\"<value>\",\"<value>\")"

Supported operators: equal, startWith, contain, any, except, greater, greaterOrEqual, less, lessOrEqual, between.

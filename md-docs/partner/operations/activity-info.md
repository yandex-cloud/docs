# Посмотреть информацию об активности

В разделе ![icon](../../_assets/console-icons/list-timeline.svg) **Активности** содержится информация об использовании партнерских инструментов в рамках сделки (сделки, регламентированной сделки или проекта).

Раздел **Активности** также можно открыть из отдельной сделки, со страницы с информацией о ней.

Для активностей доступен просмотр созданной заявки.

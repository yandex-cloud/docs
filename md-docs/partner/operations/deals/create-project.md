# Создать проект

Чтобы создать [проект](../../program/var-tools.md#project-reg) в Партнерском портале:

{% list tabs group=instructions %}

- Партнёрский портал {#partner}

  1. Перейдите на [Партнёрский портал](https://partners.yandex.cloud/).
  1. На панели слева выберите ![icon](../../../_assets/console-icons/briefcase.svg) **Сделки**.
  1. В правом верхнем углу нажмите **Создать сделку**.
  1. В открывшемся окне:
     1. В поле **Название** введите название проекта.
     1. В списке **Тип** выберите **Проект**.
     1. В списке **Продукты** выберите продукты Yandex Cloud или Яндекс 360, которые потребляет ваш клиент.

        {% note warning %}

        После создания сделки изменить продукты с Yandex Cloud на Яндекс 360 и обратно нельзя.

        {% endnote %}

     1. В списке **Аккаунт** выберите аккаунт клиента. Если аккаунта еще нет, нажмите ![image](../../../_assets/console-icons/plus.svg) и заполните форму создания аккаунта по [инструкции](../create-account.md).
     1. В списке **Область действия проекта** выберите нужную область. Под этим полем появится ссылка с инструкцией для определения идентификатора области действия проекта, который пригодится на следующем шаге.
     1. В списке **Идентификатор области** укажите идентификатор области действия проекта.
     1. В поле **Сумма** укажите целевое потребление проекта.
     1. Выберите **Тип потребления**: ежемесячное или разовое.
     1. Укажите **Период закрытия** проекта. Можно указать с точностью до месяца или дня.
     1. (Опционально) Добавьте **Описание** проекта.

  1. Нажмите **Создать**. Проект появится на странице со списком сделок.

{% endlist %}

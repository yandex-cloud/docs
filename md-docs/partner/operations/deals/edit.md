# Редактировать сделку

Для редактирования в сделке доступны следующие блоки:

1. Возможность использования [партнерских инструментов](../../program/var-tools.md).
1. Статус сделки — `In process`, `Won`, `Loss`.
1. Общие сведения — название, тип, аккаунт, сабаккаунт, описание.
1. Прогноз — сумма, тип потребления, количество пользователей, общий потенциал пользователей у клиента, период закрытия.

## Редактировать статус сделки {#edit-status}

Статус сделки можно изменить из состояния `In process` в состояние `Won` или `Loss`.

Если цели сделки достигнуты, переведите ее в статус `Won`:

1. Нажмите на кнопку **Won**.
1. Подтвердите успешное закрытие сделки.

Если цели сделки не достигнуты, переведите ее в статус `Loss`:

1. Нажмите на кнопку **Loss**.
1. Выберите из списка причину проигрыша.
1. Подтвердите закрытие сделки.

## Редактировать параметры сделки {#edit-parameters}

Для редактирования доступны блоки **Общие сведения** и **Прогноз**. Чтобы редактировать эти параметры сделки в Партнерском портале:

{% list tabs group=instructions %}

- Партнёрский портал {#partner}

  1. Перейдите на [Партнёрский портал](https://partners.yandex.cloud/).
  1. На панели слева выберите ![icon](../../../_assets/console-icons/briefcase.svg) **Сделки**.
  1. Нажмите на строку с той сделкой, которую вы хотите редактировать. Откроется страница с информацией о сделке. На этой странице вы сможете редактировать каждый из блоков.
  1. Чтобы приступить к редактированию блока, нажмите ![icon](../../../_assets/console-icons/pencil.svg).

{% endlist %}

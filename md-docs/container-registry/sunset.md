# Закрытие сервиса Yandex Container Registry

{% note warning %}

Сервис Yandex Container Registry прекращает работу. На этой странице описаны сроки, порядок закрытия и рекомендации по миграции.

{% endnote %}

## Что происходит {#what-happens}

Мы приняли решение закрыть сервис Yandex Container Registry. Понимаем, что это изменение может затронуть ваши рабочие процессы, и постараемся сделать переход комфортным.

## Ключевые даты {#key-dates}

Закрытие сервиса пройдет в три этапа:

* **13 октября 2026** — прекращение новых продаж сервиса Yandex Container Registry. Клиенты, подключившие сервис ранее, смогут пользоваться им до 10 ноября 2026 года.

* **10 ноября 2026** — сервис переходит в режим read-only. Создание новых реестров станет недоступно. Текущие пользователи Yandex Container Registry смогут только просматривать ранее созданные реестры и выгружать данные из них.

* **14 декабря 2026** — сервис полностью прекращает работу. Доступ к интерфейсу сервиса будет закрыт для всех пользователей.

## Что будет с вашими данными {#data}

Ваши данные (метаданные реестров, настройки прав доступа к реестру, политики доступа для IP-адресов, политики жизненного цикла, настройки сканирования, алиасы для реестров) не будут потеряны. После закрытия сервиса резервные копии ваших данных будут храниться до 15 марта 2027 года — их можно будет запросить через [техническую поддержку](https://center.yandex.cloud/support).

## Миграция {#migration}

В качестве альтернативы перенесите свои реестры в [Yandex Cloud Registry](../cloud-registry/index.md).

Мы подготовили руководство, которое поможет при миграции: [Миграция с Container Registry на Cloud Registry](tutorials/container-registry-migration.md).

## Если у вас есть вопросы {#support}

Если у вас остались вопросы по закрытию сервиса:

* Обратитесь в [техническую поддержку](https://center.yandex.cloud/support).
* Свяжитесь с вашим аккаунт-менеджером.

Спасибо, что пользовались Yandex Container Registry.

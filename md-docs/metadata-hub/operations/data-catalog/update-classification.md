# Изменение классификации


{% note info %}

Эта функциональность находится на стадии [Preview](../../../overview/concepts/launch-stages.md).

{% endnote %}


{% list tabs group=instructions %}

- Консоль управления {#console}

  1. В [консоли управления](https://console.yandex.cloud) выберите [каталог ресурсов](../../../resource-manager/concepts/resources-hierarchy.md#folder), в котором создан каталог метаданных.
  1. [Перейдите](https://console.yandex.cloud/link/metadata-hub) в сервис **Yandex MetaData Hub**.
  1. В блоке **Управляйте метаданными** выберите **Data Catalog**.
  1. В открывшемся списке выберите каталог метаданных, в котором вы хотите изменить классификацию.
  1. Перейдите на вкладку **Теги и классификации**.
  1. В списке классификаций нажмите на значок ![image](../../../_assets/console-icons/ellipsis.svg) в строке с нужной классификацией и выберите **Редактировать**.
  1. В поле **Имя** задайте новое уникальное имя классификации.
  1. (Опционально) Измените описание классификации.
  1. (Опционально) Задайте **Правила разметки** — текстовую инструкцию для AI-разметки. Опишите правила, по которым искусственный интеллект будет присваивать этот элемент объектам каталога данных, например: какие признаки объекта должны учитываться, какие объекты размечать не нужно, требования к формулировкам.
     
       > Примеры:
     
       > * `Придумай теги для персональных данных и размечай ими колонки, если в семплах найдены персональные данные.`
       > * `Создай отдельный глоссарий для бизнес-данных и используй его для разметки. Всё, что связанно с продажами, размечай термином «продажи». Всё, что связано с географией, размечай термином «география». Заведи отдельный термин для артикулов.`
       > * `Все теги должны состоять из одного слова.`
  1. (Опционально) Включите или выключите опцию **Взаимоисключение**.

      Если опция включена, то на любой ресурс Data Catalog можно будет назначить не более одного тега классификации.

  1. Нажмите кнопку **Сохранить изменения**.

# Техническое обслуживание в Apache Hive™ Metastore

Техническое обслуживание — это сервисные работы, которые поддерживают работоспособность кластера. Техническое обслуживание включает установку обновлений и исправлений компонента Apache Hive™ Metastore, а также другие сервисные работы. Операции по техническому обслуживанию проводятся для включенных и выключенных кластеров.

Изменение мажорной версии кластера в рамках технического обслуживания не выполняется.


## Окно обслуживания {#maintenance-window}

Предпочтительное время начала технического обслуживания можно задать с помощью интерфейсов Yandex Cloud ([консоль управления](https://console.yandex.cloud), [CLI](../../cli/index.md), Terraform и [API](../../glossary/rest-api.md)) при [создании кластера](../operations/metastore/cluster-create.md) или [изменении его настроек](../operations/metastore/cluster-update.md):

* Вариант **В любое время** (по умолчанию) разрешает проводить техническое обслуживание в любое время.
* Вариант **По расписанию** позволяет выбрать день недели и интервал времени по UTC, когда будет проводиться техническое обслуживание. Например, можно выбрать время, когда кластер наименее загружен.

В консоли управления время начала обслуживания выбирается в виде часового интервала. В других интерфейсах задается порядковый номер этого интервала от `1` до `24`.

> Например, чтобы начать обслуживание в интервале с `00:00` до `01:00`, укажите `1`, а с `04:00` до `05:00` — `5`.

{% note info %}

Чтобы просматривать информацию о заданиях на техническое обслуживание, необходима роль [managed-metastore.maintenanceTask.viewer](../security/metastore-roles.md#managed-metastore-maintenanceTask-viewer) или выше.

Чтобы управлять заданиями на техническое обслуживание, необходима роль [managed-metastore.maintenanceTask.editor](../security/metastore-roles.md#managed-metastore-maintenanceTask-editor) или выше.

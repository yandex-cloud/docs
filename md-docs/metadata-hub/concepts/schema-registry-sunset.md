# Закрытие сервиса Schema Registry

{% note warning %}

Сервис Schema Registry прекращает работу. На этой странице описаны сроки, порядок закрытия и рекомендации по миграции.

{% endnote %}

## Что происходит {#what-happens}

Мы приняли решение закрыть сервис Schema Registry. Понимаем, что это изменение может затронуть ваши рабочие процессы, и постараемся сделать переход комфортным.

## Ключевые даты {#key-dates}

Закрытие сервиса пройдет в три этапа:

* **13 октября 2026** — ограничение доступа для новых пользователей в консоли. Клиенты, подключившие сервис ранее, смогут пользоваться им до 10 ноября 2026 года.

* **10 ноября 2026** — сервис переходит в режим read-only. Создание новых реестров схем данных станет недоступно. Текущие пользователи Schema Registry смогут только просматривать ранее созданные ресурсы.

* **14 декабря 2026** — сервис полностью прекращает работу. Доступ к интерфейсу сервиса будет закрыт для всех пользователей.

## Что будет с вашими данными {#data}

Ваши данные (реестры схем, пространства имен, схемы и субъекты) не будут потеряны. После закрытия сервиса резервные копии ваших данных будут храниться до 31 января 2027 года — их можно будет запросить через [техническую поддержку](https://center.yandex.cloud/support).

## Если у вас есть вопросы {#support}

Если у вас остались вопросы по закрытию сервиса:

* Обратитесь в [техническую поддержку](https://center.yandex.cloud/support).
* Свяжитесь с вашим аккаунт-менеджером.

Спасибо, что пользовались Schema Registry.

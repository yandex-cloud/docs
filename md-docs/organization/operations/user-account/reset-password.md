# Сбросить пароль для входа в консоль управления Yandex Cloud

Администратор организации Yandex Identity Hub может разрешить пользователям самостоятельно сбрасывать свои пароли.

{% note warning %}

Самостоятельно сбрасывать пароль в Yandex Cloud могут только [локальные](../../../iam/concepts/users/accounts.md#local) пользователи, в отношении которых соблюдаются следующие условия:
* эти пользователи добавлены в целевую группу [политики MFA](../../concepts/mfa.md#mfa-policies), которая разрешает пользователям сбрасывать пароли;
* в профилях этих пользователей настроены [факторы MFA](../../concepts/mfa.md#mfa-factors), необходимые для сброса пароля.

{% endnote %}

Чтобы сбросить свой пароль для входа в [консоль управления](../../../console/quickstart/console.md) Yandex Cloud:

1. Перейдите на страницу [консоли управления](https://console.yandex.cloud).
1. В поле для ввода введите ваш логин и нажмите кнопку ![arrow-right](../../../_assets/console-icons/arrow-right.svg).
1. В открывшемся окне ввода пароля нажмите **Не могу вспомнить пароль**.
1. В окне сброса пароля нажмите **Продолжить**.
1. Следуйте инструкциям на экране, чтобы подтвердить вашу личность с помощью предложенных способов аутентификации:

    {% list tabs %}

    - Приложение для аутентификации {#app-auth}

      1. Выберите подтверждение входа по одноразовому коду.
      1. Откройте добавленное ранее в качестве фактора MFA **Приложение для аутентификации**, например:

          * [Яндекс ID](https://yandex.ru/id/about).
          * [Google Authenticator](https://support.google.com/accounts/answer/1066447).
          * [Microsoft Authenticator](https://www.microsoft.com/ru-ru/security/mobile-authenticator-app).
          * [Multifactor](https://multifactor.ru/docs/saml/yandex-cloud-2fa/).
      1. В списке подключенных сервисов приложения для аутентификации найдите ваш аккаунт Yandex Cloud и в окне браузера в поле **Введите код из приложения для аутентификации** введите относящийся к этому аккаунту одноразовый код.
      1. Нажмите кнопку **Далее**.

    - Ключ безопасности {#key-auth}

      1. Выберите подтверждение входа по ключу безопасности.
      1. Подключите физический ключ безопасности, например [Рутокен](https://www.rutoken.ru/) или [JaCarta](https://www.aladdin-rd.ru/catalog/jacarta), к компьютеру.
      1. Следуйте инструкциям в браузере для верификации с помощью ключа.

    - Биометрия {#bio-auth}

      1. Выберите подтверждение входа по лицу или отпечатку пальца.
      1. Следуйте инструкциям в браузере для верификации с помощью биометрии.

    {% endlist %}

1. Если в вашем аккаунте настроены необходимые для сброса пароля факторы MFA и вы успешно пройдете предложенные проверки, откроется окно ввода нового пароля. В этом окне:

    1. Дважды введите новый пароль.
    1. Нажмите кнопку **Сохранить пароль**.

В результате для вашей учетной записи будет установлен новый пароль, и вы сможете использовать его для входа в [консоль управления](../../../console/quickstart/console.md) Yandex Cloud.

Если в организации не настроена политика MFA, разрешающая пользователям сбрасывать свои пароли, или в ваш аккаунт не добавлены факторы MFA, позволяющие проверить вашу личность при сбросе пароля, самостоятельно сбросить пароль вы не сможете. В таких случаях для сброса пароля обратитесь к администратору вашей организации.

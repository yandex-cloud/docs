# Настроить брендирование



{% note info %}

Функциональность находится на стадии [Preview](../../overview/concepts/launch-stages.md).

{% endnote %}

## Настроить графическое оформление страницы входа {#appearance}

Чтобы настроить [графическое оформление](../concepts/branding.md#appearance) страницы входа:

{% list tabs group=instructions %}

- Интерфейс Cloud Center {#cloud-center}

  1. Войдите в сервис [Yandex Identity Hub](https://center.yandex.cloud/organization) с учетной записью администратора или владельца организации.
  1. На панели слева выберите ![brush](../../_assets/console-icons/brush.svg) **Брендирование**.
  1. В блоке **Цвета и изображения** настройте по отдельности темную и светлую цветовые темы:

      {% note info %}

      Встроенный редактор позволяет подготовить логотип или фавиконку к загрузке: обрезать лишний фон, изменить масштаб и выстроить композицию. Поддерживаются изображения в форматах `WebP`, `PNG`, `JPEG` и `JPG`.

      {% endnote %}

      1. **Фоновое изображение** — выберите изображение, которое будет использоваться в качестве фона страницы (до 3840×2160 px, до 4 МБ).
      1. **Логотип** — выберите изображение, которое будет отображаться в верхней части формы (от 1920×1920 px, до 512 КБ).
      1. **Фавиконка** — выберите изображение, которое будет отображаться во вкладке браузера рядом с названием сайта (до 512×512 px, до 512 КБ).
      1. **Основной цвет** — выберите цвет кнопок и рамок для текстовых полей.
  1. Чтобы сохранить изменения, нажмите **Сохранить**.

{% endlist %}

## Настроить способы входа {#login-options}

Чтобы настроить [способы входа](../concepts/branding.md#login-options) пользователей:

{% list tabs group=instructions %}

- Интерфейс Cloud Center {#cloud-center}

  1. Войдите в сервис [Yandex Identity Hub](https://center.yandex.cloud/organization) с учетной записью администратора или владельца организации.
  1. На панели слева выберите ![brush](../../_assets/console-icons/brush.svg) **Брендирование**.
  1. Чтобы включить автоматическое перенаправление пользователей для входа через [федерацию удостоверений](../concepts/add-federation.md):

      1. В блоке **Автоматический вход** включите опцию **Перенаправление в федерацию удостоверений**.
      1. В появившемся поле **Федерация** выберите федерацию удостоверений, через которую будет выполняться автоматический вход пользователей в приложения.

      {% note info %}

      Если включена опция **Перенаправление в федерацию удостоверений**, другие настройки входа пользователей в разделе **Брендирование** становятся недоступны, а пользователям не предлагается выбор способов входа.

      {% endnote %}

  1. Чтобы настроить способы входа, которые будут доступны пользователям в форме входа:

      1. Убедитесь, что опция **Перенаправление в федерацию удостоверений** в блоке **Автоматический вход** отключена.
      1. В блоке **Форма входа**:

          1. В поле **Приветствие** введите текст, который будет отображаться под логотипом.
          1. В поле **Подсказка** введите текст подсказки, которая будет отображаться в поле ввода логина.

              {% note info %}

              По умолчанию поле ввода логина отображается в форме входа. Чтобы скрыть его, отключите опцию **Ввод логина**.

              {% endnote %}

          1. Чтобы отключить возможность входа пользователей через Яндекс ID, отключите опцию **Яндекс ID**.

              По умолчанию возможность входа через Яндекс ID включена.
          1. Чтобы отключить возможность входа пользователей через [SSO](../../glossary/sso.md), отключите опцию **Single-Sign On**.

              По умолчанию возможность входа через SSO включена.
          1. Чтобы добавить в форму дополнительные кнопки входа через федерации удостоверений, включите опцию **Федерация удостоверений** и укажите:

              1. В поле **Федерация** выберите федерацию удостоверений, для входа через которую вы добавляете кнопку.
              1. В поле **Имя кнопки** введите текст кнопки.
              1. Чтобы добавить дополнительную кнопку для входа через еще одну федерацию удостоверений, нажмите кнопку **Добавить** и укажите данные для новой кнопки.

                  На страницу входа вы можете добавить до трех кнопок входа через федерации удостоверений.
  1. Чтобы сохранить изменения, нажмите **Сохранить**.

{% endlist %}

{% note tip %}

Чтобы сбросить внесенные изменения и настроить брендирование заново, нажмите кнопку ![broom-motion](../../_assets/console-icons/broom-motion.svg) **Сбросить все**, затем кнопку **Сохранить**. При этом будут сброшены как настройки графического оформления, так и параметры входа.

{% endnote %}

# Синхронизация пользователей и групп с внешними службами каталогов


Если для управления пользователями ваша компания использует службу каталогов и вы хотите организовать для ваших пользователей доступ к Yandex Cloud, вам не нужно создавать учетные записи для них вручную. Вместо этого вы можете [синхронизировать](../../operations/sync-external/index.md) с Yandex Identity Hub пользователей и группы из каталога вашей компании.

В настоящее время пользователей из внешних каталогов можно синхронизировать только с [локальными пользователями](../../../iam/concepts/users/accounts.md#local) Yandex Cloud в пределах [пулов пользователей](../user-pools.md).

Синхронизация пользователей и групп выполняется специальной утилитой — _агентом синхронизации Yandex Identity Hub Sync Agent_. Агент синхронизации может быть запущен на любом сервере под управлением ОС [Linux](https://ru.wikipedia.org/wiki/Linux) или [Windows](https://ru.wikipedia.org/wiki/Windows). При этом схема синхронизации, синхронизируемые атрибуты и настройки агента зависят от типа службы каталогов и операционной системы хоста, на котором запущен агент.

Yandex Identity Hub поддерживает синхронизацию со следующими типами служб каталогов:

* [Microsoft Active Directory](ad-sync.md);
* [LDAP-совместимые каталоги](ldap-sync.md).

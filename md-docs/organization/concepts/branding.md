# Брендирование


{% note info %}

Функциональность находится на стадии [Preview](../../overview/concepts/launch-stages.md).

{% endnote %}

В Yandex Identity Hub вы можете настраивать внешний вид страниц аутентификации и формы входа, чтобы они соответствовали вашему корпоративному стилю и предпочтениям. Кроме того, брендирование позволяет настраивать способы входа, доступные пользователям.

Брендирование страниц аутентификации работает при входе через SSO как во внешние [приложения](applications/index.md), так и в сервисы Yandex Cloud. При входе в сервисы Yandex Cloud брендирование работает со следующими особенностями:

* При переходе в сервис по обычной ссылке исходная страница аутентификации сервиса не будет содержать брендирования. Брендированная страница входа откроется после ввода имени пользователя.

    Пример обычной ссылки: `https://datalens.ru`
* При переходе в сервис по прямой ссылке, содержащей идентификатор [пула пользователей](user-pools.md), брендированная страница входа откроется сразу.

    Пример прямой ссылки: `https://datalens.ru/federations/ek0o6g0irskn********`
    
    Где `ek0o6g0irskn********` — идентификатор пула пользователей.

Настроить брендирование могут только пользователи с [ролью](../security/index.md) `organization-manager.admin` или `organization-manager.organizations.owner`.

{% note info %}

Функциональность доступна только для организаций, в которых [оплачен лимит](../pricing.md) пользователей Yandex Identity Hub, использующих SSO для внешних приложений. Если лимит был оплачен ранее, но в новом месяце оплаты не было, то брендирование прекратит работать.

{% endnote %}

## Настройки графического оформления страницы входа {#appearance}

{% note tip %}

Графическое оформление настраивается отдельно для светлой и темной цветовой темы.

{% endnote %}

Настройки графического оформления страницы входа включают в себя следующие возможности:

* настройка цвета кнопок и рамок для текстовых полей;
* загрузка собственных изображений в форматах `WebP`, `PNG`, `JPEG`, `JPG`:

    * фоновое изображение (до 3840×2160 px, до 4 МБ);
    * логотип для верхней части формы (от 1920×1920 px, до 512 КБ);
    * фавиконка (до 512×512 px, до 512 КБ);
* редактирование изображений для логотипов и фавиконок перед загрузкой.
    
    Встроенный редактор позволяет подготовить логотип или фавиконку к загрузке: обрезать лишний фон, изменить масштаб и выстроить композицию.

## Настройки способов входа {#login-options}

Брендирование включает в себя следующие возможности по управлению способами входа и текстовыми подсказками:

* настройка текста приветствия;
* настройка текста подсказки, которая будет отображаться в поле ввода логина;
* возможность скрывать поле ввода;
* настройка автоматического перенаправления пользователей для входа через определенную [федерацию удостоверений](add-federation.md);

    {% note info %}

    Когда включена опция автоматического перенаправления, пользователям не отображается форма входа в приложения.

    {% endnote %}

* включение и отключение отдельных способов входа:

    * с помощью Яндекс ID;
    * через [SSO](../../glossary/sso.md);
    * через федерации удостоверений: на страницу входа можно добавить до трех отдельных кнопок входа через федерации.

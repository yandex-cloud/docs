# Интеграции с внешними системами

On-premises Yandex Object Storage поддерживает следующие опциональные интеграции с внешними системами:

* *Корпоративный провайдер идентификации (IdP).* Подключается через Zitadel и позволяет использовать корпоративные учетные записи для аутентификации пользователей административной консоли.

* *Внешняя система мониторинга.* Может собирать метрики хранилища через эндпоинт Prometheus Federation и использовать их в собственных дашбордах и правилах оповещения.

* *Система управления событиями информационной безопасности (SIEM).* Может получать аудитные логи хранилища в формате syslog для централизованного хранения и анализа.

Интеграции подключаются независимо друг от друга в зависимости от требований.

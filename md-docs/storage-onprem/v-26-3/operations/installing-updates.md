# Установка обновлений

Обновить On-premises Yandex Object Storage можно с помощью CLI. Перед началом получите архив обновления `yc-storage-<версия>.tar.gz`, [инициализируйте CLI и аутентифицируйтесь](../quickstart.md#create-tenant) с учетной записью администратора.

{% note info %}

Вы можете обновлять продукт в процессе использования. При обновлении Object Storage возможна временная деградация производительности или недоступность S3 API строго по одному из адресов. Доступность S3 API в целом не нарушается.

{% endnote %}

1. Загрузите и распакуйте архив:

    ```bash
    cli ops updates upload <путь_к_архиву> --wait
    ```

    Параметр `--wait` позволяет дождаться завершения распаковки.
    
    Загрузка архива выполняется через эндпоинт S3 API. Если для S3 API используется сертификат внутреннего центра сертификации, укажите путь к файлу с сертификатами этого центра в параметре `--ca-bundle`.

    ```bash
    cli ops updates upload <путь_к_архиву> \
      --ca-bundle <путь_к_сертификатам> \
      --wait
    ```

    Также можно отключить проверку сертификата с помощью параметра `--no-verify-ssl`. Обратите внимание, что параметр `--insecure` не устранит ошибку — он отключает проверку сертификата консоли управления, а архив загружается через S3 API.

1. Получите список доступных обновлений после завершения распаковки:

    ```bash
    cli ops updates available
    ```

    В таблице отображаются версия (`Version`) и время создания (`Created`) обновления.

1. Установите нужную версию из списка:

    ```bash
    cli ops updates install <версия> --wait
    ```

    Дождитесь завершения задачи установки.

Подробнее о командах и их параметрах [в справочнике CLI](../../cli-ref/cli.md).

## Изменения базовых возможностей {#base}

* На панели слева добавили раздел ![image](../../_assets/console-icons/ellipsis.svg) **Все страницы**. При нажатии на него справа откроется дополнительная панель с полным списком разделов. В ней вы можете настроить отображение разделов на панели слева.


* Добавили раздел [Рассылки](../concepts/maillists-list.md), в котором можно посмотреть список всех рассылок.

  Для каждого элемента списка отображаются параметры рассылки и кнопки, которые позволяют подписаться на нее или отписаться.

  {% cut "Список рассылок" %}

  ![maillist-list](../../_assets/datalens/release-notes/maillists-list.png)

  {% endcut %}

* Теперь в [рассылках для дашбордов](../operations/dashboard/add-maillists.md) можно добавить анализ от Нейроаналитика. Для этого при настройке рассылки укажите свой вопрос в поле **Промпт**. Ответ Нейроаналитика будет включен в содержание письма рассылки.
* В [Галерее](../concepts/gallery.md) появились новые возможности:

  * поиск по автору;
  * новая сортировка;
  * новые фильтры;
  * отметка **Работа месяца**;
  * кнопка **Обсудить** на карточке.

  Добавили новые работы в [Галерее](https://datalens.ru/gallery). Подробнее в чате [DataLens](https://telemost.360.yandex.ru/join#01a309da-b9a8-4167-9892-b72f1ec1bff0/1789574497766061) в Яндекс Телемосте.

* Добавили возможность публикации дашборда в воркбуке по [временной ссылке](../concepts/datalens-temporary-link.md). Время действия ссылки можно настроить от одного часа до суток. Пока ссылка активна, любой пользователь может перейти по ней и посмотреть дашборд без авторизации.

* Обновили навигацию в коллекциях и воркбуках. Чтобы открыть окно навигации, на панели слева нажмите **Навигация**. На экране отобразится корневая коллекция и дерево всех коллекций, воркбуков и объектов, которые в ней расположены.
  
  Для удобства вы можете открыть слева панель навигации с деревом всех коллекций, воркбуков и объектов. Также на панели отображаются списки **Избранное** и **Недавние**.

* Добавили [datalens-sdk](https://pypi.org/project/datalens-sdk/) — типизированный Python SDK для API DataLens. [Используйте](../operations/ai-agents.md) для работы с DataLens набор [AI-агентов](../concepts/ai-agents.md). Они могут создавать и изменять подключения, датасеты, чарты и дашборды, анализировать зависимости между объектами, клонировать и переносить контент между воркбуками.

* Реализовали новый [DataLens Platform](https://datalens.ru/platform).
  
  Теперь DataLens — аналитическая платформа, которая покрывает загрузку, хранение, обработку, анализ и визуализацию данных в едином контуре:
  
  * один продукт вместо набора инструментов и сервисов;
  * совместимость компонентов «из коробки»;
  * единое рабочее пространство для инженеров, аналитиков и бизнес-пользователей;
  * варианты поставки: облако, собственный контур (on-premises) и гибрид.



## Исправления и улучшения {#fixes}


* В [картах](../visualization-ref/map-chart.md) исправили отображение названий показателей в подсказках слоя **Полилинии (геоточки)**.
* В чарте [График (Gravity UI Charts)](../charts/editor/widgets/gravity-ui.md) подписи на оси **X** теперь учитывают выбранный формат даты в линейных, столбчатых и точечных диаграммах.
* В Public API исправили схемы для вкладки [Activities](../charts/editor/tabs.md#activities).

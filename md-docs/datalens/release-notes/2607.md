# История изменений в Yandex DataLens в июле 2026

* [Изменения базовых возможностей](#base)

## Изменения базовых возможностей {#base}

* Добавили новый раздел — [HTML-страницы](https://datalens.ru/pages). Функциональность позволяет пользователям DataLens [загружать HTML-страницы](../html-pages/index.md) в воркбук или папку и делиться ими с другими пользователями с учетом прав [доступа](../security/index.md).
  
  При подготовке HTML-страниц используйте скилл на [GitHub](https://github.com/datalens-tech/datalens-skills), в котором собраны ограничения и инструкции по генерации.


* В [версионирование датасета](../dataset/versioning.md) добавили возможность создавать черновую версию. Основные пользователи не видят изменений, которые вносятся в черновик. Это позволяет скрывать редактирование датасета до актуализации версии.
* Добавили новый тип визуализации — [Воронка](../visualization-ref/funnel.md). Новая диаграмма показывает последовательное уменьшение значений показателя по этапам. Каждый этап воронки представляет собой сегмент, ширина которого соответствует значению показателя.

  Подходит для анализа процессов, где данные последовательно проходят через несколько этапов. Например, для анализа воронки продаж — от просмотра товара до покупки — или для анализа конверсии пользователей на разных этапах регистрации.

  {% cut "Пример" %}

  ![funnel-chart](../../_assets/datalens/visualization-ref/funnel-chart/funnel-chart.png =800x)

  {% endcut %}

  Особенности использования:

  * Этапы воронки можно задавать как измерением, так и набором показателей.
  * Проценты в подписях и тултипах можно считать как от начального, так и от предыдущего этапа.
  * В подписи можно добавить несколько показателей [Measure Values](../concepts/chart/measure-values.md) с разным форматом: чтобы показывать и абсолютные значения, и проценты.


* Добавили настройку выравнивания для [таблиц](../visualization-ref/table-chart.md#additional-settings) и [сводных таблиц](../visualization-ref/pivot-table-chart.md#set-column-align).

## Исправления и улучшения {#fixes}

* Реализовали сохранение пользовательских настроек чата с Нейроаналитиком: ширину и положение на экране — поверх или сбоку от контента. После перезагрузки страницы настройки восстанавливаются. Также увеличили минимальную ширину чата до 400 px.
* В селекторах на дашборде исправили отображение подсказок при использовании формул.
* Исправили проблему, при которой на некоторых версиях iOS после выбора значения селектора оно сразу сбрасывалось.
* Исправили [фильтрацию чартов чартами](../dashboard/chart-chart-filtration.md) для карт в браузерах Firefox и Safari.


* В [настройках сервиса](../settings/index.md) обновили дизайн диалога подключения [платежного аккаунта](../settings/service-plan.md#billing-account).
* Исправили некорректное отображение «хлебных крошек» при открытии чарта в воркбуке.


### Исправления в подключениях {#connection-fixes}

* В подключениях к [Google Sheets](../operations/connection/create-google-sheets.md) исправили ошибки при авторизации в Google для таблиц с ограниченным доступом.
* Для подключения [API Connector](../operations/connection/create-api-connector.md#restrictions) добавили в разрешенные методы `PUT` и `PATCH`.
* Исправили проблему, при которой состояние настройки [запрета экспорта](../concepts/chart/data-export.md#data-export-disable) данных в подключениях к [файлу](../operations/connection/create-file.md), [Яндекс Документам](../operations/connection/create-yadocs.md) и [Google Sheets](../operations/connection/create-google-sheets.md) не соответствовало фактической возможности экспорта.

### Исправления в датасетах {#dataset-fixes}

* Исправили ошибку с указанием времени в датасетах на вкладке **Фильтрация** для типа поля `Дата и время`, при которой происходило смещение времени на величину часового сдвига таймзоны пользователя.
* Добавили информацию о возможности редактирования источника в форме изменения источников датасета.

### Исправления в отчетах {#report-fixes}

* Исправили ошибку [экспорта отчета](../reports/report-operations.md#report-export), при которой в виджете **Чарт** с типом **Таблица** текст внутри ячейки экспортировался некорректно.

### Исправления на дашборде {#dashboard-fixes}

* Исправили проблему, из-за которой при многократных быстрых нажатиях на чарт на дашбордах исчезал виджет.
* Исправили проблему открытия подсказок в закрепленных виджетах на мобильных устройствах.
* Устранили одновременное открытие двух окон выбора [цвета фона](../dashboard/settings.md#dashboard-background) на дашбордах в браузере Safari.

### Исправления в чартах {#chart-fixes}

* Исправили отображение легенды при раскраске чартов по показателю.
* В чартах, которые открыты с дашборда, исправили некорректное отображение пустых значений в секции **Фильтры с дашборда**.
* Исправили проблему [прямого экспорта](../concepts/chart/data-export.md#save-data) в формате `XLSX`, при которой бесконечно отображался индикатор прогресса, если в строке итогов присутствовала невалидная дата.
* Исправили проблему настройки цветов в секции **Цвета** при использовании пользовательской палитры по умолчанию. Раньше цвета появлялись только после переключения на другую палитру и обратно. Теперь все цвета сразу доступны для выбора.
* Исправили отображение [столбчатой диаграммы](../visualization-ref/column-chart.md) с сортировкой и группировкой по полю из секции **Цвета**.
* Для [нормированной диаграммы с областями](../visualization-ref/normalized-area-chart.md) в настройках оси **Y** убрали опцию **Режим отображения**, которая показывалась ошибочно.
* В [круговой диаграмме](../visualization-ref/pie-chart.md) исправили отображение чарта с маленьким размером сектора.
* Для чартов в Editor исправили проблему, при которой в селекторах, связанных с датасетами, не отображались добавленные вручную параметры.

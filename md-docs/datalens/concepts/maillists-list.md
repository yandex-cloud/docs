# Список рассылок в Yandex DataLens

Чтобы посмотреть список всех рассылок, на панели слева нажмите ![image](../../_assets/console-icons/envelope.svg) **Рассылки**. Если на панели не отображается ![image](../../_assets/console-icons/envelope.svg), сначала выберите ![image](../../_assets/console-icons/ellipsis.svg) **Ещё**, а затем — ![image](../../_assets/console-icons/envelope.svg) **Рассылки**.

![maillist-list](../../_assets/datalens/dashboard/maillists-list.png)

Вы также можете открыть список рассылок для текущего воркбука. Для этого вверху воркбука нажмите ![image](../../_assets/console-icons/ellipsis.svg) → ![image](../../_assets/console-icons/envelope.svg) **Рассылки**.

Для каждого элемента списка отображаются параметры:

* Название рассылки.
* Состояние рассылки: ![image](../../_assets/console-icons/circle-play.svg) **Активна** или ![image](../../_assets/console-icons/circle-pause.svg) **На паузе**.
* Если вы подписаны на рассылку, отображается ![image](../../_assets/console-icons/bell.svg) **Вы подписаны**.
* Название дашборда или отчета, для которого создана рассылка.
* Расписание рассылки.
* Количество получателей рассылки.
* Кнопка ![image](../../_assets/console-icons/bell.svg), чтобы подписаться на рассылку, или ![image](../../_assets/console-icons/bell-slash.svg), чтобы отписаться от нее. Кнопка ![image](../../_assets/console-icons/bell.svg) отображается только для пользователей, которые могут подписаться на рассылку: только редактор и администратор (по умолчанию) или любой пользователь. Настройку можно задать в рассылке на вкладке **Получатели**.

Вы можете воспользоваться фильтрами вверху списка:

* **Объект** — выберите из списка объект (коллекцию, воркбук, дашборд или отчет), в котором создана рассылка.
* **Статус** — выберите статус рассылки: `Активна`, `На паузе` или `Ошибка`.
* **Получатель** — выберите получателя рассылки.
* **Я подписан** — нажмите, чтобы отобразить только рассылки, на которые вы подписаны.
* ![image](../../_assets/console-icons/arrow-rotate-left.svg) **Сбросить** — нажмите, чтобы сбросить все фильтры. Доступна, если применен хотя бы один фильтр.

При [открытии списка рассылок из воркбука](../workbooks-collections/workbooks-operations.md#maillist-list) автоматически будет задан фильтр **Объект** по этому воркбуку.

Справа от фильтра вы можете задать сортировку:

* **Больше получателей** — по количеству получателей.
* **Сначала новые** — по дате создания.

Нажав на рассылку, вы перейдете на страницу объекта (дашборда или отчета), для которого она создана.

Вы можете подписаться или отписаться от рассылки прямо из списка:
     
* Чтобы подписаться на рассылку, справа от нее нажмите ![image](../../_assets/console-icons/bell.svg) (**Подписаться**). Кнопка ![image](../../_assets/console-icons/bell.svg) отображается только для пользователей, которые могут подписаться на рассылку: только редактор и администратор (по умолчанию) или любой пользователь. Настройку можно задать в рассылке на вкладке **Получатели**.
* Чтобы отписаться от рассылки, справа от нее нажмите ![image](../../_assets/console-icons/bell-slash.svg) (**Отписаться**).

{% note info %}

* Чтобы пользователь смог получать рассылку, ему требуется активное рабочее место.
* Рассылку могут получать только пользователи, у которых есть роль на воркбук, в котором настроена эта рассылка.

{% endnote %}

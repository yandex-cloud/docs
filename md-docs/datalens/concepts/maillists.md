# Добавление рассылки в Yandex DataLens

Вы можете настроить [рассылку для дашборда](../operations/dashboard/add-maillists.md) по электронной почте. В письме адресаты получат ссылки на те состояния дашборда и чартов, которые задаются в настройках рассылки. Можно настроить состояние селекторов на дашборде, расписание, размеры чартов и другие параметры. Рассылки доступны только для актуальной версии дашборда.

Вы также можете настроить [рассылку для отчета](../reports/add-report-maillists.md) по электронной почте. В письме адресаты получат файл формата `.pdf` с теми страницами отчета, которые задаются в настройках рассылки. Можно настроить расписание и получателей рассылки.

{% note info %}

* Добавить и изменить рассылку может пользователь с [ролью](../security/roles.md#datalens-workbooks-editor) `Редактирование` и выше на воркбук.
* Рассылки доступны только для дашбордов и отчетов, расположенных в [воркбуках](../workbooks-collections/index.md).
* [RLS](../security/row-level-security.md) в рассылках не поддерживается.
* Если в рассылке используются [общие объекты](../security/workbooks-access-advanced.md), то поддерживаются только те из них, в которых настроена делегация прав доступа.

{% endnote %}

Рассылку могут получать только пользователи, у которых есть роль на воркбук, в котором настроена эта рассылка.

Наличие прав пользователя на воркбук проверяется при добавлении пользователя в рассылку и при каждой ее отправке.

Пользователь с ролью `Администрирование` (`datalens.workbooks.admin`) на воркбук может добавить в рассылку любого пользователя. При добавлении в рассылку пользователя без роли на воркбук, ему будет автоматически назначена минимальная роль `Ограниченный просмотр` (`datalens.workbooks.limitedViewer`) на этот воркбук.

Пользователь с ролью `Редактирование` (`datalens.workbooks.editor`) на воркбук может добавить в рассылку только пользователя с ролью на воркбук. Остальные пользователи заблокированы для добавления.

Пользователь с доступом к воркбуку (минимальная роль `Ограниченный просмотр`), в котором хранится рассылка, может подписаться на нее.

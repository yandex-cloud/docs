# Добавление рассылки в Yandex DataLens

Вы можете настроить [рассылку для дашборда](../operations/dashboard/add-maillists.md) по электронной почте. В письме адресаты получат ссылки на те состояния дашборда и чартов, которые задаются в настройках рассылки. Можно настроить состояние селекторов на дашборде, расписание, размеры чартов и другие параметры. Рассылки доступны только для актуальной версии дашборда.

Вы также можете настроить [рассылку для отчета](../reports/add-report-maillists.md) по электронной почте. В письме адресаты получат файл формата `.pdf` или `.pptx` с теми страницами отчета, которые задаются в настройках рассылки. Можно настроить расписание и получателей рассылки.

{% note info %}

* Добавить и изменить рассылку может пользователь с ролью `datalens.admin`.
* Рассылки доступны только для дашбордов и отчетов, расположенных в [воркбуках](../workbooks-collections/index.md).

{% endnote %}

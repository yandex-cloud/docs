# Обучающие курсы и материалы по Yandex DataLens

Вы можете получить больше знаний о DataLens и научиться использовать их для решения конкретных практических задач с помощью обучающих онлайн-курсов и полезных материалов.

## Бесплатные курсы {#free-courses}


[DataLens: анализ и визуализация данных](https://yandex.cloud/ru/training/datalens)

:   Базовый курс по основам работы с DataLens на платформе Яндекс Практикум. Подготовлен командой продукта, аналитиками Яндекса и внешними экспертами. Рекомендуем начинать погружение в DataLens именно с него.

[Основы работы с DataLens](https://stepik.org/course/213818/promo)

:   Курс по основам работы с DataLens на платформе Stepik.

[Архитектура и разработка DWH](https://yandex.cloud/ru/training/dwh-scenario)

:   Сценарий построения аналитического хранилища данных в Yandex Cloud.

## Платные курсы {#paid-courses}

[Визуализация данных в Yandex DataLens](https://productstar.ru/course/vizualizaciia-dannyx-v-yandex-datalens)

:   Курс от платформы ProductStar по визуализации данных в DataLens.

[Книга Романа Бунина «От дашборда к системе: как построить аналитику в компании»](https://datalens.ru/book/)

:   Книга, которая поможет построить BI-систему как полноценный продукт с продуманными бизнес-процессами и измеримой ценностью для компании.

Книга Александра Гинько «Анализ и визуализация данных в Yandex DataLens» в двух изданиях

:   [Книга](https://t.me/YandexDataLens/28631/149589) подробно рассказывает о Yandex DataLens — одном из мощнейших средств анализа и визуализации данных. [Второе издание](https://t.me/alexanderginko_books/424) содержит много практических разделов, проектов с применением ML и подробное описание инструмента Editor.

[Yandex DataLens Festival 2025](https://datalens.ru/festival)

:   Образовательный фестиваль с примерами и кейсами партнеров. В программе вас также ждет сравнение DataLens с лидерами рынка — Power BI, Tableau и Superset. Кроме того, вы изучите особенности построения корпоративной аналитики в облаке: хранилище, ETL и безопасность.

[Yandex DataLens Festival 2024](https://datalens.ru/festival/2024)

:   Новые возможности инструмента, сценарии использования и практические кейсы, которые помогут решить вашу бизнес-задачу с DataLens.

[Yandex DataLens Festival 2023](https://datalens.ru/festival/2023)

:   Как построить аналитику в облаке, организовать командную работу в BI-системе и использовать open source для своих задач.

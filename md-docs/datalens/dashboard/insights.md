# Нейроаналитик на дашборде в Yandex DataLens


[Нейроаналитик](../concepts/neuroanalyst.md) — AI-агент, который анализирует датасет, на основе которого построен дашборд, и может в качестве ответа подобрать чарт или построить новый чарт. При построении чартов Нейроаналитик использует датасет и чарты с эталонной вкладки, которую можно выбрать в [настройках дашборда](../operations/dashboard/dashboard-ai-reference-tab.md).

Помимо датасета, на основе которого построен дашборд, в качестве контекста также учитываются:
* [информация о дашборде](../operations/dashboard/add-description.md);
* заголовок чарта на дашборде;
* [информация о чарте](../operations/chart/add-description.md);
* [описание и подсказка](../operations/dashboard/add-chart.md) для чарта на дашборде (кроме таблиц).

## Использование Нейроаналитика на дашборде {#how-to}

Нейроаналитик на дашборде можно использовать для вкладки дашборда или для отдельных чартов на дашборде. Чтобы использовать Нейроаналитик на дашборде:

{% list tabs %}

- Для вкладки дашборда

  1. Нажмите вверху дашборда кнопку **Нейроаналитик** — справа откроется вкладка **Нейроаналитик**.

     {% cut "Нейроаналитик для вкладки дашборда" %}

     ![image](../../_assets/datalens/ai/ai-analytic-on-dashboard.png)

     {% endcut %}

  1. Выберите вопрос или задайте свой, например: «Какую промоакцию запустить?».

     {% cut "Вопрос к Нейроаналитику" %}

     ![image](../../_assets/datalens/ai/ai-analytic-on-dashboard-ask.png)

     {% endcut %}

     Нейроаналитик проанализирует состав текущей вкладки, детально углубится в релевантные для ответа чарты и сформулирует развернутый ответ.

     {% cut "Ответ Нейроаналитика" %}

     ![image](../../_assets/datalens/ai/ai-analytic-on-dashboard-result.png)

     {% endcut %}

     Вверху вкладки Нейроаналитика отображается список чартов, на основе которых был подготовлен ответ.
     
     {% cut "Список чартов для ответа Нейроаналитика" %}

     ![image](../../_assets/datalens/ai/ai-analytic-on-dashboard-charts-list.png)

     {% endcut %}

- Для отдельных чартов на дашборде

  1. В правом верхнем углу чарта на дашборде нажмите ![icon](../../_assets/console-icons/ellipsis.svg) → **Найти инсайты** — справа откроется вкладка **Нейроаналитик**.

     {% cut "Нейроаналитик для чарта на дашборде" %}

     ![image](../../_assets/datalens/ai/ai-analytic-on-dashboard-chart.png)

     {% endcut %}

  1. Если требуется добавить в анализ еще чарт, найдите его на дашборде, в правом верхнем углу чарта нажмите ![icon](../../_assets/console-icons/ellipsis.svg) → **Добавить в анализ**.

  1. Выберите вопрос или задайте свой, например:
     
     * Какие выводы можно сделать по этим данным?

       {% cut "Вопрос к Нейроаналитику" %}

       ![image](../../_assets/datalens/ai/ai-analytic-on-dashboard-chart-ask-1.png)

       {% endcut %}

       Нейроаналитик даст развернутый ответ, предложит возможные решения и рекомендации.

       {% cut "Ответ Нейроаналитика" %}

       ![image](../../_assets/datalens/ai/ai-analytic-on-dashboard-chart-result-1.png)

       {% endcut %}

     * Как сделать график более наглядным?

       {% cut "Вопрос к Нейроаналитику" %}

       ![image](../../_assets/datalens/ai/ai-analytic-on-dashboard-chart-ask-2.png)

       {% endcut %}

       Нейроаналитик проанализирует текущую визуализацию и предложит рекомендации по ее улучшению, например, подвинуть оси или убрать визуальный шум.

       {% cut "Рекомендации Нейроаналитика" %}

       ![image](../../_assets/datalens/ai/ai-analytic-on-dashboard-chart-result-2.png)

       {% endcut %}

{% endlist %}

Чарты, которые строит Нейроаналитик, можно использовать:

* сохранить в текущем виде — нажмите **Сохранить** и укажите название для нового чарта.
* редактировать и сохранить — в верхнем правом углу чарта нажмите ![image](../../_assets/console-icons/ellipsis.svg) и выберите ![image](../../_assets/console-icons/pencil.svg) **Редактировать**.
* скопировать на дашборд — нажмите ![image](../../_assets/console-icons/copy.svg), чарт будет сохранен в буфер обмена. Его можно добавить на дашборд в пределах текущего воркбука: откройте дашборд в режиме редактирования и на панели добавления виджетов нажмите **Вставить**.

## Настройки Нейроаналитика на дашборде {#settings}

Чат с Нейроаналитиком можно закрепить поверх дашборда или сбоку от него (по умолчанию). Чтобы изменить положение чата, нажмите:
  
  * ![image](../../_assets/console-icons/pin-slash.svg) — чат будет отображаться поверх дашборда;
  * ![image](../../_assets/console-icons/pin.svg) — чат будет отображаться сбоку от дашборда.

Также доступны следующие настройки:
* [запрет](../operations/dashboard/dashboard-neuroanalyst-off.md) использования Нейроаналитика для дашборда;
* выбор [эталонной вкладки](../operations/dashboard/dashboard-ai-reference-tab.md);
* добавление примеров вопросов — это те вопросы, которые показываются при запуске Нейроаналитика. Если примеры вопросов не добавлены в настройках, будут показаны вопросы по умолчанию.

## Ограничения Нейроаналитика {#restrictions-2}

* Работает только на одном датасете, на котором построена эталонная вкладка.
* Заголовки первых трех чартов попадают в рекомендации Нейроаналитика.
* Нейроаналитик недоступен на мобильном устройстве.

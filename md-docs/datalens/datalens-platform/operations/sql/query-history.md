# Работа с историей запросов в Yandex DataLens Platform

С помощью истории запросов в Редакторе SQL вы можете:

* [просмотреть выполненные запросы](#view-executed-query);
* [повторить запрос](#re-run-query);
* [удалить запрос из истории](#remove-query-from-history).

## Просмотреть выполненный запрос {#view-executed-query}

Чтобы просмотреть выполненные запросы, перейдите в раздел **История запросов**.

Чтобы просмотреть конкретный запрос, выберите его в истории. Запрос отобразится в панели данных.


{% note tip %}

Чтобы найти специфические запросы, воспользуйтесь:
* поиском — введите имя таблицы или название команды в поле поиска.
* фильтрацией — нажмите ![image](../../../../_assets/console-icons/funnel.svg) и укажите статус выполнения запроса и временной интервал.

{% endnote %}

## Повторить запрос {#re-run-query}

Чтобы повторить выполненный запрос:

1. Перейдите в раздел **История запросов**.

1. Выберите запрос — он отобразится в панели данных.

1. Нажмите кнопку **Копировать в редактор**.

1. (Опционально) Измените параметры запроса.

1. Нажмите кнопку **Выполнить**.

## Удалить запрос из истории {#remove-query-from-history}

1. Перейдите в раздел **История запросов**.

1. Нажмите ![image](../../../../_assets/console-icons/ellipsis.svg) справа от нужного запроса и выберите **Удалить**.

1. В открывшемся окне нажмите кнопку **Применить**.

# Настройка подключения для работы в Редакторе SQL Yandex DataLens Platform

Чтобы работать с Редактором SQL в DataLens Platform, настройте подключение к базе данных.

Для работы с Редактором SQL в настройках подключения включите опцию **Уровень доступа SQL-запросов** → **SQL на чтение**. Опцию можно включить при создании или изменении подключения.

Чтобы выполнять запросы на изменение данных, включите опцию **Уровень доступа SQL-запросов** → **SQL на запись**.

{% note info %}

* При работе с подключением к ClickHouse® и выбранной настройкой **Уровень доступа SQL-запросов** → **SQL на запись** укажите в продвинутых настройках подключения `Readonly` — `0`.

* Если у вас нет прав для редактирования настроек подключения, обратитесь к администратору.

{% endnote %}


Чтобы открыть подключение в Редакторе SQL:

1. Откройте нужное подключение.
1. В правом верхнем углу страницы нажмите **Открыть в Редакторе SQL**.

Откроется окно для работы с данными и выполнения запросов.

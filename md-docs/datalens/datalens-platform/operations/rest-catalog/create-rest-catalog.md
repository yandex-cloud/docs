# Создание REST-каталога

В Yandex DataLens Platform вы можете создавать [REST-каталоги](../../concepts/rest-catalog/index.md) для хранения в них таблиц и представлений. Чтобы создать REST-каталог:

1. Перейдите в раздел ![image](../../../../_assets/console-icons/compass.svg) **Навигация**, выберите вкладку **REST-каталоги** и нажмите **Создать**.
1. В блоке **Основные настройки** укажите параметры каталога:
   * В поле **Название** введите имя каталога.
   * (Опционально) В поле **Описание** укажите, для чего нужен каталог.
   * В поле **Окружение Cloud** выберите окружение из списка. REST-каталог и кластеры, которые будут работать с ним, должны находиться в одном облаке и в одном окружении. Если подходящего окружения нет, нажмите **Создать** и [создайте новое](../clusters/manage-environment.md#create-environment).
1. В блоке **Бакет** настройте хранилище данных каталога:

   * В поле **Название** задайте имя бакета.
   * В поле **Максимальный размер** выберите режим использования бакета:
     * **Ограничить** — задайте предельный размер и единицу измерения: **ГБ**, **ТБ** или **ПБ**.
     * **Без ограничения** — снимите лимит на размер бакета.
   * В поле **Класс хранилища** выберите класс в зависимости от частоты обращения к данным:
     * **Стандартное** — для часто используемых данных.
     * **Холодное** — для данных, к которым обращаются реже.
     * **Ледяное** — для редко используемых данных.

1. Нажмите **Создать REST-каталог**.

После того как REST-каталог будет создан, он отобразится в списке каталогов. Вы можете [продолжить работу](work-with-rest-catalog.md) с ним или создать в нем [пространства имен](create-namespace.md).

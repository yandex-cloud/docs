# AI-инструменты в Yandex DataLens Platform

Нейроаналитик в Yandex DataLens Platform — это AI-агент, который помогает анализировать проекты, писать запросы, предлагает улучшения и правки, ускоряет и упрощает создание и редактирование визуализаций. Кроме того, Нейроаналитик умеет строить визуализации по вашему запросу.

Нейроаналитик использует для работы только те объекты, доступ к которым есть у пользователя, который пишет запрос к Нейроаналитику.

## Безопасность и обработка данных {#security}

* Нейроаналитик основан на базе облачного сервиса [Yandex AI Studio](https://aistudio.yandex.ru/docs/ru/).
* Ваши данные и запросы не покидают контура Yandex Cloud.
* Ваши данные и запросы не используются для дообучения.
* Администратор может отключить возможность использования Нейроаналитика на уровне платформы.

Подробнее о [лимитах для Нейроаналитика](../../../concepts/limits.md#datalens-ai-limits).

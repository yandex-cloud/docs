# Редактор SQL в Yandex DataLens Platform

_Редактор SQL_ — раздел для работы с базами данных, таблицами и схемами, а также выполнения запросов. Редактор работает в браузере, не требует дополнительной авторизации, подсказывает SQL-команды при вводе и подсвечивает ошибки.

В Редакторе SQL доступен [Нейроаналитик](../../operations/sql/neuroanalyst.md), который помогает создавать и объяснять SQL-запросы.

Выполненные запросы можно [просматривать в истории запросов](../../operations/sql/query-history.md).

# Версионирование

Версионирование HTML-страницы — это возможность хранить историю изменений HTML-страницы с помощью версий.

Чтобы перейти к списку версий, в верхней части экрана нажмите на значок ![image](../../_assets/console-icons/ellipsis.svg) и выберите ![image](../../_assets/console-icons/clock.svg) **История изменений**.

Чтобы перейти к выбранной версии, нажмите на нее в списке. Номер версии отобразится в значении параметра `revId` строки адреса отчета. При переходе по ссылке, содержащей номер версии в параметре `revId`, сразу откроется эта версия отчета.

## Виды версий {#version-types}

Различают следующие версии:

1. **Актуальная**. Последняя сохраненная версия.

   Версия отображается:
   
   * при переходе на HTML-страницу по ссылке;
   * при переходе на HTML-страницу из навигации;
   * при открытии HTML-страницы в воркбуке.
   
   Актуальной может быть только одна версия HTML-страницы.

   Если у пользователя есть право доступа **Редактирование**, он может сделать актуальной любую версию HTML-страницы.
  
   {% note warning %}
  
   При актуализации любой версии создается новая версия HTML-страницы.

   {% endnote %}
  
1. **Неактуальная**. Версия, которая не является актуальной.  
   При открытии неактуальной версии вверху отображается панель, на которой указаны тип версии, дата и время создания, а также логин автора версии. Справа на панели кнопки:

   * **Сделать актуальной** — делает текущую неактуальную версию актуальной. Актуальная на текущий момент версия станет неактуальной.
   * **Открыть актуальную** — открывает актуальную версию.

{% note tip %}

Любой версией HTML-страницы можно поделиться: добавьте к ссылке на HTML-страницу параметр `revId` (например, `?revId=zac5m4edoaqqr`).

{% endnote %}

## Создание новой версии {#version-create}

Новая версия автоматически создается:

* после [загрузки новой версии](index.md#html-change) HTML-страницы;
* в режиме просмотра неактуальной версии HTML-страницы — после нажатия кнопки **Сделать актуальной**.

## Ограничения {#restrictions}

* История изменений доступна только за последние три месяца.
* История изменений содержит только список версий HTML-страницы и включает: вид версии, дату и время сохранения, а также автора редактирования.
* Версии HTML-страницы не содержат изменений прав доступа (эта операция производится отдельно от редактирования самой HTML-страницы).
* В версиях не отображается список изменений. Доступен лишь просмотр сохраненного состояния HTML-страницы.

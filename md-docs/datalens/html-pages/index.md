# HTML-страницы в DataLens

_HTML-страница_ — позволяет пользователям DataLens [загрузить страницу](#create-html) HTML в воркбук и [поделиться](#link-on-html) ей с другими пользователями.

При подготовке HTML-страниц используйте скилл на [GitHub](https://github.com/datalens-tech/datalens-skills), в котором собраны ограничения и инструкции по генерации.

## Загрузить HTML-страницу {#create-html}

HTML-страницу можно загрузить одним из способов:

{% list tabs %}

- Воркбук

  1. Перейдите на [страницу коллекций и воркбуков](https://datalens.ru/collections).
  1. Откройте [воркбук](../workbooks-collections/index.md), в котором хотите создать HTML-страницу.
  1. В правом верхнем углу нажмите кнопку **Создать** и выберите **HTML-страница**.
  1. Выберите файл с HTML-страницей или перетащите его на страницу.
  1. В открывшемся окне введите название страницы и нажмите кнопку **Создать**.

- Панель навигации

  1. Перейдите на [главную страницу](https://datalens.ru/?skipPromo=true) DataLens.
  1. На панели слева выберите ![image](../../_assets/console-icons/file-code.svg) **HTML-страницы** и нажмите кнопку **Создать HTML-страницу**.
  1. Выберите воркбук для хранения HTML-страницы и нажмите **Создать**.
  1. Выберите файл с HTML-страницей или перетащите его на страницу.
  1. В открывшемся окне введите название страницы и нажмите кнопку **Создать**.

{% endlist %}

## Загрузить новую версию HTML-страницы {#html-change}

Чтобы внести изменения на HTML-страницу:

1. Внесите необходимые изменения в исходный файл с HTML-страницей.
1. В DataLens откройте HTML-страницу, которую нужно изменить.
1. Вверху справа нажмите **Загрузить новую версию**.
1. Выберите файл с HTML-страницей или перетащите его на страницу.

На экране отобразится новая версия HTML-страницы, а предыдущая версия будет сохранена в [истории изменений](versioning.md).

## Поделиться ссылкой на HTML-страницу {#link-on-html}

Чтобы скопировать ссылку на HTML-страницу, вверху нажмите ![icon](../../_assets/console-icons/link.svg) или нажмите ![icon](../../_assets/console-icons/ellipsis.svg) и выберите ![icon](../../_assets/console-icons/link.svg) **Копировать ссылку**. Эту ссылку можно отправить пользователям с [доступом](../security/index.md) к HTML-странице. 

## Ограничения и особенности использования {#restrictions}

* Загрузить можно только один HTML-файл, поэтому в нем должно быть собрано все необходимое.
* Сетевые запросы ограничены: статику разрешено получать только с нескольких крупных CDN.
* Обычные ссылки и скачивание файлов не работают, но DataLens предоставляет для этого [postMessage](https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage) API.

# Подключения

### Поддерживаете ли тип GEO из PostgreSQL? {#postgre-type}

DataLens не поддерживает типы данных расширения [PostGIS](https://postgis.net/docs/), которое используется в PostgreSQL для работы с геоданными. [`Геоточка`](../dataset/data-types.md#geopoint) и [`Геополигон`](../dataset/data-types.md#geopolygon) — это строковые типы определенного формата.


### Как из DataLens подключиться к Яндекс Метрике? {#metrica-clickhouse-connection}

DataLens может подключаться к Яндекс Метрике напрямую (подробнее в руководстве [Веб-аналитика с подключением к Яндекс Метрике](../tutorials/data-from-metrica-visualization.md)). В этом случае будут доступны не все аналитические функции над данными (обращение происходит через API, а оно имеет ограниченную функциональность). Вероятно на больших объемах API будет медленно отвечать на запросы. Если использовать API очень активно, то можно превысить в лимиты API.

Также вы можете самостоятельно настроить экспорт метрики в свою БД с помощью скриптов и подключиться к этой БД с помощью DataLens.

{% note info %}

* По умолчанию из Метрики выгружаются данные за последние 60 дней. Если в чарте добавить фильтр по дате, то фильтр Метрики будет сброшен. Рекомендуем добавлять фильтр по дате как смещение относительно текущей даты.
* На стороне Метрики действует квота на количество одновременно исполняемых запросов для одного пользователя (`user_login`) — 3.

{% endnote %}

### Раньше в DataLens была возможность подключения к Яндекс Метрике и AppMetrica с предварительной выгрузкой данных в ClickHouse® через LogsAPI. Сейчас есть такая возможность? {#uploading-data-logs-api}

Нет. Сейчас доступно только прямое подключение к Метрике и AppMetrica.

Чтобы работать с сырыми данными Метрики и AppMetrica, вы можете:

* для AppMetrica:

  * настроить выгрузку через [Data Stream API](https://appmetrica.yandex.ru/docs/ru/mobile-api/datastream/quick-start);
  * настроить выгрузку через [Logs API](https://appmetrica.yandex.ru/docs/ru/mobile-api/logs/about);
  * [выгрузить данные в файл](https://appmetrica.yandex.ru/docs/ru/common/export).

* для Метрики:

  * воспользоваться [примером кода](https://github.com/zhdanchik/yandex_metrika_cloud_case/) из [документации](../tutorials/data-from-metrica-yc-visualization.md#get-download-data-in-ch) для экспорта сырых данных в ClickHouse® через LogsAPI;
  * подключить пакет **Метрика Про** и [настроить передачу данных](https://yandex.ru/support/metrica/ru/uploading-data/cloud) в кластер Managed Service for ClickHouse®.

### Почему при загрузке CSV в таблице отображаются только первые 100 строк, хотя их больше? {#csv-rows-display}

Это превью для проверки корректного распознавания данных и разделителей. Отображение большого количества строк может приводить к ошибкам или замедлению браузера. Поэтому мы ограничили количество отображаемых строк.

### Почему долго загружается CSV? {#csv-long-loading}

Сейчас процесс загрузки файла устроен так, что создается несколько реплик в разных датацентрах для обеспечения отказоустойчивости. Этот процесс занимает некоторое время.

### Почему возникает сетевая ошибка (Network Error) при загрузке CSV-файла? {#csv-network-error}

Попробуйте использовать другой браузер и отключить блокировщики рекламы.

### Почему при создании подключения к Google Sheets возникает ошибка «Не удалось загрузить файл»? {#google-sheets-file-load}

После указания ссылки на документ и длительного ожидания может появиться сообщение:

```text
Не удалось загрузить файл
Request ID: ********-****-****-****-************
```

Проверьте таблицу Google Sheets:

* Объем итоговых данных на каждом листе не превышает 200 МБ.
* На одном листе не больше 300 столбцов.
* На каждом листе заполнено не менее двух строк. Первая строка используется для заголовков полей датасета.
* В названии таблицы нет символов `+` и `/`.

Если таблица не соответствует одному или нескольким требованиям, создайте ее копию и приведите данные в соответствие с ограничениями.

### Что делать, если при загрузке CSV-файла возникает ошибка `ERR.FILE.PARSE_FAILED`? {#csv-upload}

Если при загрузке CSV-файла появляется сообщение `Не удалось загрузить файл` или ошибка `ERR.FILE.PARSE_FAILED`:

1. Проверьте кодировку файла. Поддерживаются UTF-8, UTF-16, Windows-1251 и UTF-8-Sig.
1. Проверьте разделители столбцов во всем файле. Поддерживаются запятая (`,`), точка с запятой (`;`) и знак табуляции.
1. Загрузите файл повторно:

   * отключите блокировщики рекламы;
   * откройте страницу датасета в режиме инкогнито;
   * используйте другой браузер.

{% note alert %}

Перед отправкой CSV-файла удалите из него чувствительные данные.

{% endnote %}

### Что делать, если при подключении к Managed Service for PostgreSQL возникает ошибка `SSL is required`? {#postgresql-ssl-required}

Ошибка может выглядеть так:

```text
ERR.CHARTS.DATA_FETCHING_ERROR
ERR.DS_API.DB
db_message": "odyssey: ***********: SSL is required"
```

Она означает, что для подключения требуется SSL. При подключении к внешней базе данных используйте на сервере доверенный SSL-сертификат.

Если ошибка возникла при создании подключения к Managed Service for PostgreSQL, [включите **Доступ из DataLens**](../../managed-postgresql/operations/datalens-connect.md#allow-access) в настройках кластера, а затем [настройте подключение](../operations/connection/create-postgresql.md).

Если ошибка возникла в существующем подключении, выключите и снова включите [доступ из DataLens](../../managed-postgresql/operations/datalens-connect.md#allow-access) в [настройках кластера](../../managed-postgresql/operations/update.md#change-additional-settings). Если это не помогло, создайте новое подключение и [замените его в датасете](../dataset/create-dataset.md#replace-connection).

### Что делать, если при подключении к API Яндекс Метрика возникает ошибка `direct_client_logins`? {#metrika-direct-client-logins}

Для построения запроса к API Яндекс Метрика требуется параметр `direct_client_logins`. Подробнее о нем описано в [документации API Яндекс Метрика](https://yandex.ru/dev/metrika/doc/api2/api_v1/direct-clicks.html?lang=ru).

DataLens не позволяет передавать этот и подобные параметры, поэтому построить чарт напрямую не получится. Вместо этого [выгрузите данные в ClickHouse®](#uploading-data-logs-api).

### Что делать, если при подключении к БД MySQL® возникает ошибка `1043 Bad handshake`? {#mysql-bad-handshake}

Ошибка означает, что клиент и сервер не смогли согласовать параметры подключения, обменяться ключами шифрования или установить безопасное соединение.

Чтобы устранить ошибку:

1. Убедитесь, что используется актуальная версия MySQL®.
1. Проверьте, что на стороне БД используется [SSL-сертификат](../../glossary/ssl-certificate.md), подписанный удостоверяющим центром. Подключение с самоподписанным сертификатом создать не получится.
1. Проверьте, что сервер MySQL® поддерживает выбранный метод аутентификации. При необходимости обновите MySQL® или измените настройки плагина аутентификации.


### Что делать, если таблица из Google Sheets работает некорректно? {#google-sheets-error}

Если в таблице Google Sheets присутствуют пустые ячейки, то в DataLens могут некорректно отображаться названия столбцов и пропадать несколько первых строк.

Чтобы исправить ситуацию, нужно в таблице Google Sheets заполнить пустые ячейки любыми подходящими по смыслу значениями: `отсутствует`, `нет`, `неизвестно`.

Чтобы быстро заполнить пустые ячейки в таблице Google Sheets:

1. Выделите всю таблицу Google Sheets.
1. В меню таблицы выберите **Данные** → **Создать фильтр**.
1. В правом углу верхней ячейки первого столбца нажмите значок фильтра.
1. Нажмите **Сбросить**, а затем выберите значение **(Пустые)**.
1. В верхней ячейке столбца введите желаемое значение, например: `0`, `отсутствует`, `нет` или любое другое.
1. Протяните ячейку вниз, чтобы заполнить все пустые ячейки в столбце введенным значением.
1. Снова нажмите значок фильтра и выберите значение **Выбрать всё**.
1. Повторите все шаги, начиная с третьего, для остальных столбцов таблицы.

### Что делать, если при подключении к Яндекс Документам возникает ошибка "Неверный формат ссылки"? {#yadocs-error-link}

Эта ошибка возникает, если в ссылке присутствует `/d` вместо `/i`. Например:

* `https://disk.yandex.ru/i/id` — верный формат ссылки;
* `https://disk.yandex.ru/d/id` — неверный формат ссылки.

Чтобы исправить ошибку, удалите ссылку на файл в Яндекс Документах и через некоторое время сгенерируйте ее заново.

### Учитываются ли таймзоны при работе с датами? {#timezone-date}

Данные о времени с указанием часового пояса DataLens запрашивает и возвращает в часовом поясе источника, само указание часового пояса при этом отбрасывается. Например, для PostgreSQL с настройкой `timezone: Europe/Berlin` все данные из колонок с типом `TIMESTAMP WITH TIME ZONE` будут выводиться в таймзоне `Europe/Berlin` независимо от часового пояса пользователя или того, с каким сдвигом они были записаны в базу.

Например:

* значение в источнике: `2025-03-31 10:00:00+01:00`;
* значение в DataLens: `2025-03-31 10:00:00`.

[Таймзона](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones#List) учитывается при вычислениях, в т. ч. с использованием функций [преобразования типов](../function-ref/type-conversion-functions.md).

Например, для PostgreSQL с настройкой `timezone: Europe/Berlin`:

* формула `DATEPART(DATETIME(#1970-01-01 01:00:00#, 'UTC'), 'hour')` вернет значение `2`, т. к. таймзона базы (`Europe/Berlin`) сдвинута относительно указанной (`UTC`) на 1 час;
* формула `INT(DATETIME(#1970-01-01 01:00:00#, 'UTC'))` вернет значение `3600`.

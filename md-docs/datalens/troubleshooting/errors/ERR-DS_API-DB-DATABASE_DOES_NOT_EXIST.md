# [Yandex DataLens] Data source database does not exist

`ERR.DS_API.DB.DATABASE_DOES_NOT_EXIST`

Ошибка возникает при обращении к несуществующей базе данных.

Чтобы исправить ошибку, проверьте имя базы с учетом регистра и убедитесь, что база не была удалена или переименована. Укажите существующую базу либо попросите администратора создать или восстановить нужную.

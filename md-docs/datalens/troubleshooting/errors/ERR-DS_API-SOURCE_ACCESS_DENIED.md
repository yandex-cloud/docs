# [Yandex DataLens] Internal Server Error

`ERR.DS_API.SOURCE_ACCESS_DENIED`

DataLens получил отказ от источника по причине отсутствия прав.

Проверьте права на источник, права учетной записи или сервисного аккаунта.


Если доступ есть, но ошибка повторяется, обратитесь в [техническую поддержку](https://center.yandex.cloud/support) Yandex Cloud. В сообщении опишите, когда возникает ошибка.

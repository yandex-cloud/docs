# [Yandex DataLens] Internal Server Error

`ERR.DS_API.SOURCE_CONFIG.TABLE_NAME_INVALID`

Для источника CHYT указан некорректный путь к таблице или список путей пуст либо содержит дубликаты.

Чтобы устранить ошибку, проверьте подробное сообщение:

* Укажите путь к таблице YT в допустимом формате.
* Удалите повторяющиеся строки из списка.

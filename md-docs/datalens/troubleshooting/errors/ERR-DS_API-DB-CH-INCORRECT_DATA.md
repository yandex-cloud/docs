# [Yandex DataLens] ClickHouse® could not parse the data in the specified source

`ERR.DS_API.DB.CH.INCORRECT_DATA`

Ошибка возникает, когда ClickHouse® не может разобрать данные источника.

Чтобы исправить ошибку, проверьте, что фактические значения, их формат и типы соответствуют схеме таблицы. Исправьте некорректные данные или схему.


Если источник выглядит корректно, обратитесь к администратору ClickHouse® или в [техническую поддержку](https://center.yandex.cloud/support) Yandex Cloud. В сообщении опишите, когда возникает ошибка.

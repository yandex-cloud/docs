# [Yandex DataLens] No space left on device

`ERR.DS_API.DB.NO_SPACE_LEFT`

Источник данных сообщил о нехватке места на диске.

Чтобы исправить ошибку:

1. Обратитесь к администратору БД: необходимо проверить свободное место и устранить причину его заполнения.
1. Повторите запрос.

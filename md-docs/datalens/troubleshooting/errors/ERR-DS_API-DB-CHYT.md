# [Yandex DataLens] CHYT Error

`ERR.DS_API.DB.CHYT`

Общий код для ошибок CHYT.

Чтобы исправить ошибку, попробуйте выполнить действия:

* Посмотрите подробное сообщение базы данных: оно содержит исходную причину.
* Проверьте запрос, доступность клики и таблиц.
* Повторите запрос позже.


Если причина непонятна или ошибка повторяется, обратитесь к администратору клики или в [техническую поддержку](https://center.yandex.cloud/support) Yandex Cloud. В сообщении опишите, когда возникает ошибка и приложите детали ошибки.

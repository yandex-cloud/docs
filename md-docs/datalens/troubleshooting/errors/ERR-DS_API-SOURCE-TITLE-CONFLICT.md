# [Yandex DataLens] Data source title conflicts with another source

`ERR.DS_API.SOURCE.TITLE.CONFLICT`

В одном датасете или файловом подключении обнаружены источники с одинаковыми названиями.

Чтобы исправить ошибку:

1. Переименуйте один из источников так, чтобы названия были уникальными.
1. Сохраните изменения.

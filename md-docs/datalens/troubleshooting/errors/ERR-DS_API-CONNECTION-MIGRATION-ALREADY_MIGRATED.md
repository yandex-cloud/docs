# [Yandex DataLens] Подключение уже мигрировано

`ERR.DS_API.CONNECTION.MIGRATION.ALREADY_MIGRATED`

Подключение уже мигрировано, повторная миграция не требуется.

Чтобы исправить ошибку, попробуйте обновить страницу подключения.

# [Yandex DataLens] Failed to COMMIT or ROLLBACK

`ERR.DS_API.DB.COMMIT_OR_ROLLBACK_FAILED`

Ошибка возникает, когда драйвер не может завершить транзакцию командой `COMMIT` или `ROLLBACK`. Ошибка может быть вызвана разрывом соединения, недоступностью сервера или проблемой состояния транзакции.

Чтобы исправить ошибку, попробуйте выполнить действия:

* Повторите запрос.
* Проверьте доступность сервера, его журналы, состояние транзакций и настройки подключения.


* Если ошибка повторяется, обратитесь к администратору базы данных или в [техническую поддержку](https://center.yandex.cloud/support) Yandex Cloud. В сообщении опишите, когда возникает ошибка.

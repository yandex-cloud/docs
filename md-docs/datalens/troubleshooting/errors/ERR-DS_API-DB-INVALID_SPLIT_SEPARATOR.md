# [Yandex DataLens] Invalid separator for splitting

`ERR.DS_API.DB.INVALID_SPLIT_SEPARATOR`

При использовании функции разбиения строки указан недопустимый разделитель.

Чтобы исправить ошибку, проверьте подробное сообщение БД: при использовании функции разбиения строки проверьте типы ее аргументов, укажите допустимый разделитель.

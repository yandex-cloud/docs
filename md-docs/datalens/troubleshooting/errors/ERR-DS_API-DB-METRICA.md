# [Yandex DataLens] Metrica API error

`ERR.DS_API.DB.METRICA`

API Яндекс Метрики или AppMetrica отклонил запрос либо не смог его выполнить.

Чтобы исправить ошибку:

* Посмотрите подробное сообщение API.
* Проверьте токен и доступ к счетчику или приложению, а также запрошенные поля и фильтры.

Если настройки верны, повторите запрос позже.


При повторении ошибки обратитесь в [техническую поддержку](https://center.yandex.cloud/support) Yandex Cloud. В сообщении приложите ответ API.

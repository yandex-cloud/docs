# Политика доступа по странам

С помощью _политики доступа по странам_ можно ограничить доступ к контенту, распространяемому через CDN, для пользователей из указанных стран. Политику можно настроить при [создании](../operations/resources/create-resource.md) или [изменении](../operations/resources/configure-geo-acl.md) CDN-ресурса с помощью консоли управления или API.

Политика доступа по странам определяется [типом политики](#policy-type) и [списком стран](#country-codes).

{% note warning %}

При включенной политике доступа по странам геолокация клиента определяется по IP-адресу и зависит от данных баз GeoIP. В отдельных случаях эти данные могут быть неточными или устаревшими, например из-за перераспределения IP-адресов между операторами, смены владельца адресного диапазона или задержки обновления информации в публичных источниках.

{% endnote %}

## Тип политики {#policy-type}

Для CDN-ресурса можно задать один из типов политики:

* `Запретить для указанных стран` — запрещает доступ к ресурсу из стран, перечисленных в списке, и разрешает из остальных стран.
* `Разрешить только для указанных стран` — разрешает доступ к ресурсу только из стран, перечисленных в списке, и запрещает из остальных стран.

## Список стран {#country-codes}

Страны и территории указываются двухбуквенными кодами в верхнем регистре по стандарту [ISO 3166-1 alpha-2](https://www.iso.org/obp/ui/#search/code/). Несколько кодов разделяются запятыми, например `RU, KZ`.

# yc application-load-balancer v0 virtual-host get

Show information about the specified virtual host

#### Command Usage

Syntax:

`yc application-load-balancer v0 virtual-host get <VIRTUAL-HOST-NAME> [<VIRTUAL-HOST-NAME>...] [Flags...] [Global Flags...]`

Aliases:

- `describe`

- `show`

#### Flags

#|
||Flag | Description ||
|| `--http-router-id` | `string`

ID of the Http router. ||
|| `--http-router-name` | `string`

Name of the Http router. ||

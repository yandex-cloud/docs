# Восстановление данных из доступного хоста Yandex Managed Service for Valkey™

Если есть доступный хост Yandex Managed Service for Valkey™, вы можете скопировать его данные в самостоятельно развернутый экземпляр Valkey™ с помощью репликации. Экземпляр можно разместить в другой зоне доступности или в другом облаке.

## Подготовьте кластер {#prepare}

Для подключения необходим кластер Yandex Managed Service for Valkey™ с включенным TLS и публичным IP-адресом доступного хоста. [Настройте публичный доступ](../concepts/network.md#public-access-to-host) к этому хосту.

## Создайте конфигурационный файл {#configure-replication}

Создайте конфигурационный файл для нового экземпляра Valkey™:

```text
replicaof <публичный_IP-адрес_хоста> 6380
tls-replication yes
tls-ca-cert-file /etc/valkey/tls/ca.crt
masteruser default
masterauth "<пароль_пользователя_default>"
```

Укажите публичный IP-адрес доступного хоста и пароль пользователя `default` исходного кластера.

**Уточнение подготовки.** [Получите сертификат центра сертификации](connect/index.md#get-ssl-cert) и сохраните его по пути `/etc/valkey/tls/ca.crt`.

{% note info %}

**Уточнение конфигурации TLS.** Для инициализации TLS в Valkey™ также необходимы сертификат и закрытый ключ нового экземпляра. Подготовьте их выбранным вами способом и добавьте в конфигурацию:

```text
tls-cert-file <путь_к_сертификату>
tls-key-file <путь_к_закрытому_ключу>
```

Это требование описано в [документации Valkey™](https://valkey.io/topics/tls/).

{% endnote %}

## Разверните новый экземпляр {#deploy}

Разверните Valkey™ любым доступным вам способом. Используйте ту же версию, что и в исходном кластере Yandex Managed Service for Valkey™, и созданный конфигурационный файл.

## Проверьте репликацию {#check-replication}

1. На новом экземпляре выполните:

   ```bash
   valkey-cli INFO replication
   ```

   В выводе должны появиться значения:

   ```text
   role:slave
   master_link_status:up
   ```

1. На хосте-источнике выполните `INFO replication`. **Уточнение подключения.** Для обращения к хосту с TLS и аутентификацией используйте:

   ```bash
   valkey-cli --tls \
     -h <публичный_IP-адрес_хоста> -p 6380 \
     --cacert /etc/valkey/tls/ca.crt \
     --user default --askpass \
     INFO replication
   ```

   Введите пароль пользователя `default`. Если новый экземпляр — единственная подключенная реплика, в выводе будет:

   ```text
   connected_slaves:1
   ```

   **Уточнение проверки.** Поле `connected_slaves` показывает общее число подключенных реплик. Если у источника уже есть реплики, значение будет больше `1`. Подробнее см. в [описании команды `INFO`](https://valkey.io/commands/info/).

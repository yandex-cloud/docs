# Автоматическое масштабирование в Yandex Managed Service for Valkey™

*Автоматическое масштабирование* — это изменение количества шардов в кластере Valkey™ в зависимости от текущей нагрузки.

При включенной опции автомасштабирования Yandex Managed Service for Valkey™ автоматически меняет количество шардов под текущую нагрузку. Такой подход обеспечивает стабильную работу кластера без ручного увеличения или уменьшения числа шардов.

Для масштабирования Yandex Managed Service for Valkey™ периодически собирает [метрики утилизации шардов кластера](#settings). На основе метрик могут быть приняты следующие решения:

* Увеличить количество шардов, если кластер близок к перегрузке.
* Уменьшить количество шардов, если кластер устойчиво недозагружен.
* Оставить без изменений, если утилизация в пределах заданных порогов.

Чтобы исключить реакцию на кратковременные скачки нагрузки, решения принимаются на основе агрегированных метрик за несколько минут. Масштабирование запускается только в случаях, когда критическое значение сохраняется на протяжении десяти минут.

При автоматическом изменении числа шардов запускается ребалансировка кластера для перераспределения данных. После этого на новые шарды переместится часть уже существующих слотов.

Преимущества автоматического масштабирования:

* Производительность кластера не снижается с ростом нагрузки.
* В моменты простоя лишние шарды удаляются, что снижает плату за кластер.
* Время выполнения запросов не увеличивается с ростом нагрузки на кластер и не зависит от количества шардов.
* Аллокация вычислительных ресурсов становится более эффективной: набор шардов подстраивается под изменяющиеся потребности приложений.

## Управление автоматическим масштабированием {#settings}

Включить и выключить автоматическое масштабирование шардов можно при [создании](../operations/cluster-create.md) или [изменении](../operations/update.md#enable-autoscaling) шардированного кластера Valkey™.

Вы можете задать:

* Диапазон значений, в котором будет изменяться число шардов в кластере:

  * Минимальное число — не меньше 1.
  * Максимальное число — не больше 10 и не меньше, чем минимальное число.

* Пороговые значения отслеживаемых метрик утилизации шардов кластера для увеличения и уменьшения числа шардов.

  Для управления автомасштабированием используются следующие [метрики Yandex Managed Service for Valkey™](../metrics.md) по каждому шарду:
  
  * использование процессорного времени,
  * использование оперативной памяти.

  Для каждой из метрик вы можете задать верхнее и нижнее пороговое значение. В зависимости от фактических значений метрик сервис Yandex Managed Service for Valkey™ меняет число шардов следующим образом:
  
  * Увеличивает на один, если любая из указанных метрик хотя бы для одного шарда непрерывно превышает свое пороговое значение в течение десяти минут. Ни у одной из метрик нет приоритета.
  * Уменьшает на один, если все указанные метрики на всех шардах не превышают заданных нижних значений порогов в течение десяти минут.

  Если задать значения не всех порогов, то для остальных будут установлены значения по умолчанию. Далее вы можете изменить значения порогов по результатам мониторинга кластера в режиме автомасштабирования.

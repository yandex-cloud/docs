# История изменений в Yandex Cloud Billing

{% note info %}

В этой статье представлены только изменения в разделе **Детализация**.

{% endnote %}

## Детализация {#usage-details}

### II квартал 2026 {#q2-2026}

* Добавлена возможность просмотра детализации потребления по [скидкам](operations/check-charges.md#discount).

    ![alt text](../_assets/billing/rn-26-q2-discount.png)

* Вкладка с детализацией по облакам стала вкладкой с детализацией по рабочим пространствам. В ней доступен [просмотр](operations/check-charges.md#instances) детализации по облакам, сервисам внеоблачного потребления и дополнительным соглашениям.

    ![alt text](../_assets/billing/rn-26-q2-workspaces.png)

* Реализована возможность [довыгрузки](operations/get-folder-report.md#additional-export) детализации потребления. Теперь вы можете выгрузить данные за прошлые периоды, не создавая новый регулярный экспорт.
* Изменена логика отображения резервируемого потребления. Подробнее в разделе [Отображение резервируемого потребления](operations/check-charges.md#cvos).
* Улучшено отображение карточки итога стоимости и потребления, обновлены фильтры по умолчанию.
* Изменена логика работы отображения [детализации](operations/check-charges.md#labels) по меткам.  При выборе метки отображается стоимость каждого связанного с ней ресурса. Если выбрать несколько меток, которые установлены на одном ресурсе, его стоимость может дублироваться.
* Добавлена возможность [просмотра детализации](operations/check-charges.md#console_1) через виджет в консоли управления. Для доступа к виджету в консоли управления добавлена роль `billing.usagerecords.admin`.

    ![alt text](../_assets/billing/rn-26-q2-details-widget.png)

### I квартал 2026 {#q1-2026}

* Реализована возможность [просмотра](operations/check-charges.md) детализации потребления по нескольким облакам и каталогам одновременно.

    ![alt text](../_assets/billing/rn-26-q1-cloud-folder.png)

* Добавлена возможность просмотра детализации потребления по [периодам](operations/check-charges.md#periods_1).

    ![alt text](../_assets/billing/rn-26-q1-period.png)

* Изменена логика просмотра детализации потребления по [меткам](../resource-manager/concepts/labels.md). Фильтрация по меткам теперь отображается с даты создания метки, а не по ресурсам, как было ранее.
* Добавлена возможность [выгрузки](operations/get-folder-report.md) детализации за прошлые периоды в [бакет](../storage/concepts/bucket.md) Object Storage, в том числе [зашифрованный](../storage/concepts/encryption.md).
* Поддержано сохранение значений фильтров в Интерфейс Yandex Cloud Billing при каждом изменении.

# Изменить способ оплаты

Изменить способ оплаты можно только в платежном аккаунте с типом **Бизнес-аккаунт**. 

Чтобы изменить способ оплаты:

1. Составьте запрос на изменение способа оплаты.

   В запросе должны содержаться:
   
   
   {% list tabs group=customers %}
   
   - Юридические лица {#businesses}
   
     * Копия решения или протокола о назначении генерального директора либо доверенность на подписание услуговых договоров.
     * Идентификатор [платежного аккаунта](../concepts/billing-account.md#billing-account-id) (billing account ID).
   
   - ИП {#entrepreneurs}
   
     * Скан-копия листа записи/выписки из [ЕГРИП](https://egrul.nalog.ru/index.html) или уведомление о постановке на учет физического лица в качестве ИП в налоговом органе.
     * Идентификатор [платежного аккаунта](../concepts/billing-account.md#billing-account-id) (billing account ID).
     * Карточка ИП с указанием полного юридического и фактического адреса. Адрес нужен для отправки оригиналов документов на оплату при старте платного потребления.
   
   {% endlist %}

1. Отправьте запрос на электронную почту [cloud_docs@support.yandex.ru](mailto:cloud_docs@support.yandex.ru). Запрос рассматривается в течение трех рабочих дней. Менеджер Yandex Cloud сообщит вам о принятом решении.

{% note info %}

При переходе на способ оплаты **Банковский перевод** ваша карта будет отвязана от платежного аккаунта и вы не сможете привязать новую карту. [Пополнять лицевой счет](pay-the-bill.md) можно будет только с помощью [перевода средств с расчетного счета (через банк)](../payment/payment-methods-business.md).

{% endnote %}

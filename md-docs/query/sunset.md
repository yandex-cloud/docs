# Закрытие сервиса Yandex Query

{% note warning %}

Сервис Yandex Query прекращает работу. На этой странице описаны сроки, порядок закрытия и рекомендации по миграции.

{% endnote %}

## Что происходит {#what-happens}

Мы приняли решение закрыть сервис Yandex Query. Понимаем, что это изменение может затронуть ваши рабочие процессы, и постараемся сделать переход комфортным.

## Ключевые даты {#key-dates}

Закрытие сервиса пройдет в три этапа:

* **13 октября 2026** — прекращение новых продаж сервиса Yandex Query. Клиенты, подключившие сервис ранее, смогут пользоваться им до 10 ноября 2026 года.

* **10 ноября 2026** — сервис переходит в режим read-only. Создание новых сущностей сервиса станет недоступно. Текущие пользователи Yandex Query смогут выполнять запросы, но не смогут создавать и изменять сущности сервиса.

* **14 декабря 2026** — сервис полностью прекращает работу. Доступ к интерфейсу сервиса будет закрыт для всех пользователей.

## Что будет с вашими данными {#data}

Исходные данные не будут удалены. Yandex Query читает данные напрямую из подключенных источников и не хранит их, поэтому после закрытия сервиса они останутся в источниках. Соединения, привязки к данным, сохраненные запросы и история запросов автоматически не переносятся.

## Миграция {#migration}

В качестве альтернативы используйте Yandex Managed Service for YDB или работайте с данными в Object Storage напрямую.

Мы подготовили руководство, которое поможет при миграции: [Миграция с Yandex Query](tutorials/migration.md).

## Если у вас есть вопросы {#support}

Если у вас остались вопросы по закрытию сервиса:

* Обратитесь в [техническую поддержку](https://center.yandex.cloud/support).
* Свяжитесь с вашим аккаунт-менеджером.

Спасибо, что пользовались Yandex Query.

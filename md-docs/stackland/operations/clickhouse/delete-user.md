# Удалить пользователя

Если у вас есть [пользователь](create-user.md) [ClickHouse®](../../concepts/components/clickhouse.md), вы можете удалить его.

При удалении ресурса `ClickhouseUser` пользователь удаляется в ClickHouse®. Связанный Kubernetes Secret с паролем не удаляется автоматически — при необходимости удалите его отдельно.

## Через CLI {#cli}

1. Найдите название нужного пользователя в списке пользователей проекта: `kubectl get clickhouseuser -n <название_проекта>`.
1. Удалите ресурс пользователя: `kubectl delete clickhouseuser <название_ресурса> -n <название_проекта>`.
1. При необходимости удалите Secret с паролем: `kubectl delete secret <имя_секрета> -n <название_проекта>`.

## Через консоль управления {#console}

1. Если вы еще не открыли проект, выберите проект.
1. В левом меню выберите **ClickHouse® Clusters**.
1. Выберите кластер.
1. Перейдите на вкладку **Пользователи**.
1. Выберите пользователя.
1. Нажмите **Удалить**.
1. Подтвердите удаление.

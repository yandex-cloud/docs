# Удалить кластер Managed Service for Trino

Если у вас есть кластер [Trino](../../concepts/components/trino.md) в [проекте](../projects/create-project.md), вы можете удалить его.

{% note warning %}

Если включена **[защита от удаления](../../concepts/components/trino.md#deletion-protection)** (`spec.deletionProtection: true`), кластер удалить нельзя. Сначала отключите защиту: установите `spec.deletionProtection: false` в манифесте и примените изменения (`kubectl apply`), либо отключите защиту в [настройках кластера](edit-cluster.md) в консоли управления. После этого можно удалить кластер.

{% endnote %}

{% list tabs group=instructions %}

- CLI {#cli}

  1. Найдите название нужного кластера в списке кластеров: `kubectl get TrinoCluster -n <пространство_имен>`.
  1. Удалите ресурс кластера: `kubectl delete TrinoCluster <имя_кластера> -n <пространство_имен>`.


- Консоль управления {#console}

  1. Откройте ваш проект.
  1. Выберите пространство имен, в котором создан кластер.
  1. В левом меню выберите **Trino** → **Кластеры**.
  1. Выберите кластер.
  1. Нажмите **Удалить**.
  1. В окне подтверждения введите имя кластера и нажмите **Удалить**.

{% endlist %}

Пока ресурс удаляется, в списке кластеров отображается состояние `Deleting`. После полного удаления строка исчезает из таблицы.

Каталоги (`TrinoCatalog`), привязанные к удаляемому кластеру, удаляются вместе с кластером.

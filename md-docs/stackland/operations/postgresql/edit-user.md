# Изменить пользователя PostgreSQL

Если у вас есть пользователь PostgreSQL в [кластере](../../concepts/components/postgresql.md), вы можете изменить его права и параметры. Имя кластера (`spec.cluster`) и имя роли (`spec.username`) после создания изменить нельзя.

{% list tabs group=instructions %}

- CLI {#cli}

  1. Откройте ресурс `PostgresqlRole`. Например, с помощью команды `kubectl edit PostgresqlRole <название_ресурса> -n <название_проекта>`.
  1. Отредактируйте параметры:

      * `spec.membership` — список родительских ролей.
      * `spec.options.superuser` — права суперпользователя.
      * `spec.options.login` — разрешение на вход.
      * `spec.options.createdb` — право создавать базы данных.
      * `spec.options.createrole` — право создавать роли.
      * `spec.options.inherit` — наследование прав родительских ролей.
      * `spec.options.replication` — право использовать репликацию.
      * `spec.options.bypassRLS` — обход политик row-level security.
      * `spec.options.connectionLimit` — лимит одновременных подключений. Значение `-1` — без лимита.
      * `spec.options.validUntil` — срок действия пароля в формате RFC3339.

  1. Чтобы изменить пароль пользователя, обновите значение ключа `password` в связанном Kubernetes Secret. Имя Secret указано в поле `spec.authentication.secretName` ресурса `PostgresqlRole`.

- Консоль управления {#console}

  1. Если вы еще не открыли проект, выберите проект.
  1. В левом меню выберите **PostgreSQL Clusters**.
  1. Выберите кластер.
  1. Перейдите на вкладку **Пользователи** и выберите пользователя.
  1. Нажмите **Редактировать**.
  1. Измените переключатели и поля раздела **Дополнительные параметры**:

      * **Суперпользователь**.
      * **Разрешить вход**.
      * **Родительские роли**.
      * **Создание баз данных**.
      * **Создание ролей**.
      * **Наследование прав ролей**.
      * **Режим репликации**.
      * **Обход политик RLS**.
      * **Лимит подключений**.
      * **Пароль действителен до**.

  1. Нажмите **Сохранить**.

  Готово, настройки пользователя изменены.

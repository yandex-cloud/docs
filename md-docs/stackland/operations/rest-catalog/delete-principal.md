# Отозвать права на каталог

Чтобы отозвать права на [Iceberg REST Catalog](../../concepts/components/rest-catalog.md), удалите соответствующий ресурс `StacklandRestCatalogAccessBinding`.

Удаление назначения не удаляет пользователя, группу или сервисный аккаунт. Права, предоставленные другими назначениями, сохраняются.

## Через CLI {#cli}

1. Найдите нужное назначение в списке. Проверьте каталог, получателя и роль:

    ```bash
    kubectl get stacklandrestcatalogaccessbinding -n <пространство_имен>
    kubectl get stacklandrestcatalogaccessbinding <имя_назначения> -n <пространство_имен> -o yaml
    ```

1. Удалите назначение прав:

    ```bash
    kubectl delete stacklandrestcatalogaccessbinding <имя_назначения> -n <пространство_имен>
    ```

## Через консоль управления {#console}

1. Откройте проект и выберите пространство имен каталога.
1. В левом меню выберите **REST Catalog** → **Каталоги**.
1. Откройте каталог и перейдите на вкладку **Доступ**.
1. Откройте нужное назначение. Проверьте получателя, цель и уровень доступа.
1. Нажмите **Отозвать доступ** и подтвердите действие.

До завершения отзыва назначение остается в списке в состоянии `deleting`. Если операция не завершается, проверьте причину на вкладке **Состояния** назначения.

# Изменить настройки каталога

Вы можете изменить настройки существующего каталога [Iceberg REST Catalog](../../concepts/components/rest-catalog.md). Имя каталога (`metadata.name`) изменить нельзя.

{% list tabs group=instructions %}

- CLI {#cli}

  1. Откройте ресурс `RestCatalog` для редактирования: `kubectl edit restcatalog <имя каталога> -n <название проекта>`.
  1. Измените нужные параметры спецификации и сохраните файл.

  Также можно отредактировать локальный манифест и применить его повторно: `kubectl apply -f restcatalog.yaml -n <название проекта>`.


- Консоль управления {#console}

  1. Если вы еще не открыли проект, выберите проект.
  1. В левом меню выберите **Iceberg REST Catalog**.
  1. На вкладке **Каталоги** выберите каталог одним из способов:

      * нажмите на имя каталога и в шапке карточки нажмите **Редактировать**;
      * нажмите **Редактировать** в строке каталога.

  1. Измените нужные поля. Поле **Имя** доступно только для чтения.
  1. Нажмите **Сохранить**.

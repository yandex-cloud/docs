# Удалить каталог

Вы можете удалить каталог [Iceberg REST Catalog](../../concepts/components/rest-catalog.md) из пространства имен проекта.

{% note warning %}

Вместе с каталогом удаляются его пространства имен Iceberg, таблицы и представления, а также бакет с данными. Если каталог подключен к Trino, запросы к его данным перестанут выполняться.

{% endnote %}

Если включена [защита от удаления](../../concepts/components/rest-catalog.md#catalog) (`spec.deletionProtection: true`), сначала [измените настройки каталога](edit-catalog.md): установите `spec.deletionProtection: false` и примените изменения.

## Через CLI {#cli}

1. Найдите нужный каталог в списке:

    ```bash
    kubectl get stacklandrestcatalog -n <пространство_имен>
    ```

1. Удалите ресурс каталога:

    ```bash
    kubectl delete stacklandrestcatalog <имя_каталога> -n <пространство_имен>
    ```

## Через консоль управления {#console}

1. Откройте проект и выберите пространство имен каталога.
1. В левом меню выберите **REST Catalog** → **Каталоги**.
1. Откройте каталог и нажмите **Удалить**.
1. Введите имя каталога в окне подтверждения и подтвердите удаление.

Удаление может занять время. Пока каталог и его данные удаляются, каталог остается в списке в состоянии `deleting`. Дождитесь его исчезновения из списка.

# Создать каталог

Создайте каталог [Iceberg REST Catalog](../../concepts/components/rest-catalog.md) в [пространстве имен проекта](../projects/manage-namespaces.md). В кластере должны быть включены компоненты Iceberg REST Catalog и [Object Storage](../../concepts/components/storage.md).

Бакет для данных каталога и ключ доступа к нему создаются автоматически. Предварительно создавать их не требуется.

## Через CLI {#cli}

1. Создайте файл `stacklandrestcatalog.yaml` с конфигурацией ресурса `StacklandRestCatalog`:

    ```yaml
    apiVersion: stacklandrestcatalog.stackland.yandex.cloud/v1alpha1
    kind: StacklandRestCatalog
    metadata:
      name: analytics
    spec:
      description: Analytics Iceberg catalog
      labels:
        environment: test
      deletionProtection: false
    ```

    Укажите имя каталога в `metadata.name`. При необходимости задайте описание в `spec.description`, метки в `spec.labels` и включите защиту от удаления с помощью `spec.deletionProtection: true`. Метки задаются только при создании каталога.

1. Примените манифест:

    ```bash
    kubectl apply -f stacklandrestcatalog.yaml -n <пространство_имен>
    ```

1. Проверьте состояние каталога:

    ```bash
    kubectl get stacklandrestcatalog analytics -n <пространство_имен>
    ```

    Дождитесь состояния `ready` в столбце `Phase`.

## Через консоль управления {#console}

1. Откройте проект и выберите пространство имен, в котором нужно создать каталог.
1. В левом меню выберите **REST Catalog** → **Каталоги**.
1. Нажмите **Создать каталог**.
1. В разделе **Основные параметры** заполните поля:

    * **Имя** — имя каталога, уникальное в пространстве имен. Используйте до 63 символов: строчные латинские буквы, цифры и дефисы. Имя должно начинаться с буквы и заканчиваться буквой или цифрой.
    * **Описание** — описание длиной до 256 символов. Необязательное поле.
    * **Метки** — пары **Ключ** и **Значение**. Чтобы добавить пару, нажмите **Добавить метку**. Ключи не должны повторяться. После создания изменить метки нельзя.
    * **Защита от удаления** — включите, чтобы предотвратить случайное удаление каталога и его данных.

1. Нажмите **Создать** и дождитесь готовности каталога в списке.

После создания [назначьте права](create-principal.md) пользователям, группам или сервисным аккаунтам. Чтобы выполнять запросы к данным через Trino, [подключите каталог к кластеру](../trino/create-catalog.md) в том же пространстве имен.

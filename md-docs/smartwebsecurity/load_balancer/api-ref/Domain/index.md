# Smart Web Security Load Balancer API, REST: Domain

A set of methods for managing domains of a Smart Web Security load balancer.

## Methods

#|
||Method | Description ||
|| [Get](get.md) | Returns the specified domain. ||
|| [List](list.md) | Lists domains of the specified load balancer. ||
|| [Create](create.md) | Creates a domain in the specified load balancer. ||
|| [Update](update.md) | Updates the specified domain. ||
|| [Delete](delete.md) | Deletes the specified domain. ||
|#

# Smart Web Security Load Balancer API, REST: LoadBalancer

A set of methods for managing Smart Web Security load balancers.

## Methods

#|
||Method | Description ||
|| [Get](get.md) | Returns the specified load balancer. ||
|| [List](list.md) | Lists load balancers in the specified folder. ||
|| [Create](create.md) | Creates a load balancer in the specified folder. ||
|| [Update](update.md) | Updates the specified load balancer. ||
|| [Delete](delete.md) | Deletes the specified load balancer. ||
|| [Start](start.md) | Starts the specified load balancer. ||
|| [Stop](stop.md) | Stops the specified load balancer. ||
|#

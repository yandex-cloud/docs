# Как работает пробный период


{% note warning %}

Пробный период временно недоступен, рекомендуем сразу [перейти на платную версию](upgrade-to-paid.md).

{% endnote %}


Пробный период доступен только для юридических лиц, которые выбрали способ оплаты **Банковский перевод** при [создании платежного аккаунта](../../../billing/quickstart/index.md). Юридические лица, привязавшие банковскую карту, начинают работу сразу в платном потреблении — пробный период для них не предусмотрен.

Пробный период — это разовое ознакомительное предложение для юридических лиц. Вы можете воспользоваться пробным периодом, если вы:

* никогда не приобретали услуги Yandex Cloud;
* ранее не активировали пробный период.

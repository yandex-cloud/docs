# Переход на платную версию

Переход на платную версию не происходит автоматически после завершения пробного периода. Чтобы перейти на платную версию, перейдите в [сервис Yandex Cloud Billing](https://center.yandex.cloud/billing/accounts), откройте страницу платежного аккаунта и нажмите **Перейти на платную версию**. Пробный период временно недоступен, рекомендуем сразу перейти на платную версию.



## Оплата услуг

В Yandex Cloud услуги оплачиваются в зависимости от потребленного количества. Подробные инструкции по оплате ресурсов после перехода на платную версию вы найдете в [документации](../../../billing/index.md) сервиса Yandex Cloud Billing.

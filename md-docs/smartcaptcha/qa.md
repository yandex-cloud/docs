# Вопросы и ответы

## Как узнать количество проверок за определенный период? {#monitoring-and-billing}

Примерное количество проверок отображается на странице капчи в разделе **Мониторинг**. Период задается с помощью временного фильтра.

На графиках представлены следующие данные:

* `Precheck captcha shows` — количество показов основного задания всех типов.
* `Precheck captcha results` — количество успешных и неуспешных решений основного задания.
* `Advanced challenge shows` — количество показов дополнительного задания.
* `Advanced challenge results` — количество ответов на дополнительное задание.
* `Validate results` — количество успешных и неуспешных валидаций.

Описание метрик приведено в [справочнике](metrics.md).

Количество валидаций на графике может отличаться от количества тарифицируемых запросов. Условия оплаты приведены в [правилах тарификации](pricing.md).

Объем потребления, учтенный для расчета стоимости, доступен в [детализации Yandex Cloud Billing](../billing/operations/check-charges.md) с разбивкой по продуктам. Детализацию можно выгрузить в формате CSV с помощью кнопки **Экспорт детализации**. Она не заменяет статистику всех успешных и неуспешных проверок в мониторинге.

## Что делать при ошибке «Ключ не может использоваться на домене captcha-api.yandex.ru»? {#captcha-cannot-be-used-on-domain}

При локальном тестировании или настройке капчи может появиться ошибка:

```text
Ошибка: ключ не может использоваться на домене captcha-api.yandex.ru
```

Возможная причина — отсутствие локальных адресов в списке разрешенных хостов. Для локального тестирования в настройках капчи в список хостов нужно добавить `localhost` и `127.0.0.1`.

Подробнее о проверке хостов — в разделе [Валидация домена](concepts/domain-validation.md).

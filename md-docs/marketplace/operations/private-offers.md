# Приватные оферы

Предварительно создайте:
* [версию продукта](create-new-version.md), в настройках которой указан тариф типа `Subscription`. Приватный офер можно создать только для продукта, у которого есть активная версия с тарифом типа `Subscription`.
* [тариф](create-tariff.md) типа `Subscription`, который нужно будет указать в настройках приватного офера. Можно использовать тот же тариф, который указан в настройках версии продукта.

Для работы с приватными оферами нужна роль `marketplace.privateOffers.publisher`.

## Создать приватный офер {#create}

1. Авторизуйтесь в [кабинете партнера Marketplace](https://partners.yandex.cloud/).
1. Выберите продукт, для которого хотите создать приватный офер.
1. Перейдите на вкладку **Приватные оферы**.
1. Нажмите **Создать офер**.
1. (Опционально) Укажите идентификатор платежного аккаунта, для которого хотите сделать приватный офер. В таком случае принять офер сможет только пользователь, у которого есть права на просмотр этого платежного аккаунта. Иначе — принять офер сможет любой пользователь, который перейдет по ссылке. Создать ссылку на офер можно после его [активации](#activate).
1. Введите название приватного офера на русском и английском языках.
1. (Опционально) Введите описание приватного офера на русском и английском языках.
1. Укажите [тариф](../concepts/tariff.md) типа `Subscription`.

    {% note warning %}

    Нельзя указать тариф, уже указанный в настройках другого офера, сроки действия которого совпадают со сроками действия текущего.

    {% endnote %}

1. Выберите один или несколько шаблонов подписки и укажите стоимость подписки, которая будет действовать в приватном офере.
1. Укажите сроки:

    * **Начало действия** — дата начала действия приватного офера. Если поле не заполнено, приватный офер начинает действовать через 40 минут после того, как его примет пользователь.
    * **Окончание действия** — дата окончания действия приватного офера. После окончания действия приватного офера пользователь перейдет на подписку, которую выбрал во время принятия приватного офера.
    * **Принять до** — дата, до которой пользователь должен принять приватный офер.

       {% note info %}

       Если пользователь не примет приватный офер до указанной даты, будет необходимо создать новый офер, который он сможет принять. Принять офер позднее даты, которая указана в поле **Принять до**, нельзя.

       {% endnote %}

1. Нажмите **Сохранить черновик**.

## Активировать офер {#activate}

1. Авторизуйтесь в [кабинете партнера Marketplace](https://partners.yandex.cloud/).
1. Выберите продукт, для которого создали приватный офер.
1. Перейдите на вкладку **Приватные оферы**.
1. Выберите приватный офер в статусе `Черновик`.
1. Убедитесь, что в приватном офере заданы верные настройки. Редактировать активный офер нельзя.
1. В правом верхнем углу нажмите **Активировать**. В открывшемся окне подтвердите действие.

## Создать ссылку на офер {#get-link}

1. Авторизуйтесь в [кабинете партнера Marketplace](https://partners.yandex.cloud/).
1. Выберите продукт, для которого создали приватный офер.
1. Перейдите на вкладку **Приватные оферы**.
1. Выберите приватный офер в статусе `Активный`.
1. Создайте ссылку на приватный офер и отправьте ее пользователю. Если в настройках офера вы указали идентификатор платежного аккаунта, принять офер сможет только пользователь, у которого есть права на просмотр этого платежного аккаунта. Иначе — принять офер сможет любой пользователь, который перейдет по ссылке.

    Вы можете изменить ссылку на приватный офер, нажав **Перевыпустить**. В таком случае старая ссылка перестанет быть активной.

## Копировать офер {#copy}

Вы можете создать новый приватный офер для продукта на основе существующего офера.

1. Авторизуйтесь в [кабинете партнера Marketplace](https://partners.yandex.cloud/).
1. Выберите продукт, для которого хотите создать новый офер на основе существующего.
1. Перейдите на вкладку **Приватные оферы**.
1. В строке с приватным офером, который хотите копировать, нажмите ![image](../../_assets/console-icons/ellipsis.svg) → **Создать копию**. Можно копировать офер, который находится в любом статусе.
1. При необходимости измените настройки приватного офера и нажмите **Сохранить черновик**.

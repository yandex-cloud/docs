# Заменить видеофайл

В интерфейсе Cloud Video вы можете заменить уже загруженный видеофайл на новый. При этом ID видео и ссылка на него останутся прежними.

Новый файл проходит обработку. Пока она не завершена, продолжает воспроизводиться предыдущая версия видео.

Заменить файл нельзя, пока видео находится в статусе `Uploading` или `Processing`. Дождитесь окончания загрузки и обработки.

{% note warning %}

После загрузки нового файла предыдущий исходный файл удаляется без возможности восстановления.

Чтобы отменить замену до завершения загрузки, нажмите **Отмена** в окне загрузки или под видео. Прежняя версия видео останется доступной.

{% endnote %}

Чтобы заменить видео:

{% list tabs group=instructions %}

- Интерфейс Cloud Video {#console}

  1. Откройте [главную страницу](https://video.yandex.cloud/) Cloud Video.
  1. Выберите канал.
  1. На вкладке ![image](../../../_assets/console-icons/circle-play.svg) **Видео** в строке с нужным видео нажмите ![image](../../../_assets/console-icons/ellipsis.svg) и выберите **Редактировать**.
  1. Под видео нажмите **Заменить видеофайл**.
  1. В открывшемся окне нажмите кнопку **Выбрать файл** и выберите новое видео.

      Поддерживается загрузка видео в различных форматах, например: [MP4](https://ru.wikipedia.org/wiki/MPEG-4_Part_14), [AVI](https://ru.wikipedia.org/wiki/Audio_Video_Interleave), [MKV](https://ru.wikipedia.org/wiki/Matroska), [FLV](https://ru.wikipedia.org/wiki/Flash_Video), [MOV](https://en.wikipedia.org/wiki/QuickTime_File_Format), [WebM](https://ru.wikipedia.org/wiki/WebM) и других.
      
      В сервисе действуют [ограничения](../../concepts/limits.md) на разрешение публикуемых видео.

  1. Дождитесь окончания загрузки и обработки нового файла.

{% endlist %}

После успешной замены файла будет показано новое видео. При необходимости вы можете [изменить](update.md) его название, описание и другие параметры.

Если при загрузке или обработке возникла ошибка, проверьте подключение к интернету, целостность и формат файла, затем повторите попытку.
